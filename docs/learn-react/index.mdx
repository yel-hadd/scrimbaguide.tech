# React Learning Roadmap

You are reading [react.dev](https://react.dev) (or Next.js docs) and want **hands-on reps in the same sitting**. This roadmap maps each major docs area to **specific Scrimba scrims**, interactive screencasts where you edit the code in the player, so "read the concept" and "type it" stay connected.

This roadmap connects the [official React documentation](https://react.dev) to Scrimba's interactive lessons. Each block below matches a major docs area, quick start, describing UI, interactivity, state, escape hatches, and React 19, so you can read on react.dev and practice in the browser. Use it for React alone or alongside Next.js.

> **Rules of React:** Components and hooks must be **pure** (same inputs → same output). Props and state are **immutable**, never mutate them directly. See [react.dev/reference/rules](https://react.dev/reference/rules) for the full rules.

## 2. Describing the UI

**Goal:** Master the fundamentals of rendering.

- **Props:** Learn how to pass data between components, <AffiliateLink href="https://scrimba.com/learn/learnreact/props-part-1-c0f">Scrimba Lesson: Props Part 1</AffiliateLink>

## 3. Adding Interactivity

**Goal:** Make your app respond to user input.

This is where `state` comes in, React's most important concept. Section 3, React State (5.2 hrs, 58 scrims), is the longest: nine lessons on forms and the Chef Claude project on the Claude API.

## 4. Managing State

**Goal:** Handle complex data flows across your application.

As your app grows, you need better ways to manage state than just passing props down.

- **Passing Data Deeply:** Avoid "prop drilling" with Context, <AffiliateLink href="https://scrimba.com/learn/learnreact/context-provider-c020">Scrimba Lesson: Context API</AffiliateLink>
- **Scaling Up:** Manage complex state logic with `useReducer`, covered in **<AffiliateLink href="https://scrimba.com/advanced-react-c02h">Advanced React</AffiliateLink>**

Advanced React's Reusability module (5 hrs, 68 scrims) builds a component library with compound components, context, and custom hooks ([review](/docs/courses/react/advanced-react/)).

## 6. React 19 & The Future

**Goal:** Learn the newest features like Server Components and Actions.

React 19 introduces major changes to how we handle data mutations and server-client communication.

- **Actions:** Handle form submissions automatically.
- **`useActionState`:** Manage pending states easily.
- **Server Components:** Render components on the server for performance.
