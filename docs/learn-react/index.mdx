# React Learning Roadmap

Three Scrimba courses map onto the react.dev outline: the free <AffiliateLink href="https://scrimba.com/learn-react-c0e">Learn React</AffiliateLink> ([review](/docs/courses/react/learn-react/), 15.1 hours), Pro-only <AffiliateLink href="https://scrimba.com/advanced-react-c02h">Advanced React</AffiliateLink> ([review](/docs/courses/react/advanced-react/), 18.8 hours), and the free React 19 update (about 69 minutes). This roadmap lines each one up against the matching section of [react.dev](https://react.dev), quick start through escape hatches, so you read a concept and type it in the same sitting.

> **Rules of React:** Components and hooks must be pure, same inputs, same output. Props and state are immutable, never mutate them directly. See [react.dev/reference/rules](https://react.dev/reference/rules) for the full rules.

## 1. Quick start

**Goal:** build your first component, understand JSX, and handle basic state.

| Concept | Official docs | Scrimba lesson |
|---|---|---|
| **Thinking in React** | [Read docs](https://react.dev/learn/thinking-in-react) | <AffiliateLink href="https://scrimba.com/learn/learnreact/intro-to-react-c0e">Intro to React</AffiliateLink> |
| **Your first component** | [Read docs](https://react.dev/learn/your-first-component) | <AffiliateLink href="https://scrimba.com/learn/learnreact/custom-components-c0b">Custom Components</AffiliateLink> |
| **Import/export** | [Read docs](https://react.dev/learn/importing-and-exporting-components) | <AffiliateLink href="https://scrimba.com/learn/learnreact/organizing-components-c0d">Organizing Components</AffiliateLink> |
| **JSX** | [Read docs](https://react.dev/learn/writing-markup-with-jsx) | <AffiliateLink href="https://scrimba.com/learn/learnreact/jsx-c0a">JSX</AffiliateLink> |

Section 1, Static pages (2.4 hrs, 29 scrims), builds a one-page ReactFacts site.

## 2. Describing the UI

**Goal:** master the fundamentals of rendering.

- **Props** pass data between components: <AffiliateLink href="https://scrimba.com/learn/learnreact/props-part-1-c0f">Props Part 1</AffiliateLink>
- **Conditional rendering** shows or hides elements based on state: <AffiliateLink href="https://scrimba.com/learn/learnreact/conditional-rendering-%26%26-c010">Conditional Rendering</AffiliateLink>
- **Rendering lists** displays array data with `.map()`: <AffiliateLink href="https://scrimba.com/learn/learnreact/mapping-components-c012">Mapping Components</AffiliateLink>

## 3. Adding interactivity

**Goal:** make your app respond to user input.

This is where state comes in, React's core concept. Section 3, React State (5.2 hrs, 58 scrims), is the longest: nine lessons on forms and the Chef Claude project on the Claude API.

| Concept | Explanation | Scrimba lesson |
|---|---|---|
| **Events** | Handling clicks, form submits, etc. | <AffiliateLink href="https://scrimba.com/learn/learnreact/event-listeners-c014">Event Listeners</AffiliateLink> |
| **State** | Data that changes over time. | <AffiliateLink href="https://scrimba.com/learn/learnreact/usestate-array-destructuring-c016">useState Hook</AffiliateLink> |
| **State updates** | Changing complex state objects. | <AffiliateLink href="https://scrimba.com/learn/learnreact/complex-state-objects-c018">Complex State (Objects)</AffiliateLink> |

## 4. Managing state

**Goal:** handle complex data flows across your application.

As your app grows, passing props down gets unwieldy and you need better ways to manage state.

- **Passing data deeply** avoids prop drilling with Context: <AffiliateLink href="https://scrimba.com/learn/learnreact/context-provider-c020">Context API</AffiliateLink>
- **Scaling up** with `useReducer` for complex state logic is covered in <AffiliateLink href="https://scrimba.com/advanced-react-c02h">Advanced React</AffiliateLink> ([review](/docs/courses/react/advanced-react/))

Advanced React's Reusability module (5 hrs, 68 scrims) builds a component library with compound components, context, and custom hooks.

## 5. Escape hatches

**Goal:** synchronize with external systems, APIs, the DOM.

This is mainly `useEffect` and `useRef`. Learn React section 4, Side Effects (108 min, 22 scrims), builds the Meme Generator before the two capstones, Tenzies and Assembly: Endgame.

- **Effects** run code when components mount, update, or unmount: <AffiliateLink href="https://scrimba.com/learn/learnreact/useeffect-syntax-c022">useEffect</AffiliateLink>, <AffiliateLink href="https://scrimba.com/learn/learnreact/async-javascript-c024">Async / API Calls</AffiliateLink>

<AffiliateLink href="https://scrimba.com/advanced-react-c02h">Advanced React</AffiliateLink> ([review](/docs/courses/react/advanced-react/)) picks up from here: 18.8 hours, six modules, 239 scrims on reusability, VanLife routing, performance, Supabase, auth, and TypeScript in React.

## 6. React 19 and what's next

**Goal:** learn the newest features, Server Components and Actions.

React 19 changes how you handle data mutations and server-client communication: Actions handle form submissions automatically, `useActionState` manages pending states, and Server Components render on the server for performance.

<AffiliateLink href="https://scrimba.com/whats-new-in-react-19-c03d">What's New in React 19</AffiliateLink> ([review](/docs/courses/react/whats-new-in-react-19/)) is free, about 69 minutes, 15 scrims: one form rebuilt with the `action` prop, `useActionState`, `useOptimistic`, and `useFormStatus`, then `use()`. Server Components are absent from the course; see the [Next.js roadmap](/docs/learn-nextjs/) for those.
