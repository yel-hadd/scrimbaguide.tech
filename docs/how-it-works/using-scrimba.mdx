# How to Use Scrimba

<DisclosureNotice />

Create a free account, open [Learn JavaScript](/docs/courses/javascript/learn-javascript/) or [Learn React](/docs/courses/react/learn-react/), press play, pause when the instructor introduces a concept, edit the code in the same player, run it, resume. Upgrade to [Pro](/docs/pricing/pro-vs-free/) once you've opened the tab two weeks in a row, not before.

## What most beginners wish they knew in week one

- **Don't binge-watch**, if you aren't typing, you're not practicing.
- **Use keyboard shortcuts** in the player when available; they keep you in flow.
- **When stuck, press EXPLAIN** in the scrim header before you go searching. [Scrimba Explain](/docs/how-it-works/scrimba-explain/) builds a narrated video from the lesson and the line you highlighted, and you get 10 on a free account.
- **Ship tiny projects** after each module; employers scan repos, not completion percentages.

## Troubleshooting

- **Mobile:** use a desktop browser. The code editor is cramped on phones; check the Scrimba Help Centre for device notes.
- **Progress:** stay logged in. If something looks stuck, refresh and confirm you're on the same account.
- **Captions:** check the player's settings menu for the course you're in.
