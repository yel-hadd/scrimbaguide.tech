# Scrimba Learning Paths

Scrimba runs four Pro career tracks: Frontend (81.6 hours), Fullstack (108.4 hours), Backend (36.2 hours), and AI Engineer (11.4 hours). Mozilla MDN reviewed and endorsed the Frontend path. Every track has you working in the browser on real projects instead of watching video. Frontend is the right start for most beginners; Fullstack is the one-track option if you can commit the extra hours.

Web and software roles remain well-paid in 2026, though outcomes vary by city, stack, and seniority. Pro is a flat annual subscription ([see current Scrimba pricing](/docs/pricing/)); bootcamps covering the same ground often cost five figures, so the choice comes down to whether you need structure and deadlines or you're fine self-paced.

**What the expanded tables of contents show (opened with a Pro account, September 2026):**

- **Frontend** and **Fullstack** share most of their first half (the same HTML, CSS, JavaScript, APIs, React and [Advanced React](/docs/courses/react/advanced-react/) scrims) and both wrap it in path-only material: a welcome module with the "Let's Make a Cake!" platform tutorial, solo projects at the end of the fundamentals modules, and a career block. Fullstack adds Tools of the Trade, Testing, Node, Databases, Express with authentication, TypeScript and Next.js, and its Advanced React module is three hours longer.
- **Backend** is labelled Intermediate on its page and opens with a JavaScript self-check (a "Super Challenge" stock ticker) rather than a welcome tour. Its DevOps module (Docker, GitHub Actions, continuous delivery, CDNs) and its Web Architecture module are not in any other path, and its career block is data structures and algorithms rather than LinkedIn and interview tips.
- **AI Engineer** is nine flat modules, seven of which are standalone courses you can also take on their own; only Deployment (a Node app to Render) and Open-source Models exist only inside the path. No welcome module, no solo-project wrapper, no career block.

The per-path pages walk through each module with screenshots from inside the lessons.

## Who each path is for (2026)

### Career switchers targeting a first developer role

Most people entering the industry need a portfolio employers can click through and fundamentals you can explain in an interview. The [Frontend Developer path](/docs/paths/frontend-developer-path/) is the usual first path: job posts still ask for JavaScript, React, and CSS constantly.

If you can commit high weekly hours and want the widest possible project surface area, the [Fullstack Developer path](/docs/paths/fullstack-developer-path/) is the one-track option. Just expect a longer calendar commitment.

- **Start here:** Frontend Developer path or Fullstack Developer path
- **Pair with:** [Career change to coding (2026)](/blog/career-change-to-coding-2026/), [6-month study plan](/docs/paths/study-plan/)

### Students (CS or not)

Computer Science students often have theory and algorithms down but not much shipped on the web. React, TypeScript, calling APIs, and finishing projects fill that gap. See [Scrimba for CS students](/docs/for/cs-students/).

Non-CS students usually mirror career switchers: start with the Frontend path unless you already have proof you can build user interfaces.

### Working professionals learning on the side

If you only have a few hours a week, pick one path and stay on it. Jumping between catalogs burns time. Frontend stays manageable; Backend can work if you already know JavaScript. Fullstack is the long game.

- **Pair with:** [Learn to code with a full-time job](/blog/how-to-get-first-developer-job-2026/)

### Developers adding backend or AI skills

The [Backend Developer path](/docs/paths/backend-developer-path/) fits if you can build pages or components and want servers, SQL, and shipping APIs without redoing all of frontend.

The [AI Engineer path](/docs/paths/ai-engineer-path/) fits if you already ship web apps and want agents, RAG, and the usual JS-side AI tooling. Still wobbly on JavaScript? Finish Frontend (or enough of it) first so you're not fighting syntax while learning prompts and APIs.

## Scrimba paths vs other ways to learn

Scrimba's official path pages sell the product. This comparison is independent.

- **Paths vs random YouTube:** curated order, interactive scrims, and bundled projects beat an infinite playlist, if you actually finish milestones. See [Scrimba vs YouTube](/docs/comparisons/scrimba-vs-youtube/) and [escape tutorial hell](/blog/how-to-escape-tutorial-hell-2026/).
- **Paths vs bootcamp-style intensity:** Scrimba is self-paced; you supply accountability. Compare costs and outcomes in [Scrimba vs bootcamps](/docs/pricing/scrimba-vs-bootcamps/).
- **Paths vs "only free":** free tiers help you validate fit; paths are mostly Pro. Read [Pro vs Free](/docs/pricing/pro-vs-free/) before you upgrade.
