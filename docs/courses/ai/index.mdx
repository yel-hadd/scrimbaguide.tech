# Scrimba AI Courses

<DisclosureNotice />

Scrimba runs 12 AI courses in JavaScript and TypeScript, covering prompt engineering, agents, RAG, MCP, and the Vercel AI SDK for web developers who want to ship AI features, not train models. Start with the free [Learn to Code with AI](/docs/courses/ai/to-code-with-ai/). Several sequence into the 11.4-hour [AI Engineer Path](/docs/paths/ai-engineer-path/) on Scrimba Pro.

*Reviewed inside each course with a Pro account, September 2026.*

:::tip Looking for the full path review?
[The AI Engineer Path review](/docs/paths/ai-engineer-path/) covers all nine modules, the 162 scrims, and what the path skips.
:::

## Where to start

Start with the free [Learn to Code with AI](/docs/courses/ai/to-code-with-ai/) (4.5 hrs) or the free [Intro to Mistral AI](/docs/courses/ai/mistral-ai/) (1.4 hrs) to try the workflow before committing to the deeper engineering courses.

Scrimba's docs also include a free written <AffiliateLink href="https://docs.scrimba.com/how-ai-works/introduction" location="companion-docs">How AI Works handbook</AffiliateLink>, covering the concepts behind this track: LLMs, prompting, embeddings, RAG, agents, and evals, with a Beginner, Intermediate, and Deep Dive depth switcher. Its code examples lean Python, but the ideas map onto the JavaScript patterns these courses teach. Weighing Scrimba against other places to learn this stack? [The best AI engineering courses of 2026](/blog/best-ai-engineering-courses/) lines up the paid and free options.

- [Learn to Code with AI](/docs/courses/ai/to-code-with-ai/): about 15 mini projects, drum kit to Firebase apps, none gated.
- [Prompt Engineering for Web Developers](/docs/courses/ai/prompt-engineering-for-web-developers/): no app to build; recorded mid 2023 with ChatGPT and Bard.
- [Intro to AI Engineering](/docs/courses/ai/ai-engineering/): 36 scrims building Gift Genie, ending with the API key moved to Node.
- [Intro to Mistral AI](/docs/courses/ai/mistral-ai/): all 25 teaching scrims free, but La Plateforme wants a card on file.
- [Learn AI Agents](/docs/courses/ai/ai-agents/): the same weather agent built twice, ReAct loop then function calling.
- [Build Serverless AI Agents with Langbase](/docs/courses/ai/serverless-ai-agents-with-langbase/): 13 free scrims, three of them challenges; Langbase account needed by scrim 4.
- [Build a Support Agent with Vercel AI SDK](/docs/courses/ai/a-support-agent-with-vercel-ai-sdk/): embeds Scrimba's own help articles into Supabase; the free scrims end before the SDK.
- [Learn RAG](/docs/courses/ai/rag/): 22 scrims ending in ReelRecs, a film recommender on Supabase.
- [Learn Context Engineering](/docs/courses/ai/context-engineering/): 15 scrims, six of them challenges with hints, on Vercel AI SDK 5 and OpenRouter.
- [Intro to Model Context Protocol (MCP)](/docs/courses/ai/model-context-protocol-mcp/): one mock-weather tool; MCP Inspector and Claude Desktop appear on slides only.

## How to progress

Begin with the free [Learn to Code with AI](/docs/courses/ai/to-code-with-ai/), then add [Intro to AI Engineering](/docs/courses/ai/ai-engineering/) for the JS-dev-meets-LLMs foundation. Layer on [Learn AI Agents](/docs/courses/ai/ai-agents/) and [Learn RAG](/docs/courses/ai/rag/) for the two core application patterns, then [Intro to Model Context Protocol (MCP)](/docs/courses/ai/model-context-protocol-mcp/) and [Build a Support Agent with Vercel AI SDK](/docs/courses/ai/a-support-agent-with-vercel-ai-sdk/) for the current plumbing.

## Where it fits

These courses are sequenced into the [AI Engineer Path](/docs/paths/ai-engineer-path/) on Scrimba Pro, the single best reason to subscribe in this category. Browse every track on the [Learning Paths hub](/docs/paths/).
