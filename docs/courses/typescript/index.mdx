# Scrimba TypeScript Courses

<DisclosureNotice />

**Scrimba teaches TypeScript in one free course, not a full track.** [Learn TypeScript](/docs/courses/typescript/learn-typescript/) is 4.2 hours and 79 lessons by Bob Ziroll, split into TypeScript Fundamentals, TypeScript in React, and TypeScript in Express. It is free with no card. TypeScript also shows up as a module inside [Advanced React](/docs/courses/react/advanced-react/) (Pro) and inside the Fullstack and Backend career paths. If you want a deep dive into generics, conditional types, or compiler configuration, this is not the place; if you want to add types to React and Express code you already write, it is exactly the right size.

## Does Scrimba have a TypeScript course?

Yes, one. Scrimba treats TypeScript as a layer on top of the JavaScript you already know rather than a separate language reboot, so the catalog is a single focused course tied to the React and Node stacks most teams ship. It is taught in the same pause-and-edit "scrim" format as the rest of the platform, so every type error you see is one you can fix inline. For how that format works, see [how scrims work](/docs/how-it-works/how-scrims-work/).

## All Scrimba TypeScript content

| Course or module | What it covers | Access | Length |
|---|---|---|---|
| [Learn TypeScript](/docs/courses/typescript/learn-typescript/) | Types, interfaces, unions, generics basics, TS in React, TS in Express, one project | Free | 4.2 hrs, 79 lessons |

| [Fullstack Developer Path](/docs/paths/fullstack-developer-path/), TypeScript module | The Learn TypeScript course placed after JavaScript and React in an ordered path | Pro | Part of 108 hrs |

| [Intro to NestJS](/docs/courses/javascript/nestjs/) | A TypeScript-first backend framework, assumes you already know TS | Free | 1.4 hrs |

Every row above is the same core material reused in context, so there is no reason to take Learn TypeScript twice. Take it standalone if you only want types, or let a path schedule it for you.

## Who the Scrimba TypeScript course is for

- **You already write JavaScript and want types.** This is the target learner. The course assumes functions, arrays, objects, and basic async are familiar.
- **You are learning React and keep seeing `.tsx` in job posts.** Do Learn React first, then this course, then the TypeScript in React module in Advanced React.
- **You are on the Fullstack or Backend path.** It is already scheduled for you; do not skip it, because the Express and Node sections lean on it.

Where it does not fit: complete beginners (start with [Learn JavaScript](/docs/courses/javascript/learn-javascript/) first), and developers who want TypeScript internals or advanced type-level programming. For that second group, our [best TypeScript courses](/blog/best-typescript-courses/) roundup pairs Scrimba's free course with a deeper video course and the official handbook.

## How to progress

1. **[Learn JavaScript](/docs/courses/javascript/learn-javascript/)** (free, 9.4 hrs) if you cannot yet write a fetch call and render its result.
2. **[Learn TypeScript](/docs/courses/typescript/learn-typescript/)** (free, 4.2 hrs) to add types, safer refactors, and the skill most React and Node postings ask for.
3. **Apply it**: the TypeScript in React module of [Advanced React](/docs/courses/react/advanced-react/), or [Learn Express.js](/docs/courses/javascript/expressjs/) and [Intro to NestJS](/docs/courses/javascript/nestjs/) on the backend side.
4. **Drill it**: [Practice TypeScript](/docs/practice/practice-typescript/) has short exercises you can run in the browser.

For a longer plan with weekly milestones, see [how to learn TypeScript on Scrimba](/blog/how-to-learn-typescript-scrimba/) and, if you are choosing between JS-only and TS, [should JavaScript developers learn TypeScript in 2026](/blog/should-javascript-developers-learn-typescript-2026/).

## Where TypeScript sits in the career paths

TypeScript modules appear inside the [Fullstack Developer Path](/docs/paths/fullstack-developer-path/) and the [Backend Developer Path](/docs/paths/backend-developer-path/). The [Frontend Developer Path](/docs/paths/frontend-developer-path/) does not include a TypeScript module, so frontend-path learners should take Learn TypeScript on the side once they finish the React section. Browse every track on the [Learning Paths hub](/docs/paths/).
