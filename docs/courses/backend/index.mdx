# Scrimba Backend Courses

<DisclosureNotice />

Scrimba's backend catalog is four courses, from a 46-minute regex crash course to the 4.8-hour Supabase build, and every one of them runs on JavaScript and TypeScript. That means a frontend developer can add databases, auth, and persistence without switching languages. Start with the free [Learn SQL](/docs/courses/backend/sql/).

## Where to start

Database literacy is what separates copy-paste developers from people who can debug a slow query, and it pays off whether you later use raw SQL, Supabase, or Firebase. [Learn SQL](/docs/courses/backend/sql/) (3.8 hrs) is free, runs Postgres in the browser, and is the strongest first step into this hub.

- [Learn SQL](/docs/courses/backend/sql/) runs Postgres in the browser (PGlite) and packs 62 challenges into 49 scrims.
- [Learn Regular Expressions](/docs/courses/backend/regular-expressions/) is freeCodeCamp's curriculum as 36 short scrims, nothing gated.
- [Intro to Supabase](/docs/courses/backend/supabase/) is free end to end, but you build in your own Supabase project.
- [Build a Mobile App with Firebase](/docs/courses/backend/a-mobile-app-with-firebase/) is Pro after two sample scrims; the free [Learn JavaScript](/docs/courses/javascript/learn-javascript/) course ends with the same Firebase build.

## How to progress

Run [Learn SQL](/docs/courses/backend/sql/) for database fundamentals, then [Intro to Supabase](/docs/courses/backend/supabase/) for SQL plus auth, storage, and row-level security in one platform. [Build a Mobile App with Firebase](/docs/courses/backend/a-mobile-app-with-firebase/) covers Google's backend-as-a-service if you want easy mobile sync instead.

## More backend on the JavaScript track

Scrimba files its server-side runtimes under JavaScript. For the request-response side of backend work, follow this hub with [Learn Node.js](/docs/courses/javascript/nodejs/), [Learn Express.js](/docs/courses/javascript/expressjs/), and [Intro to NestJS](/docs/courses/javascript/nestjs/) on the [JavaScript hub](/docs/courses/javascript/).

## Where it fits

The fastest structured route is the [Backend Developer Path](/docs/paths/backend-developer-path/), which sequences Node, Express, SQL, TypeScript, and deployment into one progression. The broader [Fullstack Developer Path](/docs/paths/fullstack-developer-path/) adds the frontend half. Browse every track on the [Learning Paths hub](/docs/paths/).
