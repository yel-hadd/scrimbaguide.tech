# Scrimba React Courses

<DisclosureNotice />

Scrimba's React track has nine courses, from a 41-minute interview crash course to the 18.8-hour [Advanced React](/docs/courses/react/advanced-react/), running from a free, project-heavy flagship to advanced patterns, routing, and interview prep. Every course is interactive: you pause the lesson and edit the code in the same browser tab.

## Where to start

Start with the free [Learn React](/docs/courses/react/learn-react/) (15.1 hrs). It covers components, props, state, hooks, and finishes on two portfolio projects. It is the anchor for everything else in this category, so do it first whether or not you ever pay for Pro.

- [Learn React](/docs/courses/react/learn-react/): about 180 scrims, all free; Pro gates the Solo Projects and the certificate.
- [React Router](/docs/courses/react/react-router/): 139 scrims, five free, all VanLife.
- [Memory Game](/docs/courses/react/memory-game-in-react/): 29 of 43 scrims are challenges.
- [React Challenges](/docs/courses/react/react-challenges/): 40 broken apps to fix.
- [Interview Questions](/docs/courses/react/react-interview-questions/): nine slide decks, React 16.
- [Advanced React](/docs/courses/react/advanced-react/): 239 scrims; Routing overlaps the Router course.
- [React 19](/docs/courses/react/whats-new-in-react-19/): one form rebuilt four times, free.

## The order to take them in

Run [Learn React](/docs/courses/react/learn-react/) first, then add [Advanced React](/docs/courses/react/advanced-react/) for production patterns and [Learn React Router](/docs/courses/react/react-router/) for navigation. Once those land, use [React Challenges](/docs/courses/react/react-challenges/) for reps and [React Interview Questions](/docs/courses/react/react-interview-questions/) when interviews are near. [What's New in React 19?](/docs/courses/react/whats-new-in-react-19/) is a short update tour for people already comfortable with React 18.

## Where it fits

React sits inside two career tracks on Scrimba Pro. The [Frontend Developer Path](/docs/paths/frontend-developer-path/) wraps Learn React and Advanced React into a longer HTML, CSS, and JS sequence. The [Fullstack Developer Path](/docs/paths/fullstack-developer-path/) adds TypeScript, Node, Express, and Next.js after React. Once you have React down, [the best Next.js courses of 2026](/blog/best-nextjs-courses/) rounds up where to go next, on Scrimba and elsewhere. Browse every track on the [Learning Paths hub](/docs/paths/).
