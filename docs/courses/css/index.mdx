# Scrimba CSS & Design Courses

<DisclosureNotice />

Scrimba runs 12 CSS and design courses, from 29 minutes to 15.1 hours, covering layout, responsive design, Tailwind, animation, and visual UI design. Start with [Learn HTML and CSS](/docs/courses/css/html-and-css/), the free 5.7-hour course every other one here assumes you already know.

## Where to start

[Learn HTML and CSS](/docs/courses/css/html-and-css/) builds the foundation. From there, the layout pillars, [Learn Flexbox](/docs/courses/css/flexbox/) and [Learn CSS Grid](/docs/courses/css/css-grid/), carry most modern layouts.

Scrimba also publishes a free written <AffiliateLink href="https://docs.scrimba.com/css/introduction" location="companion-docs">CSS reference</AffiliateLink> in its docs: a textbook counterpart to the scrims, with a Beginner, Intermediate, and Deep Dive switcher for each topic. Use it to look something up or reread a concept once you have moved past the basics.

From the full reviews:

- [Learn HTML and CSS](/docs/courses/css/html-and-css/): free except three Pro solo projects.
- [Learn CSS Grid](/docs/courses/css/css-grid/): the BBC News clone solo project has no walkthrough.
- [Learn Responsive Web Design](/docs/courses/css/responsive-web-design/): 175 lessons, four free.
- [Learn Tailwind CSS](/docs/courses/css/tailwind-css/): module 2 is five mockup challenges.
- [Learn Bootstrap](/docs/courses/css/bootstrap/): loads Bootstrap 4.0.0 from 2018, not 5.
- [Learn UI Design](/docs/courses/css/ui-design/): roughly 45 of its 100 scrims are challenges.

## How to progress

Run [Learn HTML and CSS](/docs/courses/css/html-and-css/), then the layout pillars [Learn Flexbox](/docs/courses/css/flexbox/) and [Learn CSS Grid](/docs/courses/css/css-grid/). Follow with [Learn Responsive Web Design](/docs/courses/css/responsive-web-design/), the deepest course here, and [Learn Tailwind CSS](/docs/courses/css/tailwind-css/) since Tailwind is the default for new React and Next.js work. If you want the designer's eye and not just the syntax, finish with [Learn UI Design](/docs/courses/css/ui-design/).
