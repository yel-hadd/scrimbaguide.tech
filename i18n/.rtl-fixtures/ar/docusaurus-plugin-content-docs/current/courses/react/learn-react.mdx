# تعلّم React

## التثبيت {#installation}

ابدأ بتشغيل `npm install react react-dom` ثم `npm run dev`. إن ظهر خطأ في
الإصدار، تأكد أن Node أحدث من `20.11.0`، وأن ملف `package.json` يحتوي على
`"type": "module"`.

اضغط <kbd>Ctrl</kbd> + <kbd>C</kbd> لإيقاف الخادم، ثم شغّل
`npm run build -- --base=/docs/` من جديد.

## أول مكوّن {#first-component}

المكوّن دالة تُعيد JSX. لاحظ أن `props.title` يبقى بالإنجليزية داخل جملة عربية:

```jsx
export default function Header({ title = 'مرحبا' }) {
  // The comment stays LTR inside an RTL page.
  return <h1 className="header__title">{title}</h1>;
}
```

## الحالة {#state}

`useState` يُعيد مصفوفة من عنصرين. الأمر التالي يوضّح المسار الكامل للملف داخل
فقرة عربية: `src/components/Header.tsx`، وهو نوع النص الذي ينكسر أولًا.

```bash
npm create vite@latest my-app -- --template react-ts
cd my-app && npm install && npm run dev
```

## نقاط التحقق {#assertions}

- ترتيب الكلمات داخل كل `code` يُقرأ من اليسار إلى اليمين.
- الكتلة البرمجية بأكملها محاذاة إلى اليسار داخل صفحة من اليمين إلى اليسار.
- علامات الترقيم في نهاية الفقرة لا تنتقل إلى بداية السطر.
- لا توجد مربعات فارغة مكان أي حرف عربي.
