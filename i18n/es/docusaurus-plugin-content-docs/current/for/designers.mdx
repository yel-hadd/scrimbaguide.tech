# Scrimba para diseñadores

**Respuesta rápida:** Los diseñadores pueden pasar de Figma a trabajar en frontend con HTML, CSS, Flexbox, Grid y React en Scrimba. [Frontend Developer Path](/docs/paths/frontend-developer-path/) requiere aproximadamente 81,6 horas; Pro está bien por debajo de los rangos típicos de bootcamp (ver la <AffiliateLink href="https://scrimba.com/our-pricing">página de precios oficial</AffiliateLink>). Puedes empezar gratis con HTML y CSS, y el editor interactivo coincide con la forma en que los diseñadores iteran. El Manual de Perspectivas Ocupacionales de la BLS lista los roles de desarrollador web y de software entre las carreras mejor pagadas que monitorea, que es a dónde tienden a caer los diseñadores que codifican.

*Última revisión: abril de 2026.*

## Veredicto rápido {#quick-verdict}

Si quieres programar tus diseños de Figma sin convertirte en un ingeniero completo, esta guía se detiene en la capa visual (HTML, CSS, Flexbox, Grid, React básico) y omite el backend. Si luego decides cambiar de carrera, [Frontend Developer Path](/docs/paths/frontend-developer-path/) es el siguiente paso.

## Lee esta página si {#read-this-page-if}

Diseñas en Figma, Sketch o XD y quieres programar tus propios diseños en lugar de entregarlos y ver a los desarrolladores aproximarlos. Quieres suficiente frontend para construir un sitio de portafolio, prototipar ideas interactivas, o unirte a una startup donde el límite entre diseño e ingeniería es difuso. Te gusta aprender visualmente y encuentras aburridos los cursos de puro texto.

## Omite esta página si {#skip-this-page-if}

Quieres cambiar completamente de carrera, de diseño a ingeniería. Esta guía se detiene en la capa visual; deliberadamente omite el backend, profundidad en despliegue y el módulo de contratación. Si quieres un trabajo como desarrollador en lugar de un híbrido, lee [Frontend Developer Path](/docs/paths/frontend-developer-path/) o [Fullstack Developer Path](/docs/paths/fullstack-developer-path/), y usa [6-month study plan](/docs/paths/study-plan/) para el ritmo.

Ya escribes HTML y CSS cómodamente y quieres añadir JavaScript y React. Ve directamente a [Learn JavaScript](/docs/courses/javascript/) y [Learn React](/docs/courses/react/learn-react/); el material del modelo de caja aquí te parecerá un repaso.

Solo necesitas una herramienta sin código para lanzar páginas de marketing. Webflow, Framer, o incluso sitios de Notion te llevan allí más rápido que aprender HTML y CSS desde cero. Aprende a programar cuando el límite del sin código realmente te bloquee.

## Por qué los diseñadores generalmente lo aprenden rápido {#why-designers-usually-pick-this-up-fast}

Llegas con tres hábitos transferibles.

- Pensamiento visual: ya ves los diseños como componentes, cuadrículas e jerarquía.
- Atención al detalle: notas un error de 2px de espaciado que los ingenieros no verán durante semanas.
- Intuición de CSS: Flexbox se mapea directamente a Auto Layout de Figma, y Grid se mapea a tus diseños de página basados en columnas.

La parte más difícil del frontend para la mayoría de principiantes (diseño visual) es la parte que ya dominas. El cambio más difícil para ti será la lógica de JavaScript y el estado.

## La secuencia del diseñador en Scrimba {#the-designers-sequence-on-scrimba}

No necesitas bases de datos de backend todavía. Mantente en la pila visual.

### Fase 1: fundamentos de HTML y CSS {#phase-1-html-and-css-foundation}

Curso: [Learn HTML and CSS](/docs/courses/css/html-and-css/) (Gratis).

Objetivo: comprender el modelo de caja y la estructura del documento. Traducción de diseñador: HTML es tu panel de capas; CSS es tu panel de propiedades.

### Fase 2: diseños modernos (Flexbox y Grid) {#phase-2-modern-layouts-flexbox-and-grid}

Cursos: [Learn CSS Flexbox](/docs/courses/css/flexbox/) y [Learn CSS Grid](/docs/courses/css/css-grid/) (Grid es gratis).

Objetivo: enviar Auto Layout de Figma en código. Flexbox maneja diseños unidimensionales (filas o columnas); Grid maneja la estructura de página bidimensional.

### Fase 3: diseño responsivo {#phase-3-responsive-design}

Curso: [Responsive Web Design](/docs/courses/css/responsive-web-design/).

Objetivo: hacer que un diseño funcione en teléfono, tablet y escritorio sin programar manualmente tres versiones. Este es el paso donde la mayoría de diseñadores sin código dejan de poder fingirlo.

### Fase 4: JavaScript para interactividad {#phase-4-javascript-for-interactivity}

Curso: [Learn JavaScript](/docs/courses/javascript/) (módulos introductorios gratuitos).

Objetivo: manejar clics, estados de desplazamiento y pequeños bits de estado. Traducción de diseñador: lógica de prototipo, pero real. Ya no necesitas simular interacciones en Figma; puedes construirlas.

### Fase 5: React para pensamiento en componentes {#phase-5-react-for-component-thinking}

Curso: [Learn React](/docs/courses/react/learn-react/) (gratis).

Objetivo: componentes de UI reutilizables. Traducción de diseñador: los componentes de React son componentes de Figma con código. Construyes un botón una vez y lo reutilizas en todas partes con diferentes props.

### Opcional: UI Design Fundamentals {#optional-ui-design-fundamentals}

Curso: [UI Design Fundamentals](/docs/courses/css/ui-design-fundamentals/) con Gary Simon.

Incluso como diseñador, es posible que encuentres esto útil porque enseña a implementar un sistema de diseño en CSS, no dibujarlo en Figma. El paso de traducción es donde se rompen la mayoría de tuberías de diseñador-desarrollador, y este curso vive exactamente en ese límite.

## Tu nuevo flujo de trabajo {#your-new-workflow}

Diseña en Figma, luego abre VS Code y construye la versión en vivo tú mismo. Sin más reuniones de entrega a desarrolladores donde el espaciado y la tipografía se desviaron. Para trabajo con clientes, puedes lanzar páginas de inicio completamente y cobrar en consecuencia.

## Lo que esta guía no promete {#what-this-guide-does-not-promise}

Esta secuencia no te hará un ingeniero de software. Te hará un diseñador que programa bien la capa visual, que es un rol diferente e incrementalmente valioso. Si quieres un trabajo completo como desarrollador, sigue [Frontend Developer Path](/docs/paths/frontend-developer-path/) en su totalidad e incluye el módulo de contratación.
