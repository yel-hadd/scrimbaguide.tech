# Ruta de aprendizaje de React

Estás leyendo [react.dev](https://react.dev) (o la documentación de Next.js) y quieres **práctica directa en la misma sesión**. Esta ruta mapea cada área principal de la documentación a **scrims específicos de Scrimba**, screencasts interactivos donde editas el código en el reproductor, de modo que "leer el concepto" y "escribirlo" queden conectados.

Esta ruta conecta la [documentación oficial de React](https://react.dev) con las lecciones interactivas de Scrimba. Cada bloque a continuación corresponde a un área principal de la documentación: inicio rápido, describir la interfaz, interactividad, estado, vías de escape y React 19, para que puedas leer en react.dev y practicar en el navegador. Úsala solo para React o junto con Next.js.

> **Reglas de React:** los componentes y hooks deben ser **puros** (mismas entradas, misma salida). Props y estado son **inmutables**, nunca se mutan directamente. Consulta [react.dev/reference/rules](https://react.dev/reference/rules) para ver las reglas completas.

## Para quién es esto {#who-this-is-for}

Estudiantes que siguen la ruta de React o Next.js.

## 2. Describir la interfaz {#2-describing-the-ui}

**Objetivo:** dominar los fundamentos del renderizado.

- **Props:** aprende a pasar datos entre componentes, <AffiliateLink href="https://scrimba.com/learn/learnreact/props-part-1-c0f">Scrimba Lesson: Props Part 1</AffiliateLink>
- **Renderizado condicional:** muestra u oculta elementos según el estado, <AffiliateLink href="https://scrimba.com/learn/learnreact/conditional-rendering-%26%26-c010">Scrimba Lesson: Conditional Rendering</AffiliateLink>
- **Renderizado de listas:** muestra datos de arreglos (usando `.map()`), <AffiliateLink href="https://scrimba.com/learn/learnreact/mapping-components-c012">Scrimba Lesson: Mapping Components</AffiliateLink>

## 3. Agregar interactividad {#3-adding-interactivity}

**Objetivo:** hacer que tu app responda a la interacción del usuario.

Aquí es donde entra el `state`, el concepto más importante de React.

| Concepto | Explicación | Lección de Scrimba |
|---|---|---|
| **Eventos** | Manejo de clics, envíos de formularios, etc. | <AffiliateLink href="https://scrimba.com/learn/learnreact/event-listeners-c014">Event Listeners</AffiliateLink> |
| **Estado** | Datos que cambian con el tiempo. | <AffiliateLink href="https://scrimba.com/learn/learnreact/usestate-array-destructuring-c016">useState Hook</AffiliateLink> |

## 4. Gestionar el estado {#4-managing-state}

**Objetivo:** manejar flujos de datos complejos en toda tu aplicación.

A medida que tu app crece, necesitas mejores formas de gestionar el estado que solo pasar props hacia abajo.

- **Pasar datos en profundidad:** evita el "prop drilling" con Context, <AffiliateLink href="https://scrimba.com/learn/learnreact/context-provider-c020">Scrimba Lesson: Context API</AffiliateLink>
- **Escalar:** gestiona lógica de estado compleja con `useReducer`, cubierto en **<AffiliateLink href="https://scrimba.com/advanced-react-c02h">Advanced React</AffiliateLink>**

## 5. Vías de escape {#5-escape-hatches}

**Objetivo:** sincronizarte con sistemas externos (APIs, DOM).

Esto trata principalmente sobre `useEffect` y `useRef`.

- **Efectos:** ejecuta código cuando los componentes se montan, actualizan o desmontan, <AffiliateLink href="https://scrimba.com/learn/learnreact/useeffect-syntax-c022">Scrimba Lesson: useEffect</AffiliateLink>, <AffiliateLink href="https://scrimba.com/learn/learnreact/async-javascript-c024">Scrimba Lesson: Async / API Calls</AffiliateLink>

## 6. React 19 y el futuro {#6-react-19--the-future}

**Objetivo:** aprender las funciones más nuevas, como Server Components y Actions.

React 19 introduce cambios importantes en cómo manejamos las mutaciones de datos y la comunicación cliente-servidor.

- **Actions:** maneja envíos de formularios automáticamente.
- **`useActionState`:** gestiona estados pendientes con facilidad.
- **Server Components:** renderiza componentes en el servidor para mejorar el rendimiento.
