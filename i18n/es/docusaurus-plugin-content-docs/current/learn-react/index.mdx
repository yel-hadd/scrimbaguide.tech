# Hoja de ruta de aprendizaje de React

Estás leyendo [react.dev](https://react.dev) (o la documentación de Next.js) y quieres **práctica interactiva en el mismo momento**. Esta hoja de ruta mapea cada área importante de la documentación a **scrims específicos de Scrimba**, screencasts interactivos donde editas el código en el reproductor, para que "leer el concepto" y "escribir código" se mantengan conectados.

Esta hoja de ruta conecta la [documentación oficial de React](https://react.dev) con las lecciones interactivas de Scrimba. Cada bloque abajo corresponde a un área importante de la documentación: inicio rápido, descripción de la UI, interactividad, estado, vías de escape, y React 19, para que puedas leer en react.dev y practicar en el navegador. Úsala para React solo o junto a Next.js.

> **Reglas de React:** Los componentes y hooks deben ser **puros** (las mismas entradas → la misma salida). Props y state son **inmutables**, nunca los modifiques directamente. Consulta [react.dev/reference/rules](https://react.dev/reference/rules) para todas las reglas.

## 2. Describir la UI {#2-describing-the-ui}

**Objetivo:** Domina los fundamentos del renderizado.

- **Propiedades:** Aprende cómo pasar datos entre componentes, <AffiliateLink href="https://scrimba.com/learn/learnreact/props-part-1-c0f">Lección de Scrimba: Propiedades Parte 1</AffiliateLink>
- **Renderizado condicional:** Muestra/oculta elementos según el estado, <AffiliateLink href="https://scrimba.com/learn/learnreact/conditional-rendering-%26%26-c010">Lección de Scrimba: Renderizado condicional</AffiliateLink>
- **Renderizado de listas:** Renderiza datos de arrays (usando `.map()`), <AffiliateLink href="https://scrimba.com/learn/learnreact/mapping-components-c012">Lección de Scrimba: Mapeando componentes</AffiliateLink>

## 3. Agregar interactividad {#3-adding-interactivity}

**Objetivo:** Haz que tu aplicación responda a la entrada del usuario.

Aquí es donde entra `state`, el concepto más importante de React.

| Concepto | Explicación | Lección de Scrimba |
|---|---|---|
| **Eventos** | Manejo de clics, envío de formularios, etc. | <AffiliateLink href="https://scrimba.com/learn/learnreact/event-listeners-c014">Escuchadores de eventos</AffiliateLink> |
| **Estado** | Datos que cambian con el tiempo. | <AffiliateLink href="https://scrimba.com/learn/learnreact/usestate-array-destructuring-c016">Hook useState</AffiliateLink> |
| **Actualizaciones de estado** | Cambio de objetos de estado complejos. | <AffiliateLink href="https://scrimba.com/learn/learnreact/complex-state-objects-c018">Estado complejo (objetos)</AffiliateLink> |

## 4. Gestionar estado {#4-managing-state}

**Objetivo:** Maneja los flujos de datos complejos en tu aplicación.

Conforme tu aplicación crece, necesitas mejores formas de gestionar el estado que solo pasar props.

- **Pasar datos profundamente:** Evita el "prop drilling" con Context, <AffiliateLink href="https://scrimba.com/learn/learnreact/context-provider-c020">Lección de Scrimba: Context API</AffiliateLink>
- **Escalar:** Gestiona la lógica de estado compleja con `useReducer`, cubierta en **<AffiliateLink href="https://scrimba.com/advanced-react-c02h">Advanced React</AffiliateLink>**

## 5. Vías de escape {#5-escape-hatches}

**Objetivo:** Sincroniza con sistemas externos (APIs, DOM).

Esto se trata principalmente de `useEffect` y `useRef`.

- **Efectos:** Ejecuta código cuando los componentes se monten/actualicen/desmonten, <AffiliateLink href="https://scrimba.com/learn/learnreact/useeffect-syntax-c022">Lección de Scrimba: useEffect</AffiliateLink>, <AffiliateLink href="https://scrimba.com/learn/learnreact/async-javascript-c024">Lección de Scrimba: Async / Llamadas a API</AffiliateLink>

## 6. React 19 y el futuro {#6-react-19--the-future}

**Objetivo:** Aprende las características más nuevas como Componentes de servidor y Acciones.

React 19 introduce cambios importantes en cómo manejamos mutaciones de datos y comunicación servidor-cliente.

- **Acciones:** Maneja envíos de formularios automáticamente.
- **`useActionState`:** Gestiona estados de espera fácilmente.
- **Componentes de servidor:** Renderiza componentes en el servidor para mejorar el rendimiento.
