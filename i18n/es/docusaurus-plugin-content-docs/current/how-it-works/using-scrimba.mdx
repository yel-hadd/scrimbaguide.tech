# Cómo usar Scrimba

<DisclosureNotice />

**Respuesta corta:** Crea una cuenta gratis, abre [Learn JavaScript](/docs/courses/javascript/learn-javascript/) o [Learn React](/docs/courses/react/learn-react/), presiona reproducir, pausa cuando el instructor introduce un concepto, edita el código en el mismo reproductor, ejecútalo, reanuda. Solo actualiza a [Pro](/docs/pricing/pro-vs-free/) después de haber abierto la pestaña dos semanas seguidas.

Te acabas de registrar y quieres una primera sesión sin distracciones que realmente te ayude a construir habilidades.

## Lo que muchos principiantes desearían saber en la primera semana {#what-most-beginners-wish-they-knew-in-week-one}

- **No hagas maratones de videos**, si no estás escribiendo, no estás practicando.
- **Usa accesos directos del teclado** en el reproductor cuando estén disponibles; te mantienen concentrado.
- **Crea proyectos pequeños** después de cada módulo; los empleadores revisan repositorios, no porcentajes de finalización.

## Solución de problemas {#troubleshooting}

- **Dispositivo móvil:** programar funciona mejor en escritorio; los navegadores móviles pueden ser limitados, consulta el Centro de Ayuda de Scrimba para obtener notas del dispositivo.
- **Progreso:** mantente conectado; si algo parece atascado, actualiza y confirma que estés en la misma cuenta.
- **Subtítulos:** verifica la configuración del reproductor si está disponible para un curso determinado.

## Ayuda oficial {#official-help}
