## ¿Vale la pena el tiempo? {#is-it-worth-your-time}

Si puedes construir componentes de React pero tus aplicaciones siguen siendo single-page sin navegación real, esto llena exactamente ese vacío. React Router es la librería de enrutamiento de facto para React, y v6 cambió lo suficiente (las APIs de datos, loaders y actions) como para que tutoriales antiguos te desvíen. React Router v7 ya se lanzó (GA noviembre 2024), pero se basa en el mismo modelo de datos v6, así que las rutas anidadas, loaders y actions que se enseñan aquí se transfieren directamente a v7.

La advertencia honesta es la superposición. El módulo de enrutamiento dentro de [Advanced React](/docs/courses/react/advanced-react/) cubre mucho del mismo terreno. Si ya tienes Advanced React o planeas tomarlo, no necesitas este además. Toma este curso independiente cuando el enrutamiento es específicamente lo que necesitas y no quieres pagar por el material avanzado más amplio alrededor.

El arco avanza desde la configuración hasta los patrones de datos más complejos. Comienzas con rutas y enlaces básicos, luego pasas el bloque inicial más grande en rutas anidadas (layouts, outlets e index routes). Los parámetros de búsqueda y enlaces cubren el estado de navegación real. De allí entra en la capa de datos v6: loaders que buscan datos antes de que una ruta se renderice, límites de error para cargas fallidas, actions para envíos de formularios y rutas protegidas para páginas con control de autenticación. Los datos diferidos lo cierran con respuestas de streaming lentas sin bloquear la página.

## Para quién es, y quién debe saltarlo {#who-its-for-and-who-should-skip-it}

Le va bien a desarrolladores que terminaron [Learn React](/docs/courses/react/learn-react/) o ya trabajan cómodamente con hooks y quieren enrutamiento de nivel producción.

Saltalo si aún no aprendiste React (hazlo primero con Learn React), o si ya estás comprometido con [Advanced React](/docs/courses/react/advanced-react/), cuyo módulo de enrutamiento se superpone mucho con este. No hay razón para pagar por ambos solo por enrutamiento.

## Prerrequisitos {#prerequisites}

React basado en hooks: componentes, props, `useState`, `useEffect` y búsqueda de datos con `fetch` o similar. La comodidad con promesas de JavaScript y código asincrónico importa aquí, ya que loaders y actions funcionan de forma asincrónica por diseño.

## Dónde encaja {#where-it-fits}

## Fortalezas y límites {#strengths-and-limits}

Lo que hace bien: enseña las APIs de datos v6 actuales en lugar del estilo route-config más antiguo, está impulsado por proyectos, y la notación de Bob Ziroll se traslada limpiamente si tomaste Learn React.

Dónde es limitado: se superpone con el módulo de enrutamiento de Advanced React, así que puedes terminar pagando el mismo contenido dos veces si no tienes cuidado, y es específicamente React Router v6, así que usuarios de framework-router (Next.js, Remix) solo obtendrán transferencia parcial.
