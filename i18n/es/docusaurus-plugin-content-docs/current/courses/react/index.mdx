# Cursos de React de Scrimba

La carrera de React de Scrimba va desde un buque insignia gratuito e interactivo hasta patrones avanzados, enrutamiento y preparación de entrevistas. Cada curso es interactivo: pausas la lección y editas el código en la misma pestaña del navegador.

## Por dónde empezar {#where-to-start}

Comienza con [Learn React](/docs/courses/react/learn-react/) gratuito (15.1 hrs). Cubre componentes, props, estado, hooks, y termina con dos proyectos de portafolio. Es la base para todo lo demás en esta categoría, así que hazlo primero aunque nunca pagues por Pro.

## Un orden sensato {#a-sensible-order}

Ejecuta [Learn React](/docs/courses/react/learn-react/) primero, luego suma [Advanced React](/docs/courses/react/advanced-react/) para patrones de producción y [Learn React Router](/docs/courses/react/react-router/) para navegación. Una vez que eso se asiente, usa [React Challenges](/docs/courses/react/react-challenges/) para práctica y [React Interview Questions](/docs/courses/react/react-interview-questions/) cuando se acerquen las entrevistas. [What's New in React 19?](/docs/courses/react/whats-new-in-react-19/) es un recorrido breve de actualización para personas ya cómodas con React 18.

## Dónde encaja {#where-it-fits}

React está dentro de dos carreras profesionales en Scrimba Pro. La [Frontend Developer Path](/docs/paths/frontend-developer-path/) envuelve Learn React y Advanced React en una secuencia más larga de HTML, CSS, JS y TypeScript. La [Fullstack Developer Path](/docs/paths/fullstack-developer-path/) suma Node, Express y Next.js después de React. Explora cada carrera en el [Centro de rutas de aprendizaje](/docs/paths/).
