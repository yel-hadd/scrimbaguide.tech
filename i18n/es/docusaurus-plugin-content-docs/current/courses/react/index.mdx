# Cursos de React en Scrimba

La ruta de React en Scrimba va desde un curso insignia gratuito y muy práctico hasta patrones avanzados, enrutamiento y preparación para entrevistas. Cada curso es interactivo: pausas la lección y editas el código en la misma pestaña del navegador.

## Por dónde empezar {#where-to-start}

Empieza con el gratuito [Learn React](/docs/courses/react/learn-react/) (15.1 h). Cubre componentes, props, estado, hooks y termina con dos proyectos de portafolio. Es la base de todo lo demás en esta categoría, así que hazlo primero, pagues o no por Pro después.

## Un orden con sentido {#a-sensible-order}

Haz primero [Learn React](/docs/courses/react/learn-react/), luego suma [Advanced React](/docs/courses/react/advanced-react/) para patrones de producción y [Learn React Router](/docs/courses/react/react-router/) para navegación. Con eso listo, usa [React Challenges](/docs/courses/react/react-challenges/) para practicar y [React Interview Questions](/docs/courses/react/react-interview-questions/) cuando se acerquen las entrevistas. [What's New in React 19?](/docs/courses/react/whats-new-in-react-19/) es un recorrido corto para quienes ya dominan React 18.

## Dónde encaja {#where-it-fits}

React forma parte de dos rutas de carrera en Scrimba Pro. La [Frontend Developer Path](/docs/paths/frontend-developer-path/) integra Learn React y Advanced React en una secuencia más larga de HTML, CSS, JS y TypeScript. La [Fullstack Developer Path](/docs/paths/fullstack-developer-path/) suma Node, Express y Next.js después de React. Explora todas las rutas en el [hub de rutas de aprendizaje](/docs/paths/).
