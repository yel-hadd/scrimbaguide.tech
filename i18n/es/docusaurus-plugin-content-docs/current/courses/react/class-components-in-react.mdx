Un curso breve y enfocado con Bob Ziroll: aproximadamente 1.3 horas sobre React basado en clases, que los cursos modernos ya no enseñan, dirigido a personas que mantienen códigos antiguos.

## Respuesta rápida {#quick-answer}

Learn Class Components in React es el curso Pro de Scrimba, nivel intermedio, de aproximadamente 1.3 horas impartido por Bob Ziroll, que cubre componentes de clase: métodos de ciclo de vida, enlace de `this`, y `setState`. Toma este curso solo si un trabajo o un código existente te obliga a leer o escribir componentes de clase. Para aprender React en sí, haz Learn React basado en hooks.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Vale la pena tu tiempo en una situación específica: desembarcaste en un código, o un trabajo, que aún usa componentes de clase y necesitas leerlos y editarlos sin adivinar. Para eso, una hora con un instructor claro es mucho más eficiente que armar el rompecabezas desde blogs antiguos. Bob Ziroll cubre las partes que confunden a los que vienen de hooks, es decir, enlace de `this`, métodos de ciclo de vida, y el patrón antiguo de `setState`.

El veredicto honesto es que casi nadie debería tomar esto como su introducción a React. El ecosistema se movió a componentes de función y hooks hace años, el código nuevo se escribe así, y aprender clases primero te dará hábitos que después tendrás que desaprender. Este es un curso de mantenimiento, no un curso de fundamentos.

## Qué aprenderás {#what-youll-learn}

No hay desglose de múltiples módulos para este curso breve. En aproximadamente 1.3 horas cubre el modelo de componentes de clase de punta a punta: definir un componente como una clase, el método `render`, manejar estado con `this.state` y `setState`, enlazar manejadores de eventos y la palabra clave `this`, y los métodos de ciclo de vida (`componentDidMount`, `componentDidUpdate`, `componentWillUnmount`) que hooks como `useEffect` después reemplazaron. El objetivo es fluidez en la lectura y edición de código existente basado en clases, no construir nuevas apps así.

## Para quién es, y quién debería omitirlo {#who-its-for-and-who-should-skip-it}

Se ajusta a desarrolladores que ya conocen React moderno y tienen que trabajar en un código heredado basado en clases, o que están estudiando código antiguo que no escribieron.

Omítelo si estás aprendiendo React por primera vez. Haz [Learn React](/docs/courses/react/learn-react/), que enseña el enfoque basado en hooks usado en todo trabajo actual, y solo vuelve aquí si un proyecto específico requiere clases.

## Requisitos previos {#prerequisites}

Un entendimiento funcional de clases de JavaScript, `this`, y conceptos básicos de React (componentes, props, estado). Ayuda saber hooks, ya que el curso enmarca patrones de clase contra sus equivalentes modernos.

## Fortalezas y limitaciones {#strengths-and-limits}

Qué hace bien: es breve y al punto, apunta a la fricción exacta (enlace, ciclo de vida, `setState`) que los desarrolladores de hooks encuentran en código antiguo, y Bob Ziroll explica el por qué, no solo la sintaxis.

Donde está limitado: enseña un patrón que ya no es cómo se escribe React nuevo, así que tiene una audiencia estrecha, y por sí solo no es un camino para construir apps modernas.
