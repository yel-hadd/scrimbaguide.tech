## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Vale la pena en una situación específica: llegaste a un código, o a un trabajo, que todavía usa componentes de clase y necesitas leerlos y editarlos sin adivinar. Para eso, una hora con un instructor claro es mucho más eficiente que armarlo a partir de entradas de blog antiguas. Bob Ziroll cubre las partes que confunden a quienes vienen de hooks, es decir, el enlace de `this`, los métodos del ciclo de vida y el patrón más antiguo de `setState`.

El veredicto honesto es que casi nadie debería tomar este curso como introducción a React. El ecosistema pasó a componentes de función y hooks hace años, el código nuevo se escribe así, y aprender clases primero te da hábitos que después tendrás que desaprender. Este es un curso de mantenimiento, no un curso de fundamentos.

## Qué aprenderás {#what-youll-learn}

Este curso corto no tiene un desglose de módulos múltiples. En aproximadamente 1.3 horas cubre el modelo de componentes de clase de principio a fin: definir un componente como clase, el método `render`, gestionar el estado con `this.state` y `setState`, enlazar controladores de eventos y la palabra clave `this`, y los métodos del ciclo de vida (`componentDidMount`, `componentDidUpdate`, `componentWillUnmount`) que hooks como `useEffect` reemplazaron después. El objetivo es tener soltura para leer y editar código de clase existente, no construir apps nuevas de esa forma.

## Para quién es, y quién debería omitirlo {#who-its-for-and-who-should-skip-it}

Es adecuado para quienes ya conocen el React moderno y tienen que trabajar en un código legado basado en clases, o que estudian código antiguo que no escribieron.

Omítelo si estás aprendiendo React por primera vez. Haz [Learn React](/docs/courses/react/learn-react/), que enseña el enfoque basado en hooks usado en todo el trabajo actual, y vuelve aquí solo si un proyecto específico requiere clases.

## Requisitos previos {#prerequisites}

Un manejo funcional de las clases de JavaScript, `this` y conceptos básicos de React (componentes, props, estado). Ayuda conocer ya los hooks, ya que el curso plantea los patrones de clase en comparación con sus equivalentes modernos.

## Fortalezas y límites {#strengths-and-limits}

Lo que hace bien: es corto y directo, apunta exactamente a la fricción (enlace de this, ciclo de vida, `setState`) que enfrentan quienes vienen de hooks al leer código antiguo, y Bob Ziroll explica el porqué, no solo la sintaxis.

Dónde está limitado: enseña un patrón que ya no es cómo se escribe React nuevo, así que tiene una audiencia reducida, y por sí solo no es un camino para construir apps modernas.
