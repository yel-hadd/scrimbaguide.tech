# Advanced React

La continuación de Learn React, de nuevo con Bob Ziroll: aproximadamente 19 horas sobre los patrones que separan a alguien que puede usar React de alguien que puede estructurar una aplicación real.

## Respuesta rápida {#quick-answer}

Advanced React es el curso React avanzado de nivel Pro de Scrimba: aproximadamente 18.8 horas distribuidas en seis módulos, enseñado por Bob Ziroll. Cubre patrones de reutilización, enrutamiento, rendimiento, persistencia, autenticación y TypeScript en React. Es para personas que ya terminaron Learn React (o conocen React con hooks) y quieren los patrones de composición, optimización de renders y profundidad en enrutamiento que las aplicaciones de producción necesitan. No es un curso para principiantes y no reitera los conceptos básicos.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Si has construido un par de aplicaciones React y sigues chocando con los mismos problemas (prop drilling, componentes que son difíciles de reutilizar, páginas que se sienten lentas), esto está dirigido directamente a ti. El módulo de reutilización solo tiene cinco horas sobre composición, hooks personalizados y patrones que hacen que los componentes sean flexibles sin convertirlos en un lío.

La advertencia honesta es la superposición y los requisitos previos. El módulo de enrutamiento cubre mucho del mismo terreno que el curso dedicado a [React Router](/docs/courses/react/react-router/), así que si solo necesitas enrutamiento, ese curso independiente es el camino más económico. Y esto es genuinamente avanzado: comenzar aquí sin sólidos conocimientos de hooks no funcionará bien.

Seis módulos ahora, arriba desde tres. Scrimba expandió este curso en 2026, agregando persistencia, autenticación y TypeScript sobre los tres bloques originales, que es la mayor parte de por qué creció de aproximadamente 13 horas a 18.8.

La reutilización sigue siendo el núcleo: composición, hooks personalizados y hacer componentes que se doblen sin romperse. El enrutamiento es un tratamiento completo de la navegación del lado del cliente (y se superpone al curso React Router). El rendimiento es corto pero de alto valor: memoización, evitar re-renders innecesarios e identificar qué es lo que realmente ralentiza una aplicación React. Los tres módulos más nuevos son los que la acercan más al trabajo de producción. La autenticación es el más grande de ellos con 3.8 horas, y TypeScript en React es el que probablemente cierre más la brecha entre lo que sabes y lo que los anuncios de empleo piden.

## Para quién es, y quién debería evitarlo {#who-its-for-and-who-should-skip-it}

Es adecuado para desarrolladores que han terminado [Learn React](/docs/courses/react/learn-react/) o ya trabajan con hooks y quieren subir de nivel hacia React de producción hireable.

Evítalo si aún estás aprendiendo los conceptos básicos (primero haz Learn React), o si tu único objetivo es enrutamiento, en cuyo caso toma [React Router](/docs/courses/react/react-router/) por su cuenta.

## Requisitos previos {#prerequisites}

React cómodo basado en hooks: componentes, props, `useState`, `useEffect` y obtención de datos. Este curso se construye directamente sobre eso y no se detiene para re-explicarlo.

## Dónde encaja {#where-it-fits}

Advanced React se sitúa tarde en la [Frontend Developer Path](/docs/paths/frontend-developer-path/) y la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/), después de los fundamentos de React y generalmente después de algo de trabajo de proyecto.

## Gratis o Pro {#free-or-pro}

Este es un curso Pro, así que necesita una suscripción a Scrimba. Pro también cubre las rutas de carrera completas, los desafíos de codificación, Discord y certificados. Ver <AffiliateLink href="https://scrimba.com/our-pricing">planes actuales</AffiliateLink> para lo que Pro cuesta en tu región.

## Fortalezas y limitaciones {#strengths-and-limits}

Qué hace bien: profundidad real en reutilización y rendimiento, un instructor fuerte y proyectos en lugar de diapositivas. Es uno de los mejores recursos React avanzados a cualquier precio.

Dónde es limitado: el módulo de enrutamiento se superpone al curso independiente, el contador de lecciones publicadas se adelanta al total módulo por módulo, y como todo el trabajo de React aquí, la ayuda rápida depende del Discord Pro.
