# Mejores cursos y tutoriales de React en Scrimba, comparados

Scrimba ofrece una ruta completa de React, desde un curso fundamental gratuito hasta patrones avanzados, enrutamiento, construcción de proyectos y preparación de entrevistas. Todos utilizan el mismo formato interactivo: pausas el video y editas el código del instructor en la misma pestaña del navegador. Esta página compara las opciones para que elijas la indicada a tu nivel, en lugar de empezarlas en el orden incorrecto.

## Los cursos de un vistazo {#the-courses-at-a-glance}

| Curso | Nivel | Duración | Acceso | Ideal para |
|---|---|---|---|---|
| [Learn React](/docs/courses/react/learn-react/) | Intermedio | 15,1 h, 357 lecciones | Gratis | Tu punto de partida: componentes, props, estado, hooks y dos proyectos portafolio con Bob Ziroll |
| [Advanced React](/docs/courses/react/advanced-react/) | Avanzado | 18,8 h, 240 lecciones | Pro | Patrones de producción (context, reducers, hooks personalizados) cuando lo básico te sea cómodo |
| [Learn React Router](/docs/courses/react/react-router/) | Intermedio | 9,7 h, 139 lecciones | Pro | Agregar navegación multipágina y rutas anidadas a una aplicación de React |
| [React Challenges](/docs/courses/react/react-challenges/) | Intermedio | 9,8 h, 84 lecciones | Pro | Construir soltura mediante desafíos prácticos en lugar de solo seguir al instructor |
| [Build a Memory Game in React](/docs/courses/react/memory-game-in-react/) | Intermedio | 4,4 h, 44 lecciones | Pro | Un proyecto enfocado y guiado para consolidar el estado y la gestión de eventos |
| [Movie Search App](/docs/courses/react/a-react-project-movie-search-app/) | Intermedio | 57 min, 14 lecciones | Pro | Construcción rápida conectando React a una API externa |
| [Learn Class Components in React](/docs/courses/react/class-components-in-react/) | Intermedio | 1,3 h, 19 lecciones | Pro | Lectura y mantenimiento de bases de código más antiguas con sintaxis de clases |
| [React Interview Questions](/docs/courses/react/react-interview-questions/) | Intermedio | 41 min, 13 lecciones | Pro | Repaso de último minuto antes de entrevistas, con Cassidy Williams |

Las duraciones y conteos de lecciones provienen del catálogo de Scrimba. Solo [Learn React](/docs/courses/react/learn-react/) es gratuito; todo lo demás requiere Scrimba Pro. Consulta la [página de precios](/docs/pricing/) para las tarifas actuales y lo que desbloquea Pro.

## ¿Cuál deberías elegir? {#which-one-should-you-pick}

- **¿Totalmente nuevo en React?** Comienza con <AffiliateLink href="https://scrimba.com/learn-react-c0e">Learn React</AffiliateLink>. Es gratis, es el curso más largo de la ruta y termina con proyectos reales. Fundamenta todo lo demás, así que hazlo primero sin importar si pagas por Pro.
- **¿Cómodo con componentes y hooks?** Pasa a [Advanced React](/docs/courses/react/advanced-react/) para los patrones que encuentras en bases de código reales, luego agrega [Learn React Router](/docs/courses/react/react-router/) cuando necesites más de una página.
- **¿Aprendes mejor haciendo que viendo?** [React Challenges](/docs/courses/react/react-challenges/) es el curso más práctico del conjunto. Combínalo con una construcción de proyecto como [Build a Memory Game in React](/docs/courses/react/memory-game-in-react/).
- **¿Entrevista pronto?** [React Interview Questions](/docs/courses/react/react-interview-questions/) es un repaso corto y enfocado en lugar de un curso completo.
- **¿Manteniendo una aplicación heredada?** [Learn Class Components in React](/docs/courses/react/class-components-in-react/) cubre la sintaxis más antigua que aún encontrarás en bases de código existentes.

Si quieres React dentro de una secuencia estructurada y orientada al trabajo en lugar de elegir cursos uno por uno, la ruta de React está integrada en <AffiliateLink href="https://scrimba.com/frontend-path-c0j">Frontend Developer Path</AffiliateLink> (81,6 h) y <AffiliateLink href="https://scrimba.com/fullstack-path-c0fullstack">Fullstack Developer Path</AffiliateLink> (108,4 h).

## Prerrequisitos {#prerequisites}

Necesitas dominar HTML, CSS y JavaScript, especialmente arreglos, funciones y sintaxis ES6, antes de que los cursos de React encajen. Si algo de eso se siente débil, comienza con [Learn JavaScript](/docs/courses/javascript/learn-javascript/) primero.
