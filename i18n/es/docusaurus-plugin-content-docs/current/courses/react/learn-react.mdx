## Is it worth your time? {#is-it-worth-your-time}

Es gratis, así que lo único que te cuesta es tiempo, y el formato lo vale. Editar el código del instructor directamente en el reproductor se adapta especialmente bien a React: cambias un dato de estado y ves el componente re-renderizarse en la misma ventana, algo que los tutoriales estáticos no pueden mostrarte.

La salvedad honesta es el nivel. Esto está etiquetado como Intermedio, y lo es. El curso avanza rápidamente por JSX, props y estado, y asume que ya puedas escribir funciones, usar métodos de arrays como `map` y `filter`, y seguir código asincrónico básico. Si eso aún no te describe, vas a tener dificultades alrededor del módulo de State, no porque React sea difícil sino porque el JavaScript debajo de él no te es familiar.

La secuencia es deliberada. Empiezas renderizando componentes estáticos, luego los impulsa desde datos, y después dedicas el bloque más grande (React State, más de cinco horas) en la parte que realmente causa problemas: lifting state, inputs controlados y re-renders. Side Effects cubre traer datos y hablar con APIs. Los dos proyectos finales son donde deja de ayudarte y tú mismo ensamblas las piezas, que es el punto.

## Who it's for, and who should skip it {#who-its-for-and-who-should-skip-it}

Te funciona si estás cómodo con JavaScript y quieres aprender React construyendo en lugar de viendo. Es un punto de anclaje natural para cualquiera en la [Frontend Developer Path](/docs/paths/frontend-developer-path/).

Sáltalo, por ahora, si nunca has escrito JavaScript. Haz primero [Learn JavaScript](/docs/courses/javascript/learn-javascript/) y vuelve. También sáltalo si específicamente necesitas class components o patrones de lifecycle antiguos para una base de código heredada; este curso enseña React moderno basado en hooks, y el material basado en clases vive en un [curso separado](/docs/courses/react/class-components-in-react/).

## Prerequisites {#prerequisites}

JavaScript funcional es el verdadero requisito previo: variables, funciones, métodos de arrays y una comprensión básica de código asincrónico. La comodidad con HTML y CSS ayuda. No necesitas ningún React previo.

## Where it fits {#where-it-fits}

Learn React es el anclaje de React para dos rutas: la [Frontend Developer Path](/docs/paths/frontend-developer-path/) y la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/). El paso usual después de ella es [Advanced React](/docs/courses/react/advanced-react/), que profundiza en rendimiento, patrones y las partes que este curso deja fuera.

## Free or Pro {#free-or-pro}

## Strengths and limits {#strengths-and-limits}

Lo que hace bien: es gratis, enseña React moderno enfocado en hooks, termina en dos proyectos que realmente construyes, y Bob Ziroll es un instructor claro y bien paseado. El formato interactivo es un ajuste genuino para el tema.

Donde está limitado: el ritmo Intermedio es despiadado si tu JavaScript es inestable, no cubre enrutamiento ni bibliotecas de datos (vas a [React Router](/docs/courses/react/react-router/) y otros cursos para esos), y la ayuda de pares rápida depende del Discord Pro en lugar del nivel gratuito.
