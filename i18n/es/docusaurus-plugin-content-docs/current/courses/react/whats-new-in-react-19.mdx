## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Si ya escribes React y solo quieres saber qué cambia realmente en React 19, esta es la forma más eficiente de descubrirlo. Bob Ziroll se salta lo básico e ir directo al nuevo territorio: actions para manejar trabajo asincrónico en transiciones, actualizaciones de UI optimistas, los hooks de estado de formularios y la API `use` para leer promesas y contexto. Es gratis y breve, así que hay poco riesgo.

La salvedad honesta es que es un tour de características, no un curso. Asume que dominas React y no se ralentizará para explicar hooks o estado. También es estrecho por definición; cubre lo nuevo en 19, no cómo construir con React en general. Si aún no conoces React, este no es el punto de partida correcto.

## Qué aprenderás {#what-youll-learn}

Esta es una serie breve y enfocada de scrims en lugar de un curso multimodular, así que no hay un desglose de currículo. En aproximadamente 16 scrims cubre las adiciones principales de React 19: actions, que simplifican las actualizaciones de estado asincrónico y los estados pendientes; actualizaciones optimistas para mostrar resultados antes de que se resuelva una solicitud; los nuevos hooks de estado de formularios para leer el estado de envío; y la API `use`, que permite leer promesas y contexto más directamente dentro de componentes. Cada uno se muestra como un pequeño ejemplo programable que puedes ejecutar en el reproductor.

## Para quién es, y quién debe omitirlo {#who-its-for-and-who-should-skip-it}

Encaja con desarrolladores que ya conocen React y quieren un resumen rápido y actual de las características de la versión 19 para empezar a usarlas.

Omítelo si aún estás aprendiendo React. Las características aquí se construyen sobre una base que este curso asume que ya tienes. Haz [Learn React](/docs/courses/react/learn-react/) primero, luego vuelve cuando quieras ponerte al día sobre las novedades.

## Requisitos previos {#prerequisites}

React sólido y basado en hooks: componentes, estado, props, efectos y obtención de datos asincrónico. Esta es una actualización avanzada que se construye directamente sobre eso y no lo re-explica.
