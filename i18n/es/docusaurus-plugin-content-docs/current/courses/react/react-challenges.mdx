# React Challenges

Un curso basado en desafíos con Daniel Rose: alrededor de 9.8 horas con aproximadamente 40 problemas del mundo real para resolver, diseñado para convertir tu conocimiento de React en soltura con React.

## Respuesta rápida {#quick-answer}

React Challenges es el curso Pro intermedio de Scrimba, alrededor de 9.8 horas enseñado por Daniel Rose. Son alrededor de 40 desafíos de resolución de problemas del mundo real en lugar de conferencias, diseñados para practicar habilidades de React después de haber aprendido los fundamentos. Es para personas que ya conocen React y aprenden mejor haciendo, especialmente cualquiera que se esté preparando para entrevistas o intente cerrar la brecha entre entender React y usarlo sin dudar.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Hay una brecha entre ver a alguien construir React y ser capaz de construirlo tú mismo en un archivo en blanco. Este curso existe para cerrar esa brecha. En lugar de enseñar conceptos nuevos, te propone problemas y te hace resolverlos, que es lo único que realmente construye soltura y velocidad. Para desarrolladores que completaron un curso de fundamentos y aún se sienten lentos, este es el tipo de trabajo correcto.

La advertencia honesta es que no enseña nada nuevo. Si aún no sabes hooks, state y effects, los desafíos te frustrarán en lugar de entrenarte. También es menos estructurado que un curso de construcción por diseño; se espera que luches un poco antes de cada solución. Las personas que quieren una narrativa guiada encontrarán eso incómodo. Esa incomodidad es el mecanismo, pero vale la pena saberlo de antemano.

## Lo que aprenderás {#what-youll-learn}

Este es un curso de desafíos, por lo que no hay desglose de módulos al estilo de conferencia. A través de aproximadamente 40 desafíos y alrededor de 9.8 horas, trabajas en tareas comunes de React del mundo real: gestionar state de componentes, manejar formularios e inputs, obtener y mostrar datos, componer componentes reutilizables y depurar comportamiento que no coincide con la intención. Cada desafío es un problema independiente que resuelves en el player de Scrimba, luego comparas contra la solución trabajada. El efecto acumulativo es soltura: alcanzar rápidamente el patrón correcto en lugar de razonarlo desde cero cada vez.

## Para quién es, y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Se adapta a desarrolladores que ya conocen React y quieren práctica deliberada, y es una fuerte preparación para entrevistas ya que las rondas de entrevistas recompensan exactamente este tipo de velocidad y recall.

Sáltalo si aún no has aprendido React (primero haz [Learn React](/docs/courses/react/learn-react/)), o si prefieres construcciones guiadas sobre problemas abiertos. Esto recompensa luchar a través de desafíos, que no es cómo todos quieren aprender.

## Requisitos previos {#prerequisites}

React sólido basado en hooks: componentes, props, `useState`, `useEffect` y obtención de datos. Los desafíos asumen que ya puedes escribir estos; prueban aplicación, no introducción.

## Dónde encaja {#where-it-fits}

React Challenges se encuentra en la práctica y en el estirón de preparación para entrevistas del [Frontend Developer Path](/docs/paths/frontend-developer-path/) y del [Fullstack Developer Path](/docs/paths/fullstack-developer-path/), mejor tomado después de [Learn React](/docs/courses/react/learn-react/) e idealmente junto con o después de [Advanced React](/docs/courses/react/advanced-react/).

## Fortalezas y límites {#strengths-and-limits}

Lo que hace bien: es práctica pura, cubre tareas del mundo real en lugar de ejemplos de juguete, y construye la velocidad y el recall que tanto las entrevistas como el trabajo real demandan.

Dónde está limitado: no enseña conceptos nuevos, asume que ya sabes React, y su formato abierto no se adaptará a las personas que quieren una narrativa muy guiada.
