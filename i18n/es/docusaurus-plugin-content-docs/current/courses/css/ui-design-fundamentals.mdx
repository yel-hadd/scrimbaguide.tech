## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Por ser gratis, y especialmente para desarrolladores, sí. Muchas personas que pueden escribir CSS aún producen interfaces que se ven un poco raras sin saber por qué, y este curso explica las razones: espaciado, alineación, jerarquía, moderación. Porque enseña en HTML y CSS en lugar de una herramienta de diseño, las lecciones se aplican directamente al código que ya escribes, lo que elimina la fricción habitual de tener que aprender una herramienta para aprender diseño.

La advertencia honesta es que es un curso introductorio y bastante corto. Genera conciencia y te da un vocabulario, pero 1.2 horas no te convertirá en diseñador. Se entiende mejor como una prueba: lo suficiente para decidir si el diseño es algo en lo que quieres profundizar, en cuyo caso el curso completo [Learn UI Design](/docs/courses/css/ui-design/) es el siguiente paso.

## Qué aprenderás {#what-youll-learn}

El curso camina a través de los principios fundamentales que hacen que las interfaces se vean intencionales: jerarquía visual, espaciado y espacio en blanco, opciones tipográficas, color, y la consistencia que une el diseño. Cada idea se muestra en HTML y CSS, así que ves cómo un principio de diseño se traduce en estilos reales en lugar de permanecer abstracto. Al final tienes un ojo entrenado para ver por qué algunas interfaces se sienten pulidas y otras se sienten apretadas, y el vocabulario para hablar de ello.

Es deliberadamente introductorio. Abre la puerta; la profundidad vive en el curso completo que previsualizas.

## Para quién es, y quién debería saltarlo {#who-its-for-and-who-should-skip-it}

Se ajusta bien a desarrolladores que pueden escribir CSS pero quieren mejores instintos de diseño, y a cualquiera curiosos sobre si el diseño UI vale la pena perseguir. Es un ajuste natural para [diseñadores](/docs/for/designers/) que provienen del lado del código.

Saltalo si ya eres un diseñador seguro de ti mismo, o si aún no has aprendido HTML y CSS, en cuyo caso [Learn HTML and CSS](/docs/courses/css/html-and-css/) viene primero.

## Requisitos previos {#prerequisites}

HTML y CSS básicos, ya que los principios se demuestran en código. No requiere experiencia previa en diseño ni herramienta de diseño.

## Dónde encaja {#where-it-fits}

Esta es una prueba gratuita e independiente en lugar de un hito de ruta, y es especialmente relevante para [diseñadores](/docs/for/designers/). Si te funciona, el curso más profundo [Learn UI Design](/docs/courses/css/ui-design/) es el curso completo que previsualizas.
