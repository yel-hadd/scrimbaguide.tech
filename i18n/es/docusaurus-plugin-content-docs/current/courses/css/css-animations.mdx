## ¿Vale la pena? {#is-it-worth-your-time}

El movimiento es una de las cosas que separa un layout competente de uno pulido, y es genuinamente difícil de aprender desde artículos estáticos. Ver cómo cambia una curva de transición mientras editas la función de tiempo, ahí mismo en el reproductor, es donde este formato ayuda más. Los retos te obligan a escribir tú mismo las animaciones en lugar de limitarte a mirar, que es la diferencia entre reconocer la sintaxis CSS y poder usarla.

La advertencia honesta es que la animación es un tema profundo y muy dependiente del gusto personal, y dos horas son una base, no dominio total. Terminas siendo capaz de construir transiciones CSS sólidas y secuencias con keyframes, pero las partes más difíciles (rendimiento, orquestar secuencias complejas, saber cuándo frenar) llegan con la práctica posterior. Tómalo como lo que es: una rampa de entrada.

## Qué vas a aprender {#what-youll-learn}

El curso avanza desde las transiciones CSS (estados hover, cambios de estado, funciones de easing) hasta las animaciones con `@keyframes`, y de ahí a las decisiones de tiempos y secuencias que hacen que el movimiento se sienta deliberado y no artificioso. Los retos de código son la columna vertebral: implementas cada técnica sobre un elemento real y ves el resultado de inmediato. Al final puedes añadir movimiento con propósito a una interfaz sin recurrir a una biblioteca.

Da por hecho que ya escribes CSS con soltura, así que dedica su tiempo específicamente al movimiento en lugar de repasar selectores CSS y el modelo de caja.

## A quién le sirve y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Le sirve a desarrolladores que ya se manejan con CSS y quieren que sus interfaces se sientan vivas: desarrolladores frontend, diseñadores que programan, cualquiera que construya un portafolio donde el acabado importa.

Sáltatelo si tus fundamentos de CSS todavía son inestables (haz primero [Learn HTML and CSS](/docs/courses/css/html-and-css/) o [Learn Responsive Web Design](/docs/courses/css/responsive-web-design/)), o si solo necesitas un efecto hover puntual y puedes sacarlo de la documentación.
