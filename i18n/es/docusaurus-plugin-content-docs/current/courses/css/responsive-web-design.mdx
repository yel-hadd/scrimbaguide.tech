## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Si te tomas en serio CSS, este es el curso a tomar, y la elección del instructor por sí sola hace el caso: Kevin Powell ha pasado años siendo la persona a la que recurren los desarrolladores para explicaciones de CSS, y esa claridad se mantiene durante las 15 horas completas. Es amplio y profundo a la vez, llevándote desde el modelo de caja hasta maquetaciones que no te avergonzaría desplegar profesionalmente. Hecho dentro del reproductor de Scrimba, las partes responsivas especialmente se benefician de ver cómo se adaptan los diseños mientras cambias el código.

La advertencia honesta es el compromiso. Quince horas es una inversión real, y la etiqueta Intermedio significa que se aleja del sostén rápidamente. Si eres un principiante completo, comienza con el gratuito [Learn HTML and CSS](/docs/courses/css/html-and-css/) primero; ir directamente aquí es posible pero más difícil de lo que necesita ser. Y como cubre flexbox y grid a fondo, tomarlo hace que los cursos cortos independientes sobre esos temas sean redundantes en lugar de aditivos.

El arco es deliberado y completo. Comienzas con fundamentos de CSS, luego pasas el bloque más grande aprendiendo a pensar responsivamente, que es el cambio de mentalidad alrededor del cual se construye todo el curso. De allí se afila tu estilo, lleva flexbox y grid bien más allá de lo básico, y termina con técnicas avanzadas que te llevan a una salida de nivel profesional. Como flexbox y grid se cubren adecuadamente aquí, este único curso puede reemplazar los cursos cortos separados.

## Para quién es, y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Se adapta a desarrolladores que ya conocen HTML y CSS básico y quieren ser genuinamente buenos en maquetación: cambios de carrera que construyen hacia un trabajo, desarrolladores frontend que llenan brechas, cualquiera que quiera que CSS deje de parecer una adivinanza.

Saltátelo, por ahora, si eres un principiante completo; haz [Learn HTML and CSS](/docs/courses/css/html-and-css/) primero. Saltátelo también si solo necesitas un tema estrecho rápidamente, en cuyo caso un curso corto enfocado como [Learn Flexbox](/docs/courses/css/flexbox/) o [Learn CSS Grid](/docs/courses/css/css-grid/) es la opción más ligera.

## Requisitos previos {#prerequisites}

HTML y CSS básico: etiquetas, selectores y el modelo de caja. El curso gratuito Learn HTML and CSS es suficiente preparación. No se requiere JavaScript.

## Dónde encaja {#where-it-fits}

Este es el curso CSS profundo en la [Frontend Developer Path](/docs/paths/frontend-developer-path/) y la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/), tomado después de la base HTML y CSS. Una vez que lo completes, los cursos independientes de flexbox, grid y variables son opcionales en lugar de necesarios, ya que cubre ese terreno.

## Gratuito o Pro {#free-or-pro}

Este es un curso Pro, así que necesita una suscripción a Scrimba. Pro también cubre las rutas profesionales, desafíos, certificados y Discord. Ver <AffiliateLink href="https://scrimba.com/our-pricing">planes actuales</AffiliateLink> para lo que Pro cuesta en tu región.

## Fortalezas y limitaciones {#strengths-and-limits}

Qué hace bien: es completo, es impartido por probablemente el mejor educador CSS trabajando, y te lleva a un nivel genuinamente profesional. Como un curso interactivo y consciente de proyectos sobre diseño responsivo, es difícil de superar a cualquier precio.

Dónde está limitado: es un gran compromiso de tiempo, y el ritmo Intermedio asume algo de CSS ya. No es el primer curso de un principiante, y su amplitud hace que los cursos CSS más cortos sean redundantes en lugar de complementarios.
