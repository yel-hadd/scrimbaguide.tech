# “Learn Responsive Web Design”: reseña

El curso insignia de CSS en Scrimba, impartido por Kevin Powell: unas 15 horas que llevan de los fundamentos de CSS al diseño responsivo de nivel profesional.

## Respuesta rápida {#quick-answer}

Learn Responsive Web Design es el curso insignia de CSS de Scrimba, de nivel Intermediate y acceso Pro: unas 15 horas en seis módulos extensos y 175 lecciones, impartido por Kevin Powell, el educador de CSS más conocido de la web. Recorre desde los fundamentos hasta el pensamiento responsivo, flexbox y grid, hasta llegar a maquetación de nivel profesional. Es la inversión seria en CSS del sitio, y es tan completo que los cursos cortos independientes pasan a ser opcionales.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Si te tomas en serio el CSS, este es el curso a seguir, y solo la elección de instructor ya lo justifica: Kevin Powell lleva años siendo la persona a la que los desarrolladores recurren para entender CSS, y esa claridad se mantiene durante las 15 horas. Es amplio y profundo a la vez, y lleva del modelo de caja a maquetaciones que no darían vergüenza publicar en un proyecto profesional. Hecho dentro del reproductor de Scrimba, las partes responsivas se benefician especialmente de ver cómo se adaptan las maquetaciones al cambiar el código.

La salvedad honesta es el compromiso de tiempo. Quince horas son una inversión real, y la etiqueta Intermediate significa que se aleja rápido de la mano que sostiene al principiante. Si eres un principiante total, empieza primero con el curso gratis [Learn HTML and CSS](/docs/courses/css/html-and-css/); entrar directo aquí es posible, pero más difícil de lo necesario. Y como cubre flexbox y grid a fondo, tomarlo vuelve redundantes, en lugar de complementarios, los cursos cortos independientes sobre esos temas.

El arco es deliberado y completo. Empiezas con los fundamentos de CSS, luego dedicas el bloque más largo a aprender a pensar de forma responsiva, que es el cambio de mentalidad sobre el que se construye todo el curso. A partir de ahí afina tu estilo, lleva flexbox y grid bastante más allá de lo básico, y termina con técnicas avanzadas que te llevan a un resultado de nivel profesional. Como aquí flexbox y grid están cubiertos como es debido, este curso por sí solo puede sustituir a los cortos independientes.

## Para quién es, y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Es para desarrolladores que ya conocen HTML y CSS básicos y quieren volverse realmente buenos en maquetación: personas en cambio de carrera que buscan un empleo, desarrolladores front-end que llenan huecos, cualquiera que quiera que el CSS deje de sentirse como adivinar.

Sáltatelo, por ahora, si eres un principiante total; haz primero [Learn HTML and CSS](/docs/courses/css/html-and-css/). Sáltatelo también si solo necesitas un tema puntual y rápido, en cuyo caso un curso corto y enfocado como [Learn Flexbox](/docs/courses/css/flexbox/) o [Learn CSS Grid](/docs/courses/css/css-grid/) es la opción más ligera.

## Requisitos previos {#prerequisites}

HTML y CSS básicos: etiquetas, selectores y el modelo de caja. El curso gratis Learn HTML and CSS es preparación más que suficiente. No hace falta JavaScript.

## Dónde encaja {#where-it-fits}

Este es el curso de CSS a fondo en la [Frontend Developer Path](/docs/paths/frontend-developer-path/) y la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/), y se toma después de la base de HTML y CSS. Una vez que lo completas, los cursos independientes de flexbox, grid y variables pasan a ser opcionales en lugar de necesarios, ya que cubre ese terreno.

## Gratis o Pro {#free-or-pro}

Este es un curso Pro, así que necesita una suscripción a Scrimba. Pro también incluye las rutas profesionales, los challenges, los certificados y el Discord. Consulta los <AffiliateLink href="https://scrimba.com/our-pricing">planes actuales</AffiliateLink> para ver cuánto cuesta Pro en tu región.

## Puntos fuertes y límites {#strengths-and-limits}

Lo que hace bien: es completo, está impartido posiblemente por el mejor educador de CSS en activo, y te lleva a un nivel genuinamente profesional. Como curso interactivo y consciente de proyectos reales sobre diseño responsivo, es difícil de superar a cualquier precio.

Dónde tiene límites: es un compromiso de tiempo grande, y el ritmo Intermediate asume que ya sabes algo de CSS. No es el primer curso para un principiante, y su amplitud hace que los cursos cortos de CSS resulten redundantes en lugar de complementarios.
