## ¿Vale la pena? {#is-it-worth-your-time}

Flexbox es la herramienta de maquetación a la que recurres con más frecuencia y, como grid, tiene mucho más sentido cuando puedes verla en movimiento. Cambiar `justify-content` y ver cómo se redistribuyen los elementos en la misma ventana es el tipo de respuesta inmediata que los tutoriales estáticos no pueden darte, y con menos de una hora basta para dejar de adivinar `align-items` y empezar a colocar los elementos con intención. Per Borgen lo mantiene ágil y centrado en el proyecto.

La salvedad honesta está en el alcance, y es intencional. Esto es flexbox y nada más. Los diseños bidimensionales requieren grid, y el panorama responsivo más amplio (media queries, tamaños fluidos) vive en otro lugar. Para maquetación unidimensional, este curso enseña lo que necesitas; para dominar la maquetación por completo, combínalo con grid y un curso más profundo.

## Qué aprenderás {#what-youll-learn}

El curso cubre el modelo flex directamente: convertir un contenedor en un contexto flex, controlar la dirección y usar `justify-content`, `align-items`, `flex-grow` y `flex-wrap` para organizar y dimensionar los elementos. El proyecto de construcción ancla cada propiedad a un resultado real, así que terminas siendo capaz de maquetar un componente responsivo sin ensayo y error. Los problemas de maquetación recurrentes (centrado, espaciado uniforme, filas responsivas) quedan todos cubiertos de forma concreta.

Se combina de forma natural con [Learn CSS Grid](/docs/courses/css/css-grid/). Flexbox es unidimensional; grid es bidimensional. Saber a cuál recurrir es la mayor parte de la habilidad, y los dos cursos cortos juntos te dan ese instinto.

## A quién le sirve y quién puede saltárselo {#who-its-for-and-who-should-skip-it}

Encaja con desarrolladores que ya conocen CSS básico y quieren ganar soltura rápido con la maquetación cotidiana. Es ideal como refuerzo puntual cuando flexbox es exactamente el hueco que falta.

Sáltatelo si tus bases de CSS todavía no son sólidas (haz primero [Learn HTML and CSS](/docs/courses/css/html-and-css/)), o si prefieres aprender flexbox dentro de un tratamiento más completo, en cuyo caso [Learn Responsive Web Design](/docs/courses/css/responsive-web-design/) lo cubre como parte de un curso mucho más amplio.
