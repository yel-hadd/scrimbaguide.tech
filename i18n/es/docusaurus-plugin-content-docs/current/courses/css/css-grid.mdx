## ¿Vale la pena? {#is-it-worth-your-time}

Grid es uno de esos temas que encajan en cuanto puedes verlos en acción. Editar las definiciones de las pistas y ver cómo se reajusta el diseño en la misma ventana es justo el tipo de retroalimentación inmediata que hace que el formato de Scrimba valga la pena, y una hora basta para pasar de la confusión a sentirte cómodo. Per Borgen va al grano: tres diseños, sin relleno.

La advertencia honesta tiene que ver con el alcance, y es intencional. Este curso trata el grid de forma aislada. El trabajo real de maquetado también depende de flexbox, y grid tiene rincones (subgrid, áreas con nombre complejas, dimensionamiento intrínseco) que este curso breve no explora. Para el trabajo del día a día cubre lo que necesitas; para el panorama completo, combínalo con flexbox y un curso de CSS más profundo.

## Qué aprenderás {#what-youll-learn}

El curso aborda el modelo de grid directamente: definir filas y columnas con `grid-template`, dimensionar las pistas con unidades `fr`, colocar los elementos, y usar el espaciado (gap) y la alineación para controlar el resultado. Los tres proyectos del curso le dan a cada concepto un lugar donde aplicarse, así que terminas con la confianza de recurrir a grid cuando un diseño es realmente bidimensional.

Se combina de forma natural con [Learn Flexbox](/docs/courses/css/flexbox/). Flexbox se encarga de las disposiciones unidimensionales; grid, de las bidimensionales. Saber cuándo usar cada uno es la mayor parte de la habilidad, y hacer ambos cursos breves te da ese criterio.

## Para quién es, y quién puede saltárselo {#who-its-for-and-who-should-skip-it}

Es adecuado para desarrolladores que ya conocen CSS básico y quieren dominar rápido el maquetado moderno. Es ideal como refuerzo puntual cuando grid es justo el vacío que falta cubrir.

Sáltatelo si aún no tienes los fundamentos de CSS (primero haz [Learn HTML and CSS](/docs/courses/css/html-and-css/)), o si prefieres aprender grid dentro de un tratamiento más completo, en cuyo caso [Learn Responsive Web Design](/docs/courses/css/responsive-web-design/) lo cubre como parte de un curso mucho más amplio.

Lo que hace bien: es corto, está basado en proyectos, y lo enseña un instructor claro en un tema donde el formato interactivo realmente funciona.
