## ¿Vale la pena? {#is-it-worth-your-time}

Grid es uno de esos temas que se entiende de golpe en cuanto puedes verlo. Editar las definiciones de tracks y ver cómo el layout se reacomoda en la misma ventana es justo el tipo de retroalimentación inmediata que hace que el formato de Scrimba valga la pena, y una hora alcanza para pasar de la confusión a sentirse cómodo. Per Borgen lo mantiene concreto: tres layouts, sin relleno.

La salvedad honesta es el alcance, y es intencional. Este curso trata grid de forma aislada. El trabajo de layout real también se apoya en flexbox, y grid tiene rincones (subgrid, áreas nombradas complejas, dimensionamiento intrínseco) que este curso corto no aborda. Para el trabajo del día a día cubre lo necesario; para el panorama completo, combínalo con flexbox y un curso de CSS más profundo.

## Qué vas a aprender {#what-youll-learn}

El curso cubre el modelo de grid de forma directa: definir filas y columnas con `grid-template`, dimensionar tracks con unidades `fr`, colocar elementos, y usar gaps y alineación para controlar el resultado. Los tres proyectos de práctica le dan a cada concepto un lugar donde aterrizar, así que terminas capaz de recurrir a grid con confianza cuando un layout es genuinamente bidimensional.

Se combina de forma natural con [Learn Flexbox](/docs/courses/css/flexbox/). Flexbox maneja disposiciones de una dimensión; grid maneja las de dos. Saber cuándo usar cada uno es la mayor parte de la habilidad, y hacer ambos cursos cortos te da ese criterio.

## A quién le sirve, y quién puede saltárselo {#who-its-for-and-who-should-skip-it}

Le sirve a desarrolladores que ya conocen CSS básico y quieren dominar el layout moderno rápido. Es ideal como refuerzo puntual cuando grid es la brecha específica.

Sáltatelo si tus bases de CSS todavía no están firmes (haz primero [Learn HTML and CSS](/docs/courses/css/html-and-css/)), o si prefieres aprender grid dentro de un tratamiento más completo, en cuyo caso [Learn Responsive Web Design](/docs/courses/css/responsive-web-design/) lo cubre como parte de un curso mucho más grande.

## Requisitos previos {#prerequisites}
