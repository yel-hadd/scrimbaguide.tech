# CSS Challenges

Un paquete de práctica de Scrimba con Treasure Porth: unas 2.6 horas de retos en los que recreas componentes y diseños de apps que ya usas, para descubrir qué tan bien conoces realmente el CSS.

## Respuesta rápida {#quick-answer}

CSS Challenges es un curso de práctica de nivel intermedio, dentro de Scrimba Pro: unas 2.6 horas repartidas en 54 lecciones tipo reto, a cargo de Treasure Porth. El formato es recrea-este-componente (piensa en interfaces al estilo de GitHub y diseños reales parecidos), no aprende-este-concepto. Es una prueba y un entrenamiento, no un curso de enseñanza desde cero, y también funciona como buena preparación para entrevistas de frontend.

## ¿Vale la pena? {#is-it-worth-your-time}

Si ya conoces CSS y quieres saber qué tan bueno eres en realidad, esto es una de las cosas más útiles que puedes hacer con un par de horas. Leer sobre flexbox es una cosa; recibir una interfaz objetivo y tener que reproducirla píxel por píxel es lo que expone los huecos. Como los ejercicios imitan componentes de apps que la gente usa de verdad, la práctica se traslada directamente al trabajo real y al tipo de pruebas técnicas para casa que ponen los entrevistadores.

La advertencia honesta es que aquí no se aprende CSS. Hay poca explicación previa: se asume que ya traes el conocimiento y pone a prueba si puedes aplicarlo. Si todavía estás aprendiendo las reglas, los retos van a frustrar más de lo que enseñan. Construye primero las bases y vuelve aquí después para reforzarlas.

## Qué aprenderás {#what-youll-learn}

Más que aprender conceptos nuevos, aquí demuestras y afinas los que ya tienes. Cada reto plantea un componente o diseño objetivo, muchas veces basado en la interfaz de una app reconocible, y tienes que construirlo. A lo largo del paquete practicas flexbox, grid, posicionamiento, pseudoelementos y los pequeños detalles (espaciado, alineación, estados) que separan un clon aproximado de uno convincente. El resultado es fluidez: dejas de buscar las mismas propiedades y empiezas a usarlas de memoria.

También es una preparación realista para entrevistas. El formato de recrear-esta-interfaz se parece mucho a lo que piden muchas pruebas técnicas de frontend, tanto para casa como en vivo.

## Para quién es, y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Encaja con desarrolladores que ya conocen CSS y buscan práctica que refleje el trabajo real: cualquiera que se esté preparando para entrevistas, o cualquiera que ya haya hecho los tutoriales y quiera comprobar cuánto retuvo.

Sáltatelo si todavía estás aprendiendo CSS. Empieza con [Learn HTML and CSS](/docs/courses/css/html-and-css/) o [Learn Responsive Web Design](/docs/courses/css/responsive-web-design/), y vuelve una vez que tengas los fundamentos en su lugar.

## Requisitos previos {#prerequisites}

CSS sólido y funcional: el modelo de caja, flexbox, grid y posicionamiento. El curso da por hecho todo esto y te da problemas en lugar de lecciones.

## Dónde encaja {#where-it-fits}

Es un curso de refuerzo dentro del [Frontend Developer Path](/docs/paths/frontend-developer-path/) y del [Fullstack Developer Path](/docs/paths/fullstack-developer-path/), y conviene tomarlo después de los cursos de enseñanza. Con su enfoque orientado a la carrera profesional y al estilo entrevista, es un paso natural antes de salir a buscar trabajo.

## Gratis o Pro {#free-or-pro}

Este es un curso Pro, así que necesita una suscripción a Scrimba. Pro también incluye las rutas profesionales, los certificados y el Discord. Consulta los <AffiliateLink href="https://scrimba.com/our-pricing">planes actuales</AffiliateLink> para ver cuánto cuesta Pro en tu región.

## Puntos fuertes y límites {#strengths-and-limits}

Lo que hace bien: es práctica genuina, no contenido pasivo, y el enfoque de apps reales lo hace directamente útil tanto para el trabajo como para entrevistas. Muestra con precisión dónde tu CSS todavía cojea.

Dónde está limitado: enseña poco por sí solo. Sin una base de CSS ya construida, los retos son más desalentadores que instructivos.
