# “Learn CSS Variables”: ¿vale la pena?

Un curso breve de Scrimba con Per Borgen: menos de media hora sobre las custom properties de CSS, las variables nativas que facilitan muchísimo el mantenimiento de las hojas de estilo.

## Respuesta rápida {#quick-answer}

Learn CSS Variables es un curso Pro de nivel intermedio: unos 29 minutos y 12 lecciones, impartidas por Per Borgen. Cubre las custom properties de CSS (conocidas como variables CSS): cómo declararlas, usarlas y delimitar su alcance. Es un complemento rápido y de alto valor, no un curso para el que reservas una tarde entera, y encaja bien en las herramientas de cualquier desarrollador front-end.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Por 29 minutos, el retorno es excelente. Las custom properties de CSS son una de esas funciones que mejoran en silencio todo lo que escribes después: temas visuales, espaciado consistente, valores que cambias en un solo lugar en vez de en veinte. El tema es lo bastante acotado como para que el formato interactivo lo cubra por completo, y terminas usando la función correctamente en vez de recordarla a medias de un artículo de blog.

La salvedad honesta es que, sencillamente, es pequeño. No es un curso destino, sino una sola técnica. No esperes que sostenga un plan de estudio por sí solo. Trátalo como un complemento rápido una vez que ya tengas una base sólida de CSS, del tipo que terminas en una sola sesión y aplicas el mismo día.

## Qué aprenderás {#what-youll-learn}

El curso cubre cómo declarar custom properties (normalmente en `:root`), leerlas con `var()`, delimitar su alcance a selectores específicos, y los patrones que las hacen útiles: temas visuales, design tokens y menos repetición. Per Borgen lo mantiene concreto, así que ves cada idea aplicada a estilos reales en vez de descrita en abstracto. Al final puedes introducir variables en una hoja de estilos existente sin adivinar.

Es deliberadamente acotado. Enseña una función a fondo y se detiene ahí, que es exactamente lo que pide el tema.

## A quién le sirve y quién puede saltárselo {#who-its-for-and-who-should-skip-it}

Encaja con cualquier desarrollador que escribe CSS y todavía no adoptó las custom properties, o que las usa copiando y pegando sin entender bien su alcance. Media hora resuelve eso.

Sáltatelo si ya usas las variables CSS con confianza, o si todavía estás aprendiendo los fundamentos de CSS, en cuyo caso [Learn HTML and CSS](/docs/courses/css/html-and-css/) es mejor punto de partida.

## Requisitos previos {#prerequisites}

Conocimientos funcionales de CSS: selectores y el box model. No hace falta JavaScript.
