## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Por 29 minutos, el retorno es excelente. Las propiedades personalizadas de CSS son de esas funciones que mejoran silenciosamente todo lo que escribes después: temas visuales, espaciado consistente, valores que cambias en un solo lugar en vez de en veinte. El tema es lo bastante acotado como para que el formato interactivo lo cubra por completo, y terminas usando la función correctamente en lugar de recordarla a medias de una entrada de blog.

La advertencia honesta es simplemente que es pequeño. No es un curso destino; es una sola técnica. No esperes que sostenga un plan de estudio por sí solo. Trátalo como un complemento rápido una vez que tu base de CSS ya esté lista, del tipo que terminas en una sola sesión y aplicas ese mismo día.

## Qué aprenderás {#what-youll-learn}

El curso cubre la declaración de propiedades personalizadas (normalmente en `:root`), su lectura con `var()`, delimitar su alcance a selectores específicos, y los patrones que las hacen útiles: temas visuales, tokens de diseño y reducción de repetición. Per Borgen lo mantiene concreto, así que ves cada idea aplicada a estilos reales en vez de descrita de forma abstracta. Al terminar, puedes introducir variables en una hoja de estilo existente sin adivinar.

Es deliberadamente acotado. Enseña una función a fondo y se detiene ahí, que es exactamente lo correcto para el tema.

## Para quién es, y quién puede saltárselo {#who-its-for-and-who-should-skip-it}

Le sirve a cualquier desarrollador que escriba CSS y aún no haya adoptado las propiedades personalizadas, o que las use por copiar y pegar sin entender bien su alcance. Media hora resuelve eso.

Sáltatelo si ya usas variables CSS con confianza, o si todavía estás aprendiendo los fundamentos de CSS, en cuyo caso [Learn HTML and CSS](/docs/courses/css/html-and-css/) es el mejor punto de partida.
