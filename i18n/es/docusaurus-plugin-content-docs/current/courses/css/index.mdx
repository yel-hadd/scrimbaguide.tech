# Cursos de CSS y diseño de Scrimba

La ruta de CSS de Scrimba cubre maquetación, diseño responsive, frameworks de utilidades, animación y diseño visual de interfaces. CSS es visual, así que el formato interactivo le sienta bien: cambias un valor en la lección y ves cómo se mueve la caja.

## Por dónde empezar {#where-to-start}

Empieza con el curso gratis [Learn HTML and CSS](/docs/courses/css/html-and-css) (5.7 h). Sienta las bases que dan por hechas todos los demás cursos de aquí. A partir de ahí, los pilares de maquetación, [Learn Flexbox](/docs/courses/css/flexbox) y [Learn CSS Grid](/docs/courses/css/css-grid), cubren la mayoría de las maquetaciones modernas.

Además de los cursos, Scrimba publica gratis en su documentación una <AffiliateLink href="https://docs.scrimba.com/css/introduction" location="companion-docs">referencia de CSS</AffiliateLink> escrita: el equivalente en formato libro de texto a los scrims interactivos, con un selector de nivel (Beginner, Intermediate y Deep Dive) que cambia cuánto profundiza cada tema. Útil para consultar algo puntual o repasar un concepto con más profundidad a medida que avanzas.

## Cómo avanzar {#how-to-progress}

Haz primero [Learn HTML and CSS](/docs/courses/css/html-and-css), y después los pilares de maquetación [Learn Flexbox](/docs/courses/css/flexbox) y [Learn CSS Grid](/docs/courses/css/css-grid). Sigue con [Learn Responsive Web Design](/docs/courses/css/responsive-web-design), el curso más profundo de este catálogo, y [Learn Tailwind CSS](/docs/courses/css/tailwind-css), ya que Tailwind es el estándar en los proyectos nuevos de React y Next.js. Si buscas el ojo del diseñador y no solo la sintaxis, termina con [Learn UI Design](/docs/courses/css/ui-design).

## Dónde encaja {#where-it-fits}

CSS es la primera mitad del [Frontend Developer Path](/docs/paths/frontend-developer-path) y alimenta el [Fullstack Developer Path](/docs/paths/fullstack-developer-path). Explora todas las rutas en el [catálogo de rutas de aprendizaje](/docs/paths/).
