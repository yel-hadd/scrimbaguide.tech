## ¿Vale la pena? {#is-it-worth-your-time}

Es gratis y cubre terreno real, una combinación poco común. Los patrones que aprendes (chat completions, RAG, function calling) son los mismos que encontrarías en un curso de LLM pago, solo que aquí se muestran con Mistral. Para quien está evaluando la ruta de IA, es una forma genuina y sin costo de descubrir si el material te cuadra.

La advertencia honesta es el nivel. Está etiquetado como Intermedio y lo es en serio, y asume que ya sabes escribir JavaScript y llamar una API. También avanza rápido por patrones avanzados como RAG, así que funciona como una introducción práctica y no como un tratamiento profundo de cada tema.

## Qué aprenderás {#what-youll-learn}

El curso sube desde lo básico hasta los patrones útiles. Empiezas con chat completions para lograr que un modelo responda, luego pasas a Retrieval-Augmented Generation para fundamentar las respuestas en tus propios datos, y terminas con function calling para que el modelo pueda activar código. Mistral es el proveedor, pero las técnicas son generales, y ese es el punto: aprende una vez la forma de una aplicación con LLM y reutilízala donde sea.

## Para quién es, y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Le queda bien a desarrolladores que ya saben programar y quieren un vistazo gratis y práctico a los patrones de aplicaciones con LLM antes de comprometerse con la ruta Pro de IA. También le sirve a quienes aprenden mejor construyendo, por curiosidad.

Sáltatelo, por ahora, si nunca has escrito JavaScript; el ritmo Intermedio te va a costar. Empieza con [Learn to Code with AI](/docs/courses/ai/to-code-with-ai/) o [Learn JavaScript](/docs/courses/javascript/learn-javascript/), y vuelve después.

## Requisitos previos {#prerequisites}

JavaScript funcional y una noción básica de cómo llamar una API. No se necesita experiencia previa en IA. Si tu JavaScript está flojo, haz primero [Learn JavaScript](/docs/courses/javascript/learn-javascript/).
