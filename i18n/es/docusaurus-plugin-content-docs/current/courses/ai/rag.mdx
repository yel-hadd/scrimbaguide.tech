## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

RAG es una de las técnicas de mayor impacto en IA aplicada, y este curso la enseña con la profundidad justa: lo suficiente para entender embeddings y bases de datos vectoriales y armar un pipeline funcional, sin ahogarte en teoría. Si construyes algo donde el modelo debe responder a partir de información específica y actual, esto se paga solo rápidamente.

La advertencia honesta es que asume que ya dominas los fundamentos. Deberías sentirte cómodo llamando a un LLM y escribiendo JavaScript antes de empezar aquí, o los pasos de embeddings y recuperación se sentirán como magia. También está enfocado específicamente en RAG, así que es un curso de técnica, no un panorama amplio.

## Qué vas a aprender {#what-youll-learn}

El curso construye el pipeline de RAG de principio a fin. Aprendes cómo los embeddings convierten texto en vectores, cómo una base de datos vectorial te permite recuperar los fragmentos más relevantes, y cómo alimentar esos fragmentos al modelo para que sus respuestas se mantengan precisas y fundamentadas. El formato interactivo hace que armes el pipeline tú mismo, lo que convierte una idea algo abstracta en algo concreto.

Para los conceptos en forma escrita, la documentación de Scrimba incluye un <AffiliateLink href="https://docs.scrimba.com/how-ai-works/rag" location="companion-docs">capítulo de RAG</AffiliateLink> gratuito que recorre el flujo de recuperar y luego generar, el chunking, las bases de datos vectoriales y cuándo no usar RAG, con un selector de profundidad Principiante, Intermedio y Deep Dive. Léelo junto con el proyecto para afianzar el pipeline que armas aquí.

## Para quién es, y quién puede saltárselo {#who-its-for-and-who-should-skip-it}

Encaja con desarrolladores que construyen apps con LLM que deben responder a partir de un cuerpo de información conocido: asistentes de documentación, bots de soporte, búsqueda interna. Si la precisión y el fundamento de las respuestas importan en tu app, esto es esencial.

Sáltatelo, por ahora, si aún no hiciste los fundamentos de IA; empieza con [Intro to AI Engineering](/docs/courses/ai/ai-engineering/). Para un primer vistazo gratuito a RAG, [Intro to Mistral AI](/docs/courses/ai/mistral-ai/) lo toca antes de que te comprometas con este curso.

## Requisitos previos {#prerequisites}

JavaScript y un manejo funcional de cómo llamar a un LLM. Los fundamentos de [Intro to AI Engineering](/docs/courses/ai/ai-engineering/) son la entrada ideal. No se asume conocimiento previo de embeddings ni bases de datos vectoriales.
