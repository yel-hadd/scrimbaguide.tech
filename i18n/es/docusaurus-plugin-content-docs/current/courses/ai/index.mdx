# Cursos de IA de Scrimba

La sección de IA de Scrimba enseña desarrollo de aplicaciones con LLM en JavaScript y TypeScript: ingeniería de prompts, agentes, RAG, MCP y el Vercel AI SDK. Está pensada para desarrolladores web que quieren lanzar funciones de IA, no para investigadores de ML en Python.

## Por dónde empezar {#where-to-start}

Empieza con el curso gratis [Learn to Code with AI](/docs/courses/ai/to-code-with-ai/) (4.5 h) o con el gratis [Intro to Mistral AI](/docs/courses/ai/mistral-ai/) (1.4 h). Ambos te permiten probar el flujo de trabajo sin una suscripción Pro antes de comprometerte con los cursos de ingeniería más avanzados.

Los documentos de Scrimba también incluyen <AffiliateLink href="https://docs.scrimba.com/how-ai-works/introduction" location="companion-docs">el manual gratuito How AI Works</AffiliateLink>, que cubre los conceptos detrás de esta sección: LLM, prompting, embeddings, RAG, agentes y evaluaciones, con un selector de profundidad entre Beginner, Intermediate y Deep Dive. Sus ejemplos de código son en Python, pero las ideas son independientes del lenguaje y se pueden aplicar a los patrones de JavaScript que enseñan estos cursos.

## Cómo avanzar {#how-to-progress}

Empieza con el curso gratis [Learn to Code with AI](/docs/courses/ai/to-code-with-ai/) y luego suma [Intro to AI Engineering](/docs/courses/ai/ai-engineering/) para la base que conecta el desarrollo con JS y los LLM. Añade [Learn AI Agents](/docs/courses/ai/ai-agents/) y [Learn RAG](/docs/courses/ai/rag/) para los dos patrones de aplicación principales, y después [Intro to Model Context Protocol (MCP)](/docs/courses/ai/model-context-protocol-mcp/) y [Build a Support Agent with Vercel AI SDK](/docs/courses/ai/a-support-agent-with-vercel-ai-sdk/) para la infraestructura actual.

## Dónde encaja {#where-it-fits}

Estos cursos se organizan en secuencia dentro de la [AI Engineer Path](/docs/paths/ai-engineer-path/) de Scrimba Pro, la mejor razón para suscribirte en esta categoría. Explora todas las rutas en el [catálogo de rutas de aprendizaje](/docs/paths/).
