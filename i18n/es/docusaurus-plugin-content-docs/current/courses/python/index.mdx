# Cursos de Python de Scrimba

Scrimba es una plataforma enfocada en JavaScript y desarrollo web, por lo que su catálogo de Python sigue siendo limitado: un único curso para principiantes, reconstruido en agosto de 2026, con la versión anterior disponible en línea. Es una forma fluida para escribir tu primer Python en el navegador, sin necesidad de instalar herramientas. También tiene mejor soporte que antes, gracias a la <AffiliateLink href="https://docs.scrimba.com/python/introduction" location="companion-docs">documentación oficial de Python</AffiliateLink> gratuita, una sección de una referencia más amplia que también cubre HTML, CSS, JavaScript y cómo funciona la IA, con profundidad adaptativa, proyectos prácticos y una sección de depuración del curso.

## Dónde empezar {#where-to-start}

Comienza con [Learn Python](/docs/courses/python/learn-python/) (4.1 h), reconstruido desde cero en agosto de 2026 e impartido ahora por Treasure Porth en tres módulos, cada uno terminando en una pequeña aplicación completa. Cubre desde variables y strings hasta listas, bucles, funciones y manejo de errores.

Observa qué eliminó la reconstrucción. Diccionarios, manejo de archivos y clases estaban en la versión anterior y no en esta. El curso anterior de Olof Paulson (5.6 h) sigue siendo gratuito en una <AffiliateLink href="https://scrimba.com/learn-python-c0lpy" location="old-python-course">página separada</AffiliateLink>, y es la forma más rápida de aprender los capítulos que omite la nueva. La documentación complementaria también los cubre en texto, con un selector de nivel para leer cualquier tema con mayor profundidad.

## Cómo progresar {#how-to-progress}

Haz [Learn Python](/docs/courses/python/learn-python/) para sintaxis y patrones fundamentales, luego completa los vacíos (diccionarios, manejo de archivos, clases) de la <AffiliateLink href="https://docs.scrimba.com/python/introduction" location="companion-docs">documentación oficial</AffiliateLink> o del curso anterior. Apóyate en la documentación cuando quieras ir más lentamente o profundizar en un tema. Dado que Scrimba se enfoca en JavaScript, esto es todavía un punto de partida en lugar de una especialización de múltiples cursos: una vez que tu objetivo se centra en datos o automatización, planifica continuar con un programa enfocado en Python en otro lugar. La guía [Best Python Courses for Beginners](/docs/courses/python/best-python-courses-for-beginners/) presenta esas opciones.

## Dónde encaja {#where-it-fits}

Python es una introducción independiente en Scrimba y no forma parte de las [rutas de carrera](/docs/paths/) enfocadas en JavaScript. Si tu objetivo real es el desarrollo web, la [Frontend Developer Path](/docs/paths/frontend-developer-path/) y la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/) son las rutas estructuradas alrededor de las cuales se construye Scrimba.
