## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Si ya sabes construir interfaces en React pero te frenas en cuanto necesitas una base de datos, autenticación o datos que sobrevivan a un refresh, este curso es justo el puente que te falta. Supabase te da un backend real en Postgres sin escribir código de servidor, y el curso lo enseña a través de una sola app coherente en lugar de demos sueltas. Para un desarrollador frontend es una vía rápida para sentirte full-stack, y además es gratis.

La advertencia honesta es que es un curso de proyecto, no una referencia de Supabase. Aprendes las partes que necesita el dashboard de ventas, así que temas como row-level security en profundidad, las edge functions y el storage reciben menos cobertura, o ninguna. También da por hecho JavaScript funcional y algo de React, así que no es un curso de entrada.

Dos módulos de tamaño desigual. Persistence cubre conectar la app a Supabase y guardar y leer datos, la base sobre la que se apoya todo lo demás. Authentication es, por mucho, el bloque más grande y donde está la profundidad real: iniciar y cerrar sesión, proteger datos y manejar sesiones, todo conectado al dashboard en React que construyes. La ponderación te dice que el curso trata la autenticación como la parte difícil e importante, que lo es.

## A quién le sirve y quién puede saltárselo {#who-its-for-and-who-should-skip-it}

Encaja con desarrolladores frontend y de React que quieren su primer backend real, y con cualquiera que ya domine el lado de la interfaz y quiera lanzar algo con usuarios y datos guardados. También es un buen complemento para un curso de SQL, ya que por dentro Supabase es Postgres.

Sáltatelo si todavía no aprendiste React, ya que el proyecto da por hecho que puedes construir componentes y manejar estado. Sáltatelo también si buscas una referencia exhaustiva de Supabase en lugar de una construcción guiada.

## Requisitos previos {#prerequisites}

JavaScript funcional y algo de React: componentes, estado y obtención de datos. Tener una noción básica de bases de datos ayuda, pero no es obligatorio. No se da por hecho ningún conocimiento previo de Supabase.

## Dónde encaja {#where-it-fits}

Este curso no forma parte de ninguna ruta de carrera con nombre propio, pero encaja de forma natural después de [Learn React](/docs/courses/react/learn-react/) para quien quiere sumar un backend a sus habilidades frontend. Combina bien con [Learn SQL](/docs/courses/backend/sql/), porque entender el lenguaje de consultas hace que el núcleo Postgres de Supabase resulte mucho menos opaco.

## Puntos fuertes y límites {#strengths-and-limits}

Lo que hace bien: es gratis, enseña un backend as a service moderno a través de una sola app real, y le da a los desarrolladores frontend un camino genuino para lanzar funciones full-stack sin escribir código de servidor.

Dónde está limitado: está atado al proyecto, así que no cubre Supabase de forma exhaustiva, y da por hecho que ya traes JavaScript y React. Para los fundamentos de bases de datos por debajo, complementa con un curso de SQL.
