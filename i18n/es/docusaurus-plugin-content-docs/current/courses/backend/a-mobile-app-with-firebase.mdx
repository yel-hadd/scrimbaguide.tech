# Build a Mobile App with Firebase

Un curso de proyecto de dos horas con Rafid Hoda en el que construyes una app móvil en tiempo real desde HTML, CSS y JavaScript puros, conectada a Firebase para el backend.

## Respuesta rápida {#quick-answer}

Build a Mobile App with Firebase es el curso de proyecto Pro e intermedio de Scrimba: unas dos horas en 39 lecciones, impartido por Rafid Hoda. Construyes una app en tiempo real funcional con HTML, CSS y JavaScript en el frontend, con Firebase encargándose de los datos y la persistencia detrás. Es un curso centrado en el proyecto, no un manual de referencia de Firebase, así que aprendes publicando una app en vez de recorrer cada servicio de Firebase.

## ¿Vale la pena? {#is-it-worth-your-time}

Si ya escribes JavaScript y quieres sentir lo que te da un backend as a service sin montar tú mismo un servidor, estas son dos horas bien aprovechadas. Firebase elimina las partes que suelen frenar un primer proyecto fullstack (configurar la base de datos, el hosting, la sincronización en tiempo real), así que dedicas el tiempo a la lógica de la app en vez de a la infraestructura.

La salvedad honesta es el alcance. Es un solo proyecto, no un curso que enseñe Firebase de forma sistemática. Terminas capaz de construir algo parecido, pero sin un modelo mental profundo de las reglas de Firestore, la indexación o toda la superficie de autenticación. Trátalo como una construcción guiada, y luego consulta la documentación cuando te encuentres con límites.

## Qué aprenderás {#what-youll-learn}

Construyes una sola app móvil en tiempo real de principio a fin: estructuras la interfaz con HTML y CSS, manejas la interacción en JavaScript puro y te conectas a Firebase para que los datos se sincronicen en vivo y sobrevivan a una recarga de página. El énfasis está en la conexión entre un frontend bajo tu control y un backend alojado que no lo está, la parte que intimida a quienes vienen de páginas estáticas.

## Para quién es, y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Encaja con desarrolladores de JavaScript que ya han construido páginas estáticas y quieren su primer contacto con un backend real sin aprender antes código de servidor. También es una buena opción si específicamente quieres ver Firebase en acción en una app concreta.

Sáltatelo si nunca has escrito JavaScript, o si buscas un tratamiento exhaustivo y de referencia sobre Firebase. El formato aquí es un solo proyecto, así que a quien necesite cobertura estructurada de cada función le va a quedar corto.

## Requisitos previos {#prerequisites}

El requisito real es manejar JavaScript, junto con HTML y CSS básicos. No necesitas experiencia previa con Firebase ni con backend en general; ese es justo el objetivo del curso.

## Dónde encaja {#where-it-fits}

Se combina bien con [Learn Firebase](/docs/courses/javascript/firebase/) si quieres el tratamiento más sistemático junto a esta construcción práctica, y funciona perfectamente como proyecto paralelo para cualquiera que esté siguiendo el [Fullstack Developer Path](/docs/paths/fullstack-developer-path/).

## Puntos fuertes y límites {#strengths-and-limits}

Lo que hace bien: te lleva rápido a una app en tiempo real que funciona, mantiene el frontend en JavaScript puro para que nada quede oculto detrás de un framework, y el formato de proyecto significa que terminas con algo corriendo de verdad.

Dónde está limitado: es corto y está atado a un solo proyecto, así que no cubre Firebase a fondo, y da por sentado que ya traes el JavaScript aprendido. Para una profundidad de referencia sobre Firebase, combínalo con un curso dedicado.
