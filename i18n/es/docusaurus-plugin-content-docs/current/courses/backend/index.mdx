# Cursos de backend de Scrimba

Los cursos de backend de Scrimba cubren bases de datos, backend as a service y los componentes básicos detrás de las APIs reales. El stack es JavaScript y TypeScript de principio a fin, así que le queda bien a quien ya es desarrollador frontend y quiere sumar persistencia, autenticación y datos sin salir del lenguaje que ya conoce.

## Por dónde empezar {#where-to-start}

Empieza con el curso gratis [Learn SQL](/docs/courses/backend/sql) (3.8 h). La alfabetización en bases de datos es lo que separa a quien solo copia y pega de quien puede depurar una consulta lenta, y rinde frutos ya sea que después uses SQL puro, Supabase o Firebase.

## Todos los cursos de backend {#all-backend-courses}

| Curso | Nivel | Acceso | Duración |
|---|---|---|---|
| [Learn SQL](/docs/courses/backend/sql) | Principiante | Gratis | 3.8 h |
| [Learn Regular Expressions](/docs/courses/backend/regular-expressions) | Intermedio | Gratis | 46 min |
| [Intro to Supabase](/docs/courses/backend/supabase) | Intermedio | Gratis | 4.8 h |
| [Build a Mobile App with Firebase](/docs/courses/backend/a-mobile-app-with-firebase) | Intermedio | Pro | 2.0 h |

## Cómo avanzar {#how-to-progress}

Haz [Learn SQL](/docs/courses/backend/sql) para los fundamentos de bases de datos, y luego [Intro to Supabase](/docs/courses/backend/supabase) para sumar SQL más autenticación, almacenamiento y seguridad a nivel de fila en una sola plataforma. [Build a Mobile App with Firebase](/docs/courses/backend/a-mobile-app-with-firebase) cubre el backend as a service de Google si prefieres una sincronización móvil sencilla.

## Más backend dentro de la ruta de JavaScript {#more-backend-on-the-javascript-track}

Scrimba organiza sus runtimes del lado del servidor dentro de JavaScript. Para el lado de solicitud y respuesta del trabajo de backend, sigue este hub con [Learn Node.js](/docs/courses/javascript/nodejs), [Learn Express.js](/docs/courses/javascript/expressjs) e [Intro to NestJS](/docs/courses/javascript/nestjs) en el [hub de JavaScript](/docs/courses/javascript/).

## Dónde encaja {#where-it-fits}

La ruta estructurada más rápida es el [Backend Developer Path](/docs/paths/backend-developer-path), que ordena Node, Express, SQL, TypeScript y despliegue en una sola progresión. El [Fullstack Developer Path](/docs/paths/fullstack-developer-path), más amplio, suma la mitad de frontend. Explora todas las rutas en el [hub de rutas de aprendizaje](/docs/paths/).
