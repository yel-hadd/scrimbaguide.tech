# Cursos de backend de Scrimba

Los cursos de backend de Scrimba cubren bases de datos, backend as a service y los componentes básicos detrás de las APIs reales. El stack es JavaScript y TypeScript de principio a fin, así que le queda bien a los desarrolladores frontend que quieren sumar persistencia, autenticación y datos sin salir del lenguaje que ya conocen.

## Por dónde empezar {#where-to-start}

Empieza con el curso gratis [Learn SQL](/docs/courses/backend/sql) (3.8 h). Saber de bases de datos es lo que separa a los desarrolladores que copian y pegan de quienes pueden depurar una consulta lenta, y vale la pena sin importar si después usas SQL puro, Supabase o Firebase.

## Todos los cursos de backend {#all-backend-courses}

| Curso | Nivel | Acceso | Duración |
|---|---|---|---|
| [Learn SQL](/docs/courses/backend/sql) | Principiante | Gratis | 3.8 h |
| [Learn Regular Expressions](/docs/courses/backend/regular-expressions) | Intermedio | Gratis | 46 min |
| [Intro to Supabase](/docs/courses/backend/supabase) | Intermedio | Gratis | 4.8 h |
| [Build a Mobile App with Firebase](/docs/courses/backend/a-mobile-app-with-firebase) | Intermedio | Pro | 2.0 h |

## Cómo avanzar {#how-to-progress}

Haz primero [Learn SQL](/docs/courses/backend/sql) para los fundamentos de bases de datos y después [Intro to Supabase](/docs/courses/backend/supabase) para sumar SQL, autenticación, almacenamiento y seguridad a nivel de fila en una sola plataforma. [Build a Mobile App with Firebase](/docs/courses/backend/a-mobile-app-with-firebase) cubre el backend as a service de Google si prefieres una sincronización móvil más sencilla.

## Más backend dentro del track de JavaScript {#more-backend-on-the-javascript-track}

Scrimba clasifica sus runtimes del lado del servidor dentro de JavaScript. Para la parte de solicitud-respuesta del trabajo de backend, sigue este hub con [Learn Node.js](/docs/courses/javascript/nodejs), [Learn Express.js](/docs/courses/javascript/expressjs) e [Intro to NestJS](/docs/courses/javascript/nestjs) en el [hub de JavaScript](/docs/courses/javascript/).

## Dónde encaja {#where-it-fits}

La ruta estructurada más rápida es la [Backend Developer Path](/docs/paths/backend-developer-path), que organiza Node, Express, SQL, TypeScript y el despliegue en una sola progresión. La [Fullstack Developer Path](/docs/paths/fullstack-developer-path), más amplia, suma la mitad frontend. Explora todas las rutas en el [catálogo de rutas de aprendizaje](/docs/paths/).
