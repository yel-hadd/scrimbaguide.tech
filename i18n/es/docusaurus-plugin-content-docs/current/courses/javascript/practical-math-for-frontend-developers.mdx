# Practical Math for Frontend Developers

El curso Pro de aproximadamente una hora de Scrimba, enseñado por Ryan Gonyon: el pequeño conjunto de matemática que un desarrollador frontend realmente utiliza, enseñado a través de tres proyectos de aplicaciones reales.

## Respuesta rápida {#quick-answer}

Practical Math for Frontend Developers es un curso de nivel Pro de aproximadamente 1.1 horas que cubre la matemática que los desarrolladores frontend realmente usan en CSS y JavaScript, enseñada a través de tres proyectos de aplicaciones. El énfasis está en la palabra práctica: es matemática aplicada para layout, animación y lógica, no un curso de teoría. Es para desarrolladores que se paralizan cuando una función necesita un poco de aritmética o geometría.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Si alguna vez te encontraste con una función (un cálculo de layout, una curva de animación, posicionar algo dinámicamente) y sentiste que tu falta de matemática te detuvo, este curso está dirigido precisamente a esa incomodidad. En aproximadamente una hora te da los componentes aplicados (proporciones, coordenadas, la aritmética detrás de los patrones comunes de CSS y JS) vinculados a proyectos para que se mantengan. Para desarrolladores que omitieron u olvidaron matemática, esto es un impulso de confianza que vale la pena.

La salvedad honesta es que es corto y dirigido. No te convertirá en un experto en gráficos o matemática de juegos, y los desarrolladores que ya se sienten cómodos con este tipo de matemática encontrarán poco nuevo. Aborda una necesidad específica (la ansiedad de matemática frontend cotidiana) en lugar de enseñar un tema amplio.

## Qué aprenderás {#what-youll-learn}

Este curso cubre matemática práctica tal como aparece en trabajo frontend real: los cálculos de CSS y JavaScript detrás del layout, dimensionamiento, posicionamiento y animación simple, construida a través de tres proyectos de aplicaciones en lugar de ejercicios abstractos. El marco de proyecto es el punto central; ves por qué un pedazo de matemática importa porque lo estás usando para hacer que algo en pantalla se comporte.

Al final tienes un kit de herramientas funcional para la matemática cotidiana que un desarrollador frontend encuentra, además de la confianza para usarlo en lugar de evitar funciones que lo necesitan. Esto es aplicado y práctico en toda la extensión, no teórico.

## Para quién es, y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Se ajusta a desarrolladores frontend que se ven limitados por la matemática, especialmente desarrolladores autodidactas que nunca tuvieron una base formal y quieren dejar de eludir funciones intensivas en cálculos.

Omítelo si ya dominas la matemática detrás del layout y la animación, ya que el alcance es deliberadamente pequeño. También omítelo si eres completamente principiante y aún no has aprendido CSS y JavaScript; el curso asume que ya puedes construir, y aplica matemática sobre eso.

## Requisitos previos {#prerequisites}

CSS y JavaScript funcionales: debes ser capaz de estilizar una página y escribir funciones básicas, ya que la matemática aquí se aplica a través de ambas. No se necesita una formación matemática avanzada; el curso reconstruye los componentes prácticos desde el punto de vista de un desarrollador.

## Dónde encaja {#where-it-fits}

Practical Math for Frontend Developers es una optativa de apoyo en la [Frontend Developer Path](/docs/paths/frontend-developer-path/) y la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/), mejor tomada una vez que ya puedes construir interfaces y quieres manejar las partes intensivas en cálculos con menos fricción.

## Fortalezas y limitaciones {#strengths-and-limits}

Lo que hace bien: se enfoca en una ansiedad real y común, mantiene todo aplicado a través de tres proyectos, y se ajusta a aproximadamente una hora. Ryan Gonyon mantiene el marco práctico en lugar de académico.

Sus limitaciones: el alcance corto significa que cubre solo matemática cotidiana, no gráficos avanzados o matemática de juegos, y ofrece poco a desarrolladores que ya se sienten cómodos con el tema. La ayuda rápida de pares depende del Discord Pro.
