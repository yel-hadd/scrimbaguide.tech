## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Express es la respuesta por defecto cuando alguien pregunta cómo construir un backend en JavaScript, así que aprenderlo rara vez es esfuerzo desperdiciado, y un curso gratuito basado en proyectos sobre esto es una buena oportunidad. Tom Chant enseña construyendo, y la progresión tiene sentido: primero una API, luego una aplicación fullstack para que veas el servidor y frontend comunicándose, y finalmente autenticación, que es el tema que muchos aprendices no dominan y por eso es el módulo más largo aquí, con razón.

La advertencia honesta es la cadena de requisitos previos. Express asume JavaScript y se beneficia mucho de experiencia previa con Node. Si no has visto el sistema de módulos de Node, patrones asincronía o cómo un servidor escucha solicitudes, los primeros pasos parecerán como aprender dos cosas simultáneamente. Está etiquetado como Intermediate y lo es.

Los tres módulos se construyen uno sobre otro. Build an Express API cubre lo esencial: enrutamiento, manejo de solicitudes y respuestas, y el modelo middleware que todo en Express usa. Build a Fullstack Express App conecta ese backend a un frontend para que veas un ciclo de solicitud completo de extremo a extremo. Authentication es el bloque más grande y el de mayor valor, cubriendo cómo manejar inicios de sesión y proteger rutas, que es exactamente la parte que la mayoría de desarrolladores autodidactas omiten y luego enfrentan dificultades en proyectos reales.

## Para quién es, y quién debe omitirlo {#who-its-for-and-who-should-skip-it}

Es adecuado para desarrolladores que conocen JavaScript y quieren incursionar en backend, y es una buena opción para cualquiera que haga transición desde frontend hacia fullstack. Es un punto de anclaje de ruta para el [Fullstack Developer Path](/docs/paths/fullstack-developer-path/) y el [Backend Developer Path](/docs/paths/backend-developer-path/).

Omítelo por ahora si tu JavaScript es débil o nunca has tocado Node; haz primero [Learn JavaScript](/docs/courses/javascript/learn-javascript/) y [Learn Node.js](/docs/courses/javascript/nodejs/). Omítelo también si específicamente quieres un stack backend que no sea Express.

## Requisitos previos {#prerequisites}

JavaScript funcional, incluyendo funciones y código asincrónico, es el requisito verdadero. Experiencia previa con Node.js es muy recomendada, ya que Express corre en Node y el curso no se detiene a enseñar fundamentos de Node.

## Dónde encaja {#where-it-fits}

Learn Express.js es el point de anclaje del framework backend a través de dos rutas: el [Fullstack Developer Path](/docs/paths/fullstack-developer-path/) y el [Backend Developer Path](/docs/paths/backend-developer-path/). El paso natural antes de él es [Learn Node.js](/docs/courses/javascript/nodejs/), y un seguimiento sensato es reforzar lo que construyes con [Learn Cybersecurity](/docs/courses/javascript/cybersecurity/).

## Gratuito o Pro {#free-or-pro}

El curso es gratuito, sin necesidad de suscripción para comenzar o terminarlo. Scrimba Pro es una decisión separada que desbloquea las rutas de carrera estructuradas, desafíos de codificación y certificados. Si solo quieres este curso, nunca tienes que pagar.

## Fortalezas y limitaciones {#strengths-and-limits}

Lo que hace bien: es gratuito, enseña el framework backend Node dominante construyendo cosas reales, y trata autenticación como el tema de primera clase que debería ser en lugar de un complemento tardío.

Dónde está limitado: asume JavaScript y se beneficia mucho del conocimiento previo de Node, así que no es un verdadero punto de partida, y la ayuda de pares rápida depende del Discord de Pro.
