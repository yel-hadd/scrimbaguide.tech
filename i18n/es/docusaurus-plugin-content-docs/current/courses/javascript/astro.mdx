# Intro to Astro

Una introducción Pro a Astro, el framework hecho para sitios rápidos y ricos en contenido, impartida por James Q Quick en cerca de dos horas de construcción práctica.

## Respuesta rápida {#quick-answer}

Este es el curso Pro de introducción a Astro de Scrimba, de unas 2.1 horas, impartido por James Q Quick. Astro es un framework web moderno pensado para sitios con mucho contenido, como blogs, documentación y páginas de marketing, donde combina componentes con Markdown y envía muy poco JavaScript por defecto. El curso lleva rápido a construir con el modelo de componentes y las páginas de contenido de Astro, sin asumir experiencia previa.

## ¿Vale la pena? {#is-it-worth-your-time}

Si construyes o mantienes sitios de contenido, blogs, documentación o landing pages, Astro es una de las mejores herramientas para conocer ahora mismo, y una introducción enfocada de dos horas es una forma sensata de evaluar si encaja con tu forma de trabajar. James Q Quick es un instructor enérgico y práctico, y el curso se mantiene hands-on, así que terminas habiendo construido con Astro en lugar de solo haber escuchado sobre él.

La advertencia honesta es que se trata de una introducción, no de un curso profundo. Deja cómodo con el modelo central, componentes, páginas y contenido en Markdown, pero no cubre cada integración, modo de renderizado avanzado ni arquitectura de proyectos grandes. Es la duración correcta para evaluar Astro y empezar un sitio pequeño, no para dominarlo.

## Qué aprenderás {#what-youll-learn}

Aprendes los bloques centrales de Astro: su sintaxis de componentes, cómo funcionan las páginas y el enrutamiento, y cómo trae contenido en Markdown a un sitio. El rasgo distintivo del framework, enviar casi nada de JavaScript del lado del cliente a menos que lo pidas, recorre todo el curso, así que ves por qué Astro se siente rápido y en qué se diferencia de un framework típico de aplicación de una sola página. Al final puedes armar un sitio de contenido y organizar páginas a la manera de Astro.

Como el curso es orientado a proyectos, construyes junto al instructor en el navegador en lugar de ver diapositivas, lo cual conviene cuando estás intentando agarrarle el ritmo a un framework nuevo.

## Para quién es, y quién puede saltárselo {#who-its-for-and-who-should-skip-it}

Encaja con desarrolladores frontend que ya saben HTML, CSS y algo de JavaScript y quieren una herramienta rápida y moderna para sitios de contenido. Es una buena opción para [marketers](/docs/for/marketers/) y desarrolladores que mantienen blogs o documentación.

Sáltatelo si nunca escribiste JavaScript ni construiste una página web, ya que el curso asume esas bases. Sáltatelo también si tu trabajo es desarrollo de apps muy interactivas, donde un framework como React es la herramienta principal más adecuada; Astro brilla para contenido, no para apps complejas del lado del cliente.

## Requisitos previos {#prerequisites}

Comodidad con HTML, CSS y JavaScript básico. Familiaridad con componentes de cualquier framework ayuda pero no es obligatoria. No se asume experiencia previa con Astro.

## Dónde encaja {#where-it-fits}

Este curso es un curso Pro independiente y no forma parte de una ruta con nombre propio, pero complementa las rutas de herramientas fullstack y frontend. Si ya conoces un framework de JavaScript, Astro es una adición útil para el lado de contenido de un stack.

## Fortalezas y límites {#strengths-and-limits}

Lo que hace bien: es una introducción concisa y práctica a un framework genuinamente útil, impartida por un instructor atractivo, y deja claro el modelo de Astro centrado en contenido y con poco JavaScript.

Dónde está limitado: es introductorio por diseño, así que no cubre integraciones avanzadas ni arquitectura de aplicaciones grandes, está detrás de Pro, y Astro en sí es una herramienta especializada, mejor adaptada a sitios de contenido que a cualquier proyecto.
