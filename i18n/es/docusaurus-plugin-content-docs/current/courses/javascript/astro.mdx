# Intro to Astro

Una introducción Pro a Astro, el framework diseñado para sitios rápidos y ricos en contenido, con James Q Quick durante aproximadamente dos horas de construcción práctica.

## Respuesta rápida {#quick-answer}

Este es el curso introductorio Pro de Scrimba para Astro, unas 2.1 horas con James Q Quick. Astro es un framework moderno pensado para sitios con mucho contenido, como blogs, documentación y páginas de marketing, donde combina componentes con Markdown y envía muy poco JavaScript por defecto. El curso te lleva a construir con el modelo de componentes de Astro y páginas de contenido rápidamente, sin asumir experiencia previa con Astro.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Si construyes o mantienes sitios de contenido, blogs, documentación o landing pages, Astro es una herramienta que conviene conocer ahora, y una introducción enfocada de dos horas es una forma sensata de saber si se ajusta a cómo trabajas. James Q Quick es un instructor energético y práctico, y el curso se mantiene práctico, así que terminas habiendo construido realmente con Astro, no solo haberlo escuchado.

La salvedad honesta es que es una introducción, no un curso profundo. Te pone cómodo con el modelo central, componentes, páginas y contenido Markdown, pero no cubrirá todas las integraciones, modos de renderizado avanzados, o arquitectura de proyectos grandes. Es la duración correcta para evaluar Astro e iniciar un sitio pequeño, no para dominarlo.

## Qué aprenderás {#what-youll-learn}

Aprenderás los componentes fundamentales de Astro: su sintaxis de componentes, cómo funcionan las páginas y el routing, y cómo incorpora contenido Markdown en un sitio. El rasgo definitorio del framework, enviar casi nada de JavaScript del lado del cliente a menos que lo pidas, atraviesa todo el curso, así que ves por qué Astro se siente rápido y en qué difiere de un framework típico de aplicación de una sola página. Al final puedes crear un sitio de contenido y diseñar páginas a la manera de Astro.

Como el curso está impulsado por proyectos, construyes junto al instructor en el navegador en lugar de ver diapositivas, lo cual funciona bien para un framework del que estás tratando de conseguir una sensación.

## Para quién es y quién debería saltarlo {#who-its-for-and-who-should-skip-it}

Funciona bien para desarrolladores frontend que ya conocen HTML, CSS y algo de JavaScript y quieren una herramienta rápida y moderna para sitios de contenido. Es un buen ajuste para [especialistas en marketing](/docs/for/marketers/) y desarrolladores que mantienen blogs o documentación.

Saltalo si nunca has escrito JavaScript o construido una página web, ya que el curso asume esos conceptos básicos. Saltalo también si tu trabajo es desarrollo intensivo de aplicaciones interactivas, donde un framework como React es la herramienta principal mejor; Astro destaca para contenido, no para aplicaciones del lado del cliente complejas.

## Requisitos previos {#prerequisites}

Comodidad con HTML, CSS, y JavaScript básico. Familiaridad con componentes de cualquier framework ayuda pero no es necesaria. No se asume experiencia previa con Astro.

## Dónde encaja {#where-it-fits}

Este curso es un curso Pro independiente en lugar de un miembro de ruta con nombre, pero complementa las pistas de tooling fullstack y frontend. Si ya conoces un framework JavaScript, Astro es una adición útil para el lado del contenido de un stack.

## Gratis o Pro {#free-or-pro}

Es un curso Pro, así que necesita una suscripción a Scrimba. Pro también cubre las rutas de carrera completas, los desafíos de codificación, Discord, y certificados. Ve a <AffiliateLink href="https://scrimba.com/our-pricing">planes actuales</AffiliateLink> para saber qué cuesta Pro en tu región.

## Fortalezas y límites {#strengths-and-limits}

Lo que hace bien: es una introducción concisa y práctica a un framework genuinamente útil, enseñado por un instructor atractivo, y aclara el modelo de contenido primero y bajo JavaScript de Astro.

Dónde está limitado: es introductorio por diseño, así que no cubre integraciones avanzadas ni arquitectura de aplicaciones grandes, está tras Pro, y el propio Astro es una herramienta especializada más adecuada para sitios de contenido que para cada proyecto.
