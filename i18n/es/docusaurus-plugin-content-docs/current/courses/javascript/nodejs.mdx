## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Para un desarrollador frontend, esta es la forma más económica de dejar de temerle al backend. Es gratis, y dedica su tiempo a lo que más rápido desmitifica el trabajo de servidor: construir una API REST real que responde a solicitudes. Una vez que hiciste eso, la idea de un servidor deja de ser abstracta.

La advertencia honesta es el alcance. Node es un runtime, no un currículo completo de backend, y este curso se mantiene cerca de los fundamentos. No cubre bases de datos, autenticación ni despliegue a fondo. Piénsalo como la base sobre la que construyes con [Learn Express.js](/docs/courses/javascript/expressjs/) y, más adelante, con material de bases de datos y autenticación, no como un curso independiente para "convertirte en ingeniero de backend".

El primer módulo es práctico desde el inicio: construyes una API REST, lo que obliga a que el ciclo de solicitud y respuesta cobre sentido de una forma que leer sobre el tema nunca logra. El segundo módulo, más largo, profundiza en el ruteo y las rutas, en cómo un servidor decide qué hacer según la URL y el método que recibe. Juntos cubren el modelo mental que reutilizas en cada framework de Node después.

## Para quién es, y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Le queda bien a desarrolladores de JavaScript, en especial a los de frontend, que quieren entender y construir el lado del servidor. Es el primer curso de backend indicado si ya conoces el lenguaje y quieres extenderlo más allá del navegador.

Sáltatelo, por ahora, si no has aprendido JavaScript. Haz primero [Learn JavaScript](/docs/courses/javascript/learn-javascript/). También sáltatelo si necesitas específicamente un curso de backend guiado por un framework y con todo incluido, en cuyo caso [Intro to NestJS](/docs/courses/javascript/nestjs/) es la opción más estructurada una vez que tengas las bases de aquí.

## Requisitos previos {#prerequisites}

JavaScript funcional: variables, funciones, objetos y código asíncrono, ya que los servidores son asíncronos por naturaleza. Tener soltura con el funcionamiento de las solicitudes HTTP ayuda, pero el curso construye esa intuición por ti. No se necesita experiencia previa en backend.

## Dónde encaja {#where-it-fits}

Learn Node.js es el ancla de backend en tres rutas: la [Frontend Developer Path](/docs/paths/frontend-developer-path/) (donde amplía las habilidades de un frontend), la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/), y la [Backend Developer Path](/docs/paths/backend-developer-path/), donde se ubica cerca del inicio.

## Fortalezas y límites {#strengths-and-limits}

Lo que hace bien: es gratis, está centrado en proyectos, y hace concreto el lado del servidor al hacerte construir una API real desde temprano. Tom Chant es un instructor claro y el formato interactivo le sienta sorprendentemente bien al trabajo de backend.

Dónde está limitado: se queda en los fundamentos, así que las bases de datos, la autenticación y el despliegue viven en otro lugar, y la ayuda rápida entre compañeros depende del Discord de Pro más que del nivel gratuito.
