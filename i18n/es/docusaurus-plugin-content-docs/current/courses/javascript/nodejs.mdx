# Learn Node.js

El curso gratuito de Node.js de Scrimba, impartido por Tom Chant durante aproximadamente 3.5 horas: dónde un desarrollador frontend comienza a construir el lado del servidor.

## Respuesta rápida {#quick-answer}

Learn Node.js es el curso gratuito de backend intermedio de Scrimba: aproximadamente 3.5 horas en dos módulos, impartido por Tom Chant. Construyes una API REST y trabajas con enrutamiento y rutas, que es el núcleo práctico de lo que un servidor Node realmente hace. Es el ancla backend en la pista de JavaScript de Scrimba y se empareja directamente con el curso de Express.js. Asume que ya puedes escribir JavaScript.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Para un desarrollador frontend, esta es la forma más económica de dejar de temer al backend. Es gratuito, y dedica su tiempo a lo que desmitifica el trabajo del servidor más rápido: construir una API REST real que responda a solicitudes. Una vez que lo hagas, la idea de un servidor deja de ser abstracta.

La salvedad honesta es el alcance. Node es un entorno de ejecución, no un currículum completo de backend, y este curso se mantiene cerca de los fundamentos. No cubre bases de datos, autenticación o despliegue en profundidad. Piensa en ello como la base que construyes encima con [Learn Express.js](/docs/courses/javascript/expressjs/) y, más tarde, material de base de datos y autenticación, no como un curso independiente "conviértete en ingeniero de backend".

El primer módulo es práctico desde el inicio: construyes una API REST, que obliga al ciclo de solicitud y respuesta a tener sentido de una forma que leer sobre ello nunca lo hace. El segundo módulo más largo profundiza en enrutamiento y rutas, cómo un servidor decide qué hacer según la URL y el método que recibe. En conjunto, cubren el modelo mental que reutilizas en cada framework de Node después.

## Para quién es, y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Se ajusta a desarrolladores de JavaScript, especialmente frontendistas, que quieren entender y construir el lado del servidor. Es el primer curso de backend correcto si ya conoces el lenguaje y quieres extenderlo más allá del navegador.

Saltátelo, por ahora, si no has aprendido JavaScript. Haz [Learn JavaScript](/docs/courses/javascript/learn-javascript/) primero. También saltátelo si específicamente necesitas un curso de backend impulsado por framework, lleno de características, en cuyo caso [Intro to NestJS](/docs/courses/javascript/nestjs/) es la opción más estructurada una vez que tengas los fundamentos aquí.

## Requisitos previos {#prerequisites}

JavaScript que funcione: variables, funciones, objetos y código asincrónico, ya que los servidores son asincronos por naturaleza. La comodidad con cómo funcionan las solicitudes HTTP ayuda, pero el curso construye esa intuición para ti. No se necesita experiencia previa de backend.

## Dónde encaja {#where-it-fits}

Learn Node.js es el ancla backend en tres rutas: la [Frontend Developer Path](/docs/paths/frontend-developer-path/) (dónde amplía un conjunto de habilidades frontend), la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/), y la [Backend Developer Path](/docs/paths/backend-developer-path/), dónde se sitúa cerca del inicio.

## Fortalezas y limitaciones {#strengths-and-limits}

Lo que hace bien: es gratuito, basado en proyectos, y hace el lado del servidor concreto al pedirte construir una API real temprano. Tom Chant es un instructor claro y el formato interactivo se ajusta sorprendentemente bien al trabajo de backend.

Dónde está limitado: se mantiene en los fundamentos, así que bases de datos, autenticación y despliegue viven en otro lugar, y la ayuda rápida de pares depende del Discord de Pro en lugar del nivel gratuito.
