## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Lo más valioso de este curso es el flujo de trabajo que enseña, no solo la sintaxis. Leer un archivo de Figma (espaciado, escala tipográfica, componentes) y reproducirlo con precisión en HTML y CSS es una habilidad que muchos desarrolladores simulan pero pocos dominan. Cinco proyectos de complejidad creciente ofrecen suficiente práctica para desarrollar esa destreza, y Gary Simon proviene de una sólida formación en diseño, así que la perspectiva que aporta es lo que realmente importa.

La salvedad honesta es que esto es solo HTML y CSS. No enseña JavaScript ni comportamiento interactivo; los sitios que construyes son diseños estáticos, aunque bien pulidos. Si buscas agregar interactividad o crear aplicaciones, este es un curso de estilos y diseño, y necesitarás JavaScript aparte. Evaluado como un curso de diseño a código, ese es el alcance correcto; solo entra sabiendo esto.

La estructura son cinco proyectos, cada uno una construcción completa que aumenta en dificultad. Comienzas con una tarjeta simple para aprender el flujo de trabajo, luego avanzas por una página de destino, un panel de análisis, un sitio de ventas y una página de destino de evento de drones más extensa que integra todo. Cada uno parte de una maqueta de Figma, así que el hilo conductor es convertir diseños en código: leer un diseño y reproducir su espaciado, tipografía y diseño en CSS limpio y receptivo.

## Para quién es, y para quién no {#who-its-for-and-who-should-skip-it}

Es para diseñadores que quieren aprender a programar, que ya piensan en términos de diseño y quieren desplegar su trabajo, y para desarrolladores frontend que desean convertir maquetas en código con mayor fidelidad. Consulta la [guía para diseñadores](/docs/for/designers/) para ver dónde encaja este curso en tu carrera como diseñador.

No es para ti si buscas JavaScript o interactividad; esto es solo HTML y CSS. Tampoco si eres un desarrollador frontend experimentado que ya dominas convertir diseños en código, porque los proyectos serían más repetición que crecimiento.

## Requisitos previos {#prerequisites}

Una comprensión básica de HTML y CSS es útil, aunque el curso avanza de forma gradual, y es práctica tener algo de familiaridad con Figma ya que trabajarás con maquetas durante todo el curso. No se requiere JavaScript.

## Dónde encaja {#where-it-fits}

Build Websites with Figma, HTML, and CSS se sitúa al inicio de la [Frontend Developer Path](/docs/paths/frontend-developer-path/) y la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/), en la fase de diseño y estilos antes de que JavaScript y los frameworks entren en escena.
