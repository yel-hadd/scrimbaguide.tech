# The Tricky Parts of JavaScript

Un curso Pro breve y enfocado de Zack Wilson sobre los conceptos de JavaScript que causan confusión: cierres, `this`, hoisting, y coerción de tipos, en menos de una hora.

## Respuesta rápida {#quick-answer}

The Tricky Parts of JavaScript es un curso de 59 minutos, nivel Pro, e intermedio enseñado por Zack Wilson (PortEXE). Se enfoca en los comportamientos del lenguaje que confunden a desarrolladores autodidactas, como cierres, la palabra clave `this`, hoisting, y coerción. Se utiliza mejor como un refuerzo enfocado después de un curso para principiantes, no como tu primer encuentro con JavaScript. Si esos cuatro temas te hacen sentir inseguro, esta es una hora eficiente.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Si puedes construir pequeñas aplicaciones de JavaScript pero aún te sorprende cuando `this` señala hacia un lugar inesperado o un cierre captura un valor que no esperabas, esta es una hora bien invertida. Es estrecho a propósito, y ese enfoque es el valor: sin relleno, solo los conceptos que causan bugs silenciosamente.

La salvedad honesta es que asume que ya conoces lo básico. No es un curso de enseñanza desde cero, y con 20 lecciones es un suplemento, no un currículo. Si nunca has escrito JavaScript, esto se sentirá como respuestas a preguntas que aún no has formulado.

## Qué aprenderás {#what-youll-learn}

El curso se construye como un conjunto de lecciones y desafíos enfocados alrededor de los mecanismos más incomprendidos de JavaScript. Espera cierres y alcance léxico, las reglas que deciden a qué se refiere `this`, hoisting de variables y funciones, y la coerción de tipos detrás de las comparaciones de igualdad sorprendentes de JavaScript. Cada uno es el tipo de tema que los cursos para principiantes pasan por alto y que los entrevistadores adoran investigar.

Debido a que es breve y orientado a conceptos, combina bien con práctica en otro lugar. Piénsalo como la capa de explicación que hace que tu JavaScript existente tenga sentido.

## Para quién es, y quién debe omitirlo {#who-its-for-and-who-should-skip-it}

Se ajusta a desarrolladores que han completado un curso para principiantes como [Learn JavaScript](/docs/courses/javascript/learn-javascript/) y siguen encontrando comportamientos confusos, o cualquiera que se esté preparando para entrevistas donde estos temas surgen constantemente.

Omítelo si eres completamente principiante; haz Learn JavaScript primero. También omítelo si quieres cobertura amplia en lugar de una corrección enfocada, donde [Advanced JavaScript](/docs/courses/javascript/advanced-javascript/) es el curso más completo.

## Requisitos previos {#prerequisites}

Conocimiento práctico de los fundamentos de JavaScript: variables, funciones, y alcance. No necesitas ser avanzado, pero debes haber escrito algo de JavaScript antes para que esto tenga sentido.
