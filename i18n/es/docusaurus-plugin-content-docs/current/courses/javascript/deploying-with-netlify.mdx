# Deploying with Netlify

Un recorrido corto y gratis para poner tus proyectos en línea con Netlify, impartido por Treasure Porth en unos 23 minutos.

## Respuesta rápida {#quick-answer}

Este es un curso gratis de Scrimba de 23 minutos impartido por Treasure Porth, y hace bien una sola cosa: muestra dos formas de desplegar un sitio en Netlify. La primera es arrastrar y soltar, la manera más rápida de poner un sitio estático en línea, y la segunda es conectar un repositorio de git para que los despliegues ocurran automáticamente cada vez que haces push. Es una habilidad práctica y enfocada, más cercana a un tutorial detallado que a un curso completo.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

El despliegue es una habilidad pequeña que muchos estudiantes convierten en algo intimidante, y 23 minutos gratis son el esfuerzo justo para volverla rutinaria. Poner un sitio real en línea por primera vez motiva de verdad, y los dos métodos aquí cubren los casos comunes: arrastrar y soltar para una subida estática rápida, y despliegues basados en git para cualquier cosa que sigas actualizando. Si ya construiste algo y no lo has publicado, esto elimina la excusa.

La advertencia honesta es que es corto por diseño. No es un curso sobre hosting, DNS, dominios personalizados, configuración de builds ni comparación de plataformas. Enseña específicamente el flujo de despliegue de Netlify, y lo enseña rápido. Ajusta tus expectativas a un cómo-hacerlo enfocado, no a una inmersión profunda.

## Qué vas a aprender {#what-youll-learn}

Aprendes dos flujos de despliegue. El método de arrastrar y soltar muestra cómo tomar una carpeta de archivos estáticos y ponerla en la web en segundos, ideal para un portafolio terminado o una landing page. El método basado en git conecta un repositorio para que cada push dispare un despliegue nuevo, que es como conviene trabajar en cualquier cosa que sigas modificando. Entre ambos, terminas sabiendo cuándo usar cada uno y cómo hacerlo sin fricción.

Por ser tan corto y práctico, es el tipo de contenido que puedes ver una vez y aplicar de inmediato a un proyecto que ya tienes pendiente.

## Para quién es, y quién puede saltárselo {#who-its-for-and-who-should-skip-it}

Le sirve a cualquiera que haya construido un sitio estático o un proyecto frontend y quiera ponerlo en línea sin lidiar con hosting. Encaja de forma natural con trabajos de portafolio y proyectos de HTML/CSS.

Sáltatelo si ya despliegas con git regularmente; no hay nada nuevo aquí para ti. Sáltatelo también si necesitas hosting del lado del servidor, despliegue backend o profundidad en infraestructura, ya que este curso trata específicamente el flujo de Netlify orientado a frontend.

## Requisitos previos {#prerequisites}

Un proyecto para desplegar y familiaridad básica con archivos y carpetas. Para el método basado en git, ayuda tener una comprensión básica de git y de los repositorios. No se requiere conocimiento de backend ni de DevOps.
