# Deploying with Netlify

Un recorrido corto y gratuito para poner tus proyectos en vivo en Netlify, impartido por Treasure Porth en aproximadamente 23 minutos.

## Respuesta rápida {#quick-answer}

Es un curso gratuito de Scrimba de 23 minutos impartido por Treasure Porth, y hace una cosa bien: muestra dos formas de desplegar un sitio en Netlify. La primera es arrastra y suelta, la forma más rápida de poner un sitio estático en línea, y la segunda es conectar un repositorio de git para que los despliegues ocurran automáticamente cuando hagas push. Es una habilidad práctica enfocada, más cercana a un tutorial completo que a un curso completo.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

El despliegue es una habilidad pequeña que los aprendices a menudo exageran haciéndola parecer aterradora, y 23 minutos gratis es la cantidad correcta de esfuerzo para hacerla rutinaria. Poner un sitio real en línea por primera vez es genuinamente motivador, y los dos métodos aquí cubren los casos comunes: arrastra y suelta para una carga rápida estática, y despliegues basados en git para cualquier cosa que sigas actualizando. Si has construido algo y no lo has desplegado, esto elimina la excusa.

La caveat honesta es que es corto por diseño. No es un curso sobre hosting, DNS, dominios personalizados, configuración de compilación, o comparación de plataformas. Enseña el flujo de despliegue de Netlify específicamente, y lo enseña rápidamente. Establece tus expectativas en un how-to enfocado en lugar de un análisis profundo.

## Qué aprenderás {#what-youll-learn}

Aprendes dos flujos de despliegue. El método arrastra y suelta muestra cómo tomar una carpeta de archivos estáticos y ponerla en vivo en la web en segundos, lo cual es ideal para un portafolio terminado o una página de inicio. El método basado en git conecta un repositorio para que cada push dispare un despliegue fresco, que es cómo quieres trabajar en cualquier cosa que sigas cambiando. Entre ambos adquieres conocimiento de cuándo usar cada uno y cómo hacer que cualquiera funcione sin fricción.

Porque es muy corto y práctico, es el tipo de cosa que puedes ver una vez y aplicar inmediatamente a un proyecto que ya tienes sin terminar.

## Para quién es, y quién debe omitirlo {#who-its-for-and-who-should-skip-it}

Se ajusta a cualquiera que haya construido un sitio estático o un proyecto frontend y lo quiera en línea sin luchar con hosting. Se empareja naturalmente con trabajo de portafolio y proyectos HTML/CSS.

Omítelo si ya desplegas vía git regularmente; no hay nada nuevo aquí para ti. Omítelo también si necesitas hosting del lado del servidor, despliegue backend, o profundidad de infraestructura, ya que esto es específicamente sobre el flujo amigable con el frontend de Netlify.

## Requisitos previos {#prerequisites}

Un proyecto para desplegar y familiaridad básica con archivos y carpetas. Para el método basado en git, una comprensión básica de git y un repositorio ayuda. No se requiere conocimiento de backend o DevOps.
