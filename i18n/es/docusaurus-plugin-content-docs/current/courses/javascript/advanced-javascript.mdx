## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Si terminaste un curso de JS para principiantes y sientes que puedes escribir código pero no lo entiendes del todo, este curso está pensado justo para esa brecha. El formato basado en retos hace que estés escribiendo código todo el tiempo en lugar de solo asentir con la cabeza, y los módulos de async y generadores en particular cubren terreno que los cursos para principiantes suelen apenas mencionar.

La advertencia honesta está en la etiqueta de nivel. Está marcado como Intermedio, pero la segunda mitad (objetos personalizados, colecciones y symbols, generadores) es genuinamente exigente, y el ritmo asume que ya dominas funciones, scope y métodos de arrays. Si tus fundamentos son débiles, te vas a atascar.

El recorrido avanza desde afianzar fundamentos y métodos hacia el material genuinamente avanzado. El módulo de Asynchronous JavaScript and APIs es el centro práctico, mientras que Creating Custom Objects, Collections and Symbols, y el módulo final de Generators son donde el curso se gana su nombre. Al terminar deberías entender las construcciones del lenguaje que antes solo copiabas.

## Para quién es, y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Es adecuado para desarrolladores que hayan completado [Learn JavaScript](/docs/courses/javascript/learn-javascript/) o tengan experiencia equivalente y quieran realmente entender el lenguaje en lugar de solo usarlo.

Sáltatelo si eres principiante absoluto; primero haz Learn JavaScript. También sáltatelo si solo necesitas un repaso rápido de un concepto puntual, donde el más breve [Tricky Parts of JavaScript](/docs/courses/javascript/tricky-parts-of-javascript/) es mejor opción.

## Requisitos previos {#prerequisites}

JavaScript funcional: variables, funciones, scope, métodos de arrays y una noción básica de código asíncrono. El curso construye directamente sobre eso y no se detiene a reenseñarlo. HTML y CSS ayudan para los ejercicios basados en APIs.

## Dónde encaja {#where-it-fits}

Advanced JavaScript se ubica a mitad de camino tanto en la [Frontend Developer Path](/docs/paths/frontend-developer-path/) como en la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/), después de los fundamentos de JavaScript y antes o en paralelo con el track de React.

## Gratis o Pro {#free-or-pro}

Este es un curso Pro, así que requiere una suscripción a Scrimba. Pro también cubre las rutas de carrera estructuradas, los retos de código, el Discord y los certificados. Consulta <AffiliateLink href="https://scrimba.com/our-pricing">los planes actuales</AffiliateLink> para ver cuánto cuesta Pro en tu región.

## Fortalezas y límites {#strengths-and-limits}

Lo que hace bien: profundidad real en async, objetos y generadores, un formato basado en retos que te mantiene escribiendo código, y un instructor claro en Tom Chant. Llena exactamente la brecha que la mayoría de los cursos para principiantes deja abierta.

Dónde tiene límites: la etiqueta Intermedio subestima lo exigentes que son los módulos finales, el desglose por módulo no publica el número de lecciones individuales, y como todos los cursos Pro, la ayuda rápida de otros estudiantes depende del Discord.
