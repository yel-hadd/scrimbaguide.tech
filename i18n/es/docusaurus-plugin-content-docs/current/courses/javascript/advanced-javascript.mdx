Advanced JavaScript es el curso JavaScript Pro intermedio-a-avanzado de Scrimba: aproximadamente 9.8 horas distribuidas en nueve módulos, impartido por Tom Chant. Cubre código asincrónico, internals de objetos, colecciones personalizadas y funciones generador, con muchos desafíos prácticos en lugar de solo ver videos. ## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Si terminaste un curso JavaScript para principiantes y sientes que puedes escribir código pero no lo entiendes completamente, este está diseñado exactamente para ese vacío. El formato enfocado en desafíos significa que estás escribiendo código constantemente en lugar de solo mirar, y los módulos de async y generadores en particular cubren terreno que los cursos para principiantes tienden a omitir.

La salvedad honesta es la etiqueta de nivel. Está marcado como Intermedio, pero la segunda mitad (objetos personalizados, colecciones, símbolos y generadores) es genuinamente exigente, y el ritmo asume que ya dominas funciones, scope y métodos de arrays. Si tus conceptos fundamentales son frágiles, te estancarás.

La progresión avanza desde solidificar fundamentos y métodos hacia el material genuinamente avanzado. El módulo JavaScript Asincrónico y APIs es la pieza práctica central, mientras que Creando Objetos Personalizados, Colecciones y Símbolos, y el módulo de Generadores al cierre son donde el curso se gana su nombre. Al final deberías entender las construcciones del lenguaje que antes solo copiabas.

## Para quién es, y quién debe saltarlo {#who-its-for-and-who-should-skip-it}

Se ajusta a desarrolladores que han completado [Learn JavaScript](/docs/courses/javascript/learn-javascript/) o tienen experiencia equivalente y quieren entender realmente el lenguaje en lugar de solo usarlo.

Sáltatelo si eres un principiante completo; haz Learn JavaScript primero. También sáltatelo si solo necesitas un repaso rápido de un concepto único, donde el más corto [Tricky Parts of JavaScript](/docs/courses/javascript/tricky-parts-of-javascript/) es mejor opción.

## Requisitos previos {#prerequisites}

JavaScript funcional: variables, funciones, scope, métodos de arrays y una comprensión básica de código asincrónico. El curso se construye directamente sobre eso y no hace pausas para re-enseñar. HTML y CSS ayudan para los ejercicios impulsados por API.

## Dónde encaja {#where-it-fits}

Advanced JavaScript se sitúa a mitad de camino en ambas la [Frontend Developer Path](/docs/paths/frontend-developer-path/) y la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/), después de los fundamentos de JavaScript y antes o junto con la pista de React.

## Gratis o Pro {#free-or-pro}

Este es un curso Pro, por lo que requiere una suscripción a Scrimba. Pro también cubre las rutas de carrera estructuradas, los desafíos de código, el Discord y certificados. Ver <AffiliateLink href="https://scrimba.com/our-pricing">planes actuales</AffiliateLink> para saber cuánto cuesta Pro en tu región.

## Fortalezas y limitaciones {#strengths-and-limits}

Lo que hace bien: profundidad real en async, objetos y generadores, un formato enfocado en desafíos que te mantiene escribiendo código, e instructor claro en Tom Chant. Llena el vacío exacto que la mayoría de cursos para principiantes dejan abierto.

Dónde es limitado: la etiqueta Intermedio no refleja cuan exigentes son los módulos posteriores, el desglose por módulo no publica recuentos de lecciones individuales, y como todos los cursos Pro, la ayuda rápida entre compañeros depende del Discord.
