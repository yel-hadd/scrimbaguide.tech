## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Si ya elegiste Vue, esta es una forma rápida y gratuita de aprender el modelo principal. El sistema de reactividad es la característica distintiva de Vue, y verlo actualizar la página mientras cambias el estado en el reproductor es exactamente el tipo de cosa que el formato interactivo hace bien. Con 1.6 horas, respeta tu tiempo y te pone a construir rápidamente.

La salvedad honesta es que es corto. Dos módulos y 1.6 horas te darán los fundamentos y una sensación del framework, pero no la profundidad en enrutamiento, gestión de estado a escala ni el ecosistema más amplio (Pinia, Vue Router) que utiliza una aplicación Vue real. Es un comienzo sólido, no una educación Vue completa.

## Para quién es y quién debería saltarlo {#who-its-for-and-who-should-skip-it}

Se ajusta a cualquiera que haya elegido Vue para un proyecto o trabajo, y desarrolladores curiosos sobre cómo Vue se compara con React en la práctica. El formato breve lo hace una forma de bajo costo de probar el framework antes de comprometerte.

Saltalo si aún no aprendiste JavaScript; haz [Learn JavaScript](/docs/courses/javascript/learn-javascript/) primero, ya que Vue lo asume. También saltalo si tu objetivo es React específicamente, en cuyo caso [Learn React](/docs/courses/react/learn-react/) es el curso a tomar. Aprender ambos a la vez tiende a confundir los dos.

## Requisitos previos {#prerequisites}

JavaScript funcional: variables, funciones, métodos de arrays y una comprensión básica del código asincrónico. La comodidad con HTML y CSS ayuda, ya que las plantillas Vue mezclan los tres. No se necesita experiencia previa con Vue u otro framework.

## Dónde encaja {#where-it-fits}

Learn Vue es un curso de framework independiente en lugar de un paso dentro de las rutas de carrera centradas en React de Scrimba. Trátalo como una materia optativa: tómalo cuando Vue es el framework que necesitas, independientemente de la [Frontend Developer Path](/docs/paths/frontend-developer-path/), que está construida alrededor de React.

## Gratuito o Pro {#free-or-pro}

El curso en sí es gratuito, sin suscripción requerida. Scrimba Pro es una decisión separada que desbloquea las rutas de carrera, desafíos de código, el Discord privado y certificados. ## Fortalezas y limitaciones {#strengths-and-limits}

Lo que hace bien: es gratuito, breve y basado en proyectos, y Rachel Johnson lo mantiene enfocado en el modelo de reactividad distintivo de Vue. Una introducción limpia para cualquiera que esté eligiendo el framework.

Dónde está limitado: el alcance de 1.6 horas se detiene en los fundamentos, así que enrutamiento, gestión de estado y el ecosistema más amplio no se cubren, y la ayuda rápida entre compañeros depende del Discord Pro en lugar del nivel gratuito.
