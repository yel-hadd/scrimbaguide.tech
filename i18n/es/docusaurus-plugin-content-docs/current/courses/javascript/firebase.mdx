# Learn Firebase

Un curso Pro sobre Firebase, el backend-as-a-service de Google, enseñado por Rafid Hoda, que muestra cómo construir apps reales con autenticación y una base de datos usando solo código frontend.

## Respuesta rápida {#quick-answer}

Este es el curso Pro de Firebase de Scrimba, de aproximadamente 3.4 horas enseñado por Rafid Hoda. Firebase es el backend-as-a-service de Google, y su atractivo es exactamente eso: obtienes autenticación y una base de datos real (Cloud Firestore) sin escribir ni alojar un backend, usando solo HTML, CSS y JavaScript. El curso se construye alrededor de esos dos pilares, autenticación y Firestore, y es una opción sólida para desarrolladores frontend que necesitan características de backend sin convertirse en desarrolladores backend.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Firebase resuelve muy bien un problema específico: tienes habilidades frontend y una idea de app que necesita inicios de sesión y datos almacenados, pero no quieres configurar ni mantener un servidor. Este curso satisface esa necesidad directamente. Rafid Hoda recorre Firebase auth y Cloud Firestore con la profundidad suficiente para que termines siendo capaz de construir una app real con datos desde código frontend solamente, lo cual es genuinamente empoderador si el trabajo backend ha sido una barrera para ti.

La cavedad honesta es que este es un curso de Firebase, y Firebase es una opción particular con compromisos particulares. Estás aprendiendo un servicio gestionado de Google y su modelo de datos, no principios transferibles como arquitectura de servidores, SQL, o cómo funcionan las solicitudes y el middleware. Esta es la herramienta correcta para algunos proyectos y un mal ajuste para otros, así que ten claro que estás aprendiendo Firebase específicamente en lugar de backend en general.

El curso consta de dos módulos enfocados. Authentication cubre registrar usuarios, conectarlos y gestionar la identidad a través de Firebase, que es la característica en la que más apps solo frontend se atascan. Cloud Firestore, el módulo más grande por mucho, es donde está la verdadera profundidad: modelar datos, leer y escribir documentos, y estructurar una base de datos NoSQL para que tu app pueda almacenar y recuperar contenido real. Juntos cubren las dos cosas que realmente necesitas para convertir un frontend estático en una app funcional.

## Para quién es, y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Es adecuado para desarrolladores frontend que conocen HTML, CSS y JavaScript y quieren lanzar apps con inicios de sesión y datos almacenados sin construir un backend. Es un miembro de ruta útil para la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/).

Sáltalo si tu objetivo es aprender principios de backend o frameworks del lado del servidor; Firebase los abstrae, así que [Learn Node.js](/docs/courses/javascript/nodejs/) y [Learn Express.js](/docs/courses/javascript/expressjs/) son la mejor ruta. Sáltalo también si aún no has aprendido JavaScript, ya que el curso lo presupone.

## Requisitos previos {#prerequisites}

HTML, CSS y JavaScript funcionales, incluyendo código asincrónico, ya que comunicarse con Firebase es asincrónico en toda la extensión. No se requiere experiencia en backend, servidor o bases de datos; ese es el punto del curso.

## Dónde encaja {#where-it-fits}

Learn Firebase se encuentra en la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/) como la forma de agregar características de backend sin un backend. Si más tarde deseas los principios de backend reales que Firebase oculta, [Learn Node.js](/docs/courses/javascript/nodejs/) y [Learn Express.js](/docs/courses/javascript/expressjs/) son la ruta complementaria.

## Fortalezas y limitaciones {#strengths-and-limits}

Qué hace bien: permite que los desarrolladores frontend lancen apps reales con datos rápidamente, profundiza en Firestore en lugar de simplemente esbozarlo, y elimina la barrera de backend que detiene muchos proyectos.

Dónde es limitado: enseña un servicio gestionado específico en lugar de principios de backend transferibles, el recuento de módulos publicados es pequeño (dos módulos), y está detrás de Pro.
