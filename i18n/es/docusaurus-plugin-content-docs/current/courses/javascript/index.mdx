# Cursos de JavaScript de Scrimba

JavaScript es la categoría más amplia en Scrimba. Incluye el lenguaje central, los frameworks y runtimes construidos sobre él, las herramientas que lo rodean, y preparación para carrera. Todos los cursos son interactivos, así que escribes código en la lección en lugar de solo ver.

## Dónde empezar {#where-to-start}

Comienza con el gratuito [Learn JavaScript](/docs/courses/javascript/learn-javascript) (9.4 hrs). Enseña el lenguaje a través de cuatro proyectos construidos en lugar de un solo capstone, lo que mantiene el ritmo alto. Es el ancla para el resto de esta categoría.

Junto con los cursos, Scrimba publica una <AffiliateLink href="https://docs.scrimba.com/javascript/introduction" location="companion-docs">referencia de JavaScript</AffiliateLink> gratuita escrita en su documentación. Se lee como un libro de texto para los scrims interactivos, con un selector de Principiante, Intermedio y Análisis Profundo que ajusta cuán profundo va cada tema, así que puedes buscar algo o revisitarlo a mayor profundidad conforme tu JavaScript madura.

## Cómo progresar {#how-to-progress}

Ejecuta [Learn JavaScript](/docs/courses/javascript/learn-javascript) primero, luego añade [Advanced JavaScript](/docs/courses/javascript/advanced-javascript) y [The Tricky Parts of JavaScript](/docs/courses/javascript/tricky-parts-of-javascript) para profundidad en el lenguaje. De ahí, ramifica por objetivo: [Learn Node.js](/docs/courses/javascript/nodejs) y [Learn Next.js](/docs/courses/javascript/nextjs) para el lado del runtime y framework, o [JavaScript Interview Challenges](/docs/courses/javascript/javascript-interview-challenges) cuando las entrevistas están cerca.

## Dónde encaja {#where-it-fits}

El [Frontend Developer Path](/docs/paths/frontend-developer-path) envuelve los cursos de JS central en una pista más larga, el [Fullstack Developer Path](/docs/paths/fullstack-developer-path) lo extiende con Node, Express y Next.js, y el [Backend Developer Path](/docs/paths/backend-developer-path) se enfoca en JavaScript asincrónico y servidores. Explora todos en el [hub de Rutas de Aprendizaje](/docs/paths/).
