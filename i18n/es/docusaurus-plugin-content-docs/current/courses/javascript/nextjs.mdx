# Learn Next.js

Curso gratis de Next.js de Scrimba, impartido por Bob Ziroll a lo largo de aproximadamente 8.5 horas: el framework más popular entre desarrolladores de React cuando una aplicación de página única ya no es suficiente. Un tercer módulo llegó en 2026 y casi duplicó su duración.

## Respuesta rápida {#quick-answer}

Learn Next.js es el curso gratuito e intermedio de Scrimba sobre Next.js, el framework fullstack de React más popular. Aproximadamente 8.5 horas en tres módulos, impartido por Bob Ziroll. Cubres enrutamiento basado en archivos, diseños compartidos, obtención de datos, las estrategias de renderizado (servidor, estático, cliente) que definen cómo se comporta una aplicación Next.js, y un tercer módulo sobre cómo mover datos a través de una aplicación con acciones del servidor y mutaciones. Asume que ya conoces React. Si es así, este es el próximo paso natural.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Es gratis e impartido por el mismo instructor que [Learn React](/docs/courses/react/learn-react/), así que el estilo y la notación se transfieren limpiamente. Para un desarrollador de React, esa continuidad importa: no estás reaprendiendo cómo funciona el reproductor o cómo piensa el instructor, solo agregando la capa del framework encima de lo que ya sabes.

La caveat honesta es que Next.js se mueve rápido como proyecto, y un curso grabado es una instantánea. Los conceptos de enrutamiento y renderizado aquí son duraderos, pero la superficie específica de la API alrededor del App Router y componentes de servidor cambia entre versiones. Trata esto como la base conceptual, luego consulta los documentos oficiales para la sintaxis exacta actual.

El primer módulo te pone a construir una aplicación funcional: enrutamiento, diseños, navegación y obtención de datos. El segundo es donde Next.js se gana su reputación, recorriendo las estrategias de renderizado que deciden si una página se genera en el servidor, se construye estáticamente o se hidrata en el cliente, y por qué esa elección afecta la velocidad y el SEO. Ese segundo módulo es la parte que no puedes obtener de un curso de React simple. El tercero, Making Data Flow, es el más grande con 3.9 horas y el más nuevo: cubre cómo mover datos a través de una aplicación Next.js con acciones del servidor y mutaciones, que es donde la mayoría de proyectos reales se atascan.

## Para quién es y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Se ajusta a desarrolladores de React que quieren lanzar aplicaciones reales, multipágina y amigables con el SEO en lugar de SPAs solo del cliente. Si has terminado un curso de React y sigues escuchando "simplemente usa Next.js", esto explica por qué.

Saltátelo si aún no has aprendido React. Next.js es un framework de React, no un punto de partida; haz [Learn React](/docs/courses/react/learn-react/) primero. También saltátelo si tu proyecto es un pequeño widget del lado del cliente que nunca necesita renderizado del servidor, porque el peso del framework no valdría la pena.

## Requisitos previos {#prerequisites}

React funcional: componentes, props, hooks y obtención de datos. Una comprensión básica de cómo funcionan las solicitudes HTTP y las URLs ayuda, ya que el enrutamiento y el renderizado del servidor se apoyan en ambos. Sin Next.js previo necesario.

## Fortalezas y límites {#strengths-and-limits}

Lo que hace bien: es gratis, está impartido por un instructor fuerte y familiar, y se enfoca en las dos cosas que realmente distinguen Next.js de React simple, enrutamiento y renderizado. El formato interactivo se adapta a un framework que aprendes construyendo.

Dónde es limitado: un framework que se mueve rápido significa que alguna sintaxis se desviará de la grabación, el alcance de dos módulos lo mantiene introductorio en lugar de exhaustivo, y la ayuda rápida entre pares depende del Discord de Pro.
