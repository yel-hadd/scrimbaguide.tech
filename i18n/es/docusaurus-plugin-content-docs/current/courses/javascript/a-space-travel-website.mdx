# Build a Multi-Page Website with HTML and CSS

Un curso gratis y guiado por un proyecto en el que Kevin Powell convierte un diseño de Frontend Mentor en un sitio web de viajes espaciales multipágina completo, construyendo un sistema de diseño reutilizable en el camino.

## Respuesta rápida {#quick-answer}

Este es el curso gratis e intermedio de HTML y CSS de Scrimba, impartido por Kevin Powell. A lo largo de unas 6.8 horas, tomas un diseño real de Frontend Mentor y lo construyes como un sitio multipágina, empezando por un sistema de diseño adecuado (propiedades personalizadas, escalas de tipografía y espaciado) antes de maquetar la página de inicio, la navegación, la página de destino y el contenido con pestañas. Aunque vive en la carpeta de JavaScript, es trabajo puro de maquetación frontend, no un curso de JavaScript.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Si sabes escribir HTML y CSS básico pero te bloqueas cuando te dan un diseño terminado y te piden construirlo, este curso es justo el puente que necesitas. Kevin Powell es uno de los profesores de CSS más respetados que hay, y lo destacable aquí es empezar desde un sistema de diseño en lugar de estilizar página por página. Aprendes a configurar tokens una vez y reutilizarlos, que es como los proyectos reales se mantienen manejables.

La advertencia honesta es que este es trabajo de un solo proyecto, centrado en maquetación. No tocarás JavaScript, interactividad más allá de CSS, ni ninguna herramienta de build. Si buscabas un panorama amplio de frontend, esto es más acotado a propósito; profundiza en traducir un diseño a CSS limpio y responsivo.

El orden es deliberado y el primer módulo es el más largo por una buena razón: pasas más de dos horas construyendo el sistema de diseño antes de maquetar una sola página. Una vez que esos tokens existen, la página de inicio, la navegación, la página de destino y la interfaz con pestañas se arman rápido porque las decisiones difíciles ya están tomadas. Esa secuencia es la verdadera lección, más que cualquier propiedad de CSS en particular.

## Para quién es, y quién debería saltárselo {#who-its-for-and-who-should-skip-it}

Le queda bien a cualquiera cómodo con los fundamentos de HTML y CSS que quiera practicar la construcción de una maquetación completa y multipágina a partir de un diseño profesional en lugar de partir de cero. Es una buena opción para desarrolladores autodidactas y para [diseñadores](/docs/for/designers/) que se mueven hacia el código.

Sáltatelo si todavía estás aprendiendo qué es un div o una clase; el ritmo asume que ya sabes leer CSS. Sáltatelo también si específicamente quieres JavaScript o interactividad, ya que este curso se queda en HTML y CSS todo el tiempo.

## Prerrequisitos {#prerequisites}

HTML y CSS básico: deberías conocer selectores, el box model y cómo aplicar estilos. Tener familiaridad con flexbox o grid ayuda pero no es estrictamente necesario, ya que el curso trabaja la maquetación sobre la marcha. No se necesita JavaScript.

## Dónde encaja {#where-it-fits}

Este curso es un proyecto independiente en lugar de parte de una ruta con nombre propio, pero combina naturalmente con trabajo de portafolio y despliegue. Un seguimiento sensato es [Build and Deploy Your Portfolio](/docs/courses/javascript/and-deploy-your-portfolio/), también impartido por Kevin Powell, que te lleva de construir un sitio a ponerlo en línea.

## Gratis o Pro {#free-or-pro}

El curso es gratis, sin necesidad de suscripción para empezarlo ni terminarlo. Scrimba Pro es una decisión aparte que desbloquea las rutas de carrera estructuradas, los desafíos de código y los certificados. Si solo quieres este proyecto, nunca tienes que pagar.

## Fortalezas y límites {#strengths-and-limits}

Lo que hace bien: es gratis, lo enseña una autoridad genuina de CSS, y está construido alrededor de un diseño real en lugar de un ejemplo de juguete. El enfoque de sistema de diseño primero es un hábito que vale la pena formar temprano.

Dónde está limitado: es un solo proyecto, así que las técnicas están atadas a esta maquetación particular, y no cubre JavaScript ni herramientas. La ayuda rápida entre compañeros depende del Discord de Pro más que del nivel gratis.
