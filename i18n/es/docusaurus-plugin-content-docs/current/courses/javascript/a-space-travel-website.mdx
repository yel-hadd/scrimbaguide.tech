# Build a Multi-Page Website with HTML and CSS

Un curso gratuito dirigido por proyectos en el que Kevin Powell convierte un diseño de Frontend Mentor en un sitio web completo multipágina de viajes espaciales, construyendo un sistema de diseño reutilizable en el camino.

## Respuesta rápida {#quick-answer}

Es el curso gratuito e intermedio de HTML y CSS de Scrimba, impartido por Kevin Powell. Durante aproximadamente 6.8 horas, tomas un diseño real de Frontend Mentor y lo construyes en un sitio multipágina, comenzando con un sistema de diseño apropiado (propiedades personalizadas, escalas de tipo y espaciado) antes de diseñar la página de inicio, navegación, página de destino y contenido con pestañas. A pesar de estar en la carpeta de JavaScript, es trabajo puro de diseño frontend, no un curso de JavaScript.

## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Si puedes escribir HTML y CSS básico pero te quedas paralizado cuando te entregan un diseño terminado y te dicen que lo construyas, este curso es exactamente el puente que necesitas. Kevin Powell es uno de los maestros de CSS más respetados, y la opción destacada aquí es comenzar con un sistema de diseño en lugar de estilizar página por página. Aprendes a establecer fichas una sola vez y reutilizarlas, que es cómo los proyectos reales se mantienen mantenibles.

La salvedad honesta es que este es trabajo enfocado en un solo proyecto y diseño. No tocarás JavaScript, interactividad más allá de CSS, ni ninguna herramienta de construcción. Si querías una encuesta amplia de frontend, esto es deliberadamente más estrecho; profundiza en traducir un diseño en CSS limpio y receptivo.

El orden es deliberado y el primer módulo es el más grande por una razón: pasas más de dos horas construyendo el sistema de diseño antes de diseñar una sola página. Una vez que existen esas fichas, la página de inicio, navegación, página de destino e interfaz con pestañas se unen rápidamente porque las decisiones difíciles ya se han tomado. Esa secuencia es la lección real, más que cualquier propiedad de CSS individual.

## Para quién es, y quién debería evitarlo {#who-its-for-and-who-should-skip-it}

Se ajusta a cualquiera cómodo con lo básico de HTML y CSS que quiera practicar construir un diseño completo y multipágina a partir de un diseño profesional en lugar de desde cero. Es un ajuste fuerte para desarrolladores autodidactas y para [diseñadores](/docs/for/designers/) moviéndose hacia código.

Évitalo si aún estás aprendiendo qué es un div o una clase; el ritmo asume que ya puedes leer CSS. Evítalo también si específicamente quieres JavaScript o interactividad, ya que este curso permanece en HTML y CSS todo el tiempo.

## Requisitos previos {#prerequisites}

HTML y CSS básicos: debes conocer selectores, el modelo de caja y cómo aplicar estilos. La familiaridad con flexbox o grid ayuda pero no es estrictamente requerida, ya que el curso avanza a través del diseño. No se necesita JavaScript.

## Dónde encaja {#where-it-fits}

Este curso es un proyecto independiente en lugar de ser parte de una ruta nombrada, pero se empareja naturalmente con trabajo de portafolio e implementación. Un seguimiento sensato es [Build and Deploy Your Portfolio](/docs/courses/javascript/and-deploy-your-portfolio/), también impartido por Kevin Powell, que te lleva desde construir un sitio hasta ponerlo en línea.

## Gratuito o Pro {#free-or-pro}

El curso es gratuito, sin suscripción necesaria para comenzar o terminar. Scrimba Pro es una decisión separada que desbloquea las rutas de carrera estructuradas, desafíos de codificación y certificados. Si solo quieres este proyecto, nunca tienes que pagar.

## Fortalezas y limitaciones {#strengths-and-limits}

Lo que hace bien: es gratuito, impartido por una autoridad genuina en CSS, y construido alrededor de un diseño real en lugar de un ejemplo de juguete. El enfoque sistema-de-diseño-primero es un hábito que vale la pena formar temprano.

Dónde es limitado: es un proyecto, por lo que las técnicas están vinculadas a este diseño particular, y no cubre JavaScript ni herramientas. La ayuda rápida de pares depende del Discord Pro en lugar del nivel gratuito.
