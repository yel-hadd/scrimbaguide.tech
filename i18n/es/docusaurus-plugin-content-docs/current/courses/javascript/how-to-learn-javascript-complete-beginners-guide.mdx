# Learn JavaScript: guía práctica para principiantes

JavaScript está detrás de cada sitio web que usas. Es el lenguaje del navegador y, mediante Node.js, también ejecuta servidores, así que es uno de los pocos lenguajes con los que puedes avanzar desde tu primer "Hola, mundo" hasta trabajo fullstack sin cambiar de herramienta. Esta es una guía breve y directa para ir de cero a comodidad, con un orden lógico y expectativas realistas.

## Por dónde empezar {#where-to-start}

Comienza gratis, y comienza con los fundamentos. [Learn JavaScript](/docs/courses/javascript/learn-javascript/) de Scrimba es el punto de partida natural: es el curso gratuito orientado a principiantes en el catálogo, y su formato interactivo (editas el código del instructor en el navegador) se adapta mejor a un primer lenguaje que solo ver videos. Aprende lo básico (variables, funciones, arrays, objetos, loops) practicando antes de pasar a cosas más complejas.

Resiste la tentación de empezar con un framework. React, Vue y el resto son JavaScript con estructura adicional; aprenderlos antes del lenguaje base es la forma más común en que los principiantes se quedan estancados.

## Un orden sensato {#a-sensible-order}

Una progresión que funciona para la mayoría:

1. [Learn JavaScript](/docs/courses/javascript/learn-javascript/) para los fundamentos.
2. The Tricky Parts of JavaScript, para solidificar los conceptos que atrapan a los principiantes (scope, closures, `this`, código asincrónico).
3. [Advanced JavaScript](/docs/courses/javascript/advanced-javascript/), para dominar el lenguaje completamente.
4. Un framework una vez que el lenguaje sea sólido, más comúnmente [Learn React](/docs/courses/react/learn-react/), o [Learn Vue](/docs/courses/javascript/vue/) si Vue se ajusta mejor a tus objetivos.

El orden importa más que la velocidad. Cada paso asume el anterior, y saltarse niveles solo traslada la confusión más adelante.

## Cuánto tiempo tarda {#how-long-it-takes}

No hay un número honesto único, pero una progresión realista: algunas semanas de práctica consistente para sentirte cómodo con los fundamentos, y algunos meses para llegar al punto donde puedas construir proyectos pequeños por ti mismo y empezar un framework. Estudiar diariamente, aunque sea brevemente, supera los atracones de fin de semana. El formato interactivo de código ayuda aquí porque estás practicando, no solo absorbiendo.

Ten cuidado con las promesas "aprende JavaScript en X días". Puedes aprender la sintaxis rápidamente; construir fluidez real toma repetición en proyectos auténticos.

## Errores comunes {#common-mistakes}

Algunos patrones que ralentizan a los principiantes:

- Saltarse a un framework antes de que el lenguaje sea sólido. Construye los fundamentos primero.
- Ver sin escribir código. Los tutoriales se sienten productivos pero la habilidad viene de escribir, romper y arreglar.
- Cambiar de tutoriales para siempre. En algún momento tienes que construir algo sin guía; es ahí donde el aprendizaje se consolida.
- Saltarse las "partes tricky" (closures, `this`, async). Se sienten opcionales hasta que te bloquean, entonces lo bloquean todo.
- Comparar tu semana uno con el año tres de alguien. La consistencia supera la intensidad.
