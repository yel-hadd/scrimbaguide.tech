## ¿Vale la pena tu tiempo? {#is-it-worth-your-time}

Es gratis, lo imparte Bob Ziroll (cuyos cursos de React están entre los más fuertes de Scrimba), y hace algo que muchos cursos de TypeScript evitan: muestra el lenguaje en frameworks reales, no solo en ejemplos aislados de tipos. Ver TS tanto en React como en Express significa que te vas con una sensación de cómo el tipado realmente cambia tu código día a día, que es la parte que hace que se pegue.

La advertencia honesta es el prerequisito. Esto es genuinamente intermedio y se apoya mucho en conocimiento previo de JavaScript. Si tu JavaScript es débil, el sistema de tipos se sentirá como reglas extra sobre un lenguaje que aún estás aprendiendo. Los módulos de React y Express también asumen cierta familiaridad con esas herramientas, así que la segunda mitad es más suave si las has tocado antes.

## Para quién es, y quién debe saltárselo {#who-its-for-and-who-should-skip-it}

Se ajusta a desarrolladores que ya escriben JavaScript cómodamente y quieren añadir tipos, especialmente cualquiera que trabaje en React o construya APIs con Express. Porque cubre TypeScript tanto en frontend como en backend, se ajusta particularmente bien a aprendices fullstack.

Saltátelo por ahora si tu JavaScript no es sólido. Primero haz [Learn JavaScript](/docs/courses/javascript/learn-javascript/) y vuelve. Saltátelo también si solo quieres teoría pura del lenguaje sin contexto de framework, ya que una buena parte de este curso es deliberadamente aplicada.

## Prerequisitos {#prerequisites}

JavaScript sólido es el verdadero prerequisito: variables, funciones, objetos, métodos de arrays y código asincrónico. Algo de exposición a React y Express ayuda para los módulos posteriores pero no es estrictamente requerido para los fundamentos.

## Dónde encaja {#where-it-fits}

Learn TypeScript está en la [Frontend Developer Path](/docs/paths/frontend-developer-path/), la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/) y la [Backend Developer Path](/docs/paths/backend-developer-path/) como la capa de tipado sobre JavaScript. Se empareja naturalmente con [Learn React](/docs/courses/react/learn-react/), ya que los props tipados y los hooks se construyen directamente sobre ese conocimiento, y complementa el trabajo backend donde las APIs Express tipadas son comunes.

## Fortalezas y límites {#strengths-and-limits}

Lo que hace bien: es gratis, lo imparte un instructor fuerte y ancla TypeScript en código React y Express real más que en acertijos de tipos abstractos. El formato interactivo te permite arreglar errores de tipos conforme avanzas.

Dónde es limitado: el ritmo intermedio es implacable si tu JavaScript es débil, y los módulos de React y Express son cortos, así que introducen el tipado en esas herramientas más que enseñar las herramientas mismas. Trae algo de exposición previa a frameworks para el recorrido más suave.
