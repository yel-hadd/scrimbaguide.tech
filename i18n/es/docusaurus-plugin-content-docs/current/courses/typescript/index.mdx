# Cursos de TypeScript en Scrimba

Scrimba trata TypeScript como una capa sobre el JavaScript que ya escribes, no como un reinicio en otro lenguaje. El catálogo es un curso gratis y enfocado, ligado a los stacks de React y Node que los equipos realmente usan en producción.

## Por dónde empezar {#where-to-start}

Hay un solo curso aquí: el gratis [Learn TypeScript](/docs/courses/typescript/learn-typescript/) (4.2 h). Cubre los fundamentos de tipos, TypeScript en React y TypeScript en Express, además de un proyecto práctico. Asume que ya sabes JavaScript, así que haz un curso de JS primero si no es tu caso.

## Todos los cursos de TypeScript {#all-typescript-courses}

| Curso | Nivel | Acceso | Duración |
|---|---|---|---|
| [Learn TypeScript](/docs/courses/typescript/learn-typescript/) | Intermedio | Gratis | 4.2 h |

## Cómo avanzar {#how-to-progress}

El prerrequisito es JavaScript: haz [Learn JavaScript](/docs/courses/javascript/learn-javascript/) primero si no lo has hecho, y luego [Learn TypeScript](/docs/courses/typescript/learn-typescript/) para sumar tipos, refactors más seguros y la habilidad que piden la mayoría de las vacantes de React y Node. Después, aplícalo en los cursos de framework de los hubs de [React](/docs/courses/react/) y [backend](/docs/courses/backend/).

## Dónde encaja {#where-it-fits}

Los módulos de TypeScript aparecen dentro de la [Frontend Developer Path](/docs/paths/frontend-developer-path/), la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/) y la [Backend Developer Path](/docs/paths/backend-developer-path/), lo que refleja la realidad de contratación. Explora todas las rutas en el [hub de Learning Paths](/docs/paths/).
