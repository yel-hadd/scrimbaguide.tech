# Cursos de TypeScript de Scrimba

Scrimba trata TypeScript como una capa sobre el JavaScript que ya escribes, no como un reinicio de lenguaje separado. El catálogo tiene un curso único y enfocado, gratuito, vinculado a los stacks de React y Node que realmente usan los equipos.

## Dónde comenzar {#where-to-start}

Hay un curso aquí: el gratuito [Learn TypeScript](/docs/courses/typescript/learn-typescript/) (4.2 horas). Cubre fundamentos de tipos, TypeScript en React y TypeScript en Express, además de un proyecto práctico. Asume que ya sabes JavaScript, así que aprende JavaScript primero si aún no lo has hecho.

## Todos los cursos de TypeScript {#all-typescript-courses}

| Curso | Nivel | Acceso | Duración |
|---|---|---|---|
| [Learn TypeScript](/docs/courses/typescript/learn-typescript/) | Intermedio | Gratuito | 4.2 horas |

## Cómo avanzar {#how-to-progress}

El requisito previo es JavaScript: aprende [Learn JavaScript](/docs/courses/javascript/learn-javascript/) primero si aún no lo has hecho, luego [Learn TypeScript](/docs/courses/typescript/learn-typescript/) para agregar tipos, refactoraciones más seguras y la habilidad que la mayoría de publicaciones de trabajos de React y Node piden. Después, aplícalo en los cursos de framework en los hubs de [React](/docs/courses/react/) y [backend](/docs/courses/backend/).

## Dónde encaja {#where-it-fits}

Los módulos de TypeScript aparecen dentro de la [Frontend Developer Path](/docs/paths/frontend-developer-path/), la [Fullstack Developer Path](/docs/paths/fullstack-developer-path/) y la [Backend Developer Path](/docs/paths/backend-developer-path/), lo que refleja la realidad de contratación. Explora cada ruta en el hub de [Learning Paths](/docs/paths/).
