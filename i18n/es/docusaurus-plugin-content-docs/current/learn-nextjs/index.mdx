# Ruta de aprendizaje de Next.js

Este hub vincula la [documentación oficial de Next.js](https://nextjs.org/docs) con el curso gratuito App Router de Scrimba, cubriendo configuración, enrutamiento, Server vs Client Components, obtención de datos, UI de carga y Server Actions, para que cada concepto que lees tenga un equivalente interactivo de escribir-en-el-navegador.

## Quién es esto para {#who-this-is-for}

Desarrolladores de React que pueden construir SPAs pero se pierden cuando aparecen `app/`, Server Components y `loading.tsx`, y cualquiera en la [ruta Fullstack](/docs/paths/fullstack-developer-path/) que quiera aprender Next de forma práctica.

## 2. Enruta y navega como Next lo espera {#2-route-and-navigate-like-next-expects}

**Objetivo:** Mapea carpetas a URLs, comparte diseños y añade segmentos dinámicos.

Next.js utiliza un **enrutador basado en el sistema de archivos**. Las carpetas definen las rutas.

- **Vinculación:** componente `Link` para navegación del lado del cliente.
    - _Cubierto en el curso de Scrimba: The Link Component_
- **Rutas dinámicas:** `[slug]/page.js` para contenido dinámico.
    - _Cubierto en el curso de Scrimba: Dynamic Routes_

## 3. Elige entre Server y Client Components a propósito {#3-pick-server-vs-client-components-on-purpose}

**Objetivo:** Deja de enviar bundles JS gigantes cuando HTML sería suficiente.

| Tipo | Cuándo usar | En el curso de Scrimba |
|---|---|---|
| **Server Components** | Obtención de datos, llamadas a base de datos, lógica sensible. (Predeterminado) | Server Components |
| **Client Components** | Interactividad, `onClick`, `useState`, `useEffect`. | Client Components |

## 4. Obtén y transmite datos sin spinners por todos lados {#4-fetch-and-stream-data-without-spinners-everywhere}

**Objetivo:** Permite que Server Components gestionen lecturas; usa Suspense + `loading.tsx` para UX.

En el App Router, puedes obtener datos directamente en tus Server Components usando `async/await`.

- **Obtención de datos:** `const data = await fetch(...)`
    - _Cubierto en el curso de Scrimba: Fetching Data_
- **UI de carga:** `loading.js` para estados de carga instantáneos.
    - _Cubierto en el curso de Scrimba: Loading UI_

## 5. Muta con Server Actions (salta APIs estándar) {#5-mutate-with-server-actions-skip-boilerplate-apis}

**Objetivo:** Envía formularios directamente a funciones de servidor cuando se adapta a tu aplicación.

En lugar de escribir un endpoint de API separado (`/api/submit`), escribes una función que se ejecuta en el servidor y la llamas directamente desde tu formulario.
