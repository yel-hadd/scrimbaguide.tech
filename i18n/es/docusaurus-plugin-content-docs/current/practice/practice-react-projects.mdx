# Proyectos prácticos de React

Cursos de Scrimba recomendados para practicar este tema. Incluye formato interactivo.

Los tutoriales enseñan conceptos. Los proyectos enseñan a construir cosas de verdad. La mejor forma de demostrarle tus habilidades de React a un empleador es con un portafolio de aplicaciones reales y funcionales. Los cursos de Scrimba incluyen proyectos capstone que se construyen desde cero.

## Para quién es esto {#who-this-is-for}

Desarrolladores que quieren práctica directa con este tema.


## Proyectos destacados de React en Scrimba {#featured-react-projects-on-scrimba}

### Tenzies (curso Learn React) {#tenzies-learn-react-course}
**Dificultad**: Principiante-Intermedio | **Qué construyes**: Un juego de dados

Construye un juego completo donde los jugadores lanzan dados para igualar todos los valores. Cubre: `useState`, `useEffect`, renderizado condicional, manejadores de eventos y estilos CSS. Este proyecto enseña cómo interactúan los componentes de React en una aplicación real.

[Empieza el curso Learn React](/docs/courses/react/learn-react) (Gratis)

### Assembly: Endgame (curso Learn React) {#assembly-endgame-learn-react-course}
**Dificultad**: Intermedio | **Qué construyes**: Un juego de adivinar palabras

Construye un juego estilo ahorcado con lenguajes de programación como temática. Cubre: composición de componentes, manejo de estado entre varios componentes y renderizado dinámico de clases. Más complejo que Tenzies, ideal para subir de nivel.

[Empieza el curso Learn React](/docs/courses/react/learn-react) (Gratis)

### Movie Search App (tutorial de búsqueda en React) {#movie-search-app-react-search-tutorial}
**Dificultad**: Intermedio | **Qué construyes**: Un buscador de base de datos de películas

Construye una app que consulta la API de OMDB, muestra resultados en una cuadrícula responsiva y maneja estados de carga y error. Cubre: integración de API, `useEffect` para obtención de datos, y debounce de búsqueda.

[Empieza el curso Movie Search](/docs/courses/react/a-react-project-movie-search-app)

### Advanced React Projects {#advanced-react-projects}
**Dificultad**: Avanzado | **Qué construyes**: Varias apps de calidad de producción

El curso Advanced React (18.8 h) incluye proyectos sobre: componentes compuestos, render props, hooks personalizados, optimización de rendimiento y patrones de context API.

[Empieza el curso Advanced React](/docs/courses/react/advanced-react) (Pro)

## Cómo aprovechar al máximo el aprendizaje basado en proyectos {#how-to-get-the-most-from-project-based-learning}

1. **Construye primero, mira después**, intenta implementar cada función tú mismo antes de ver la solución
2. **Extiende el proyecto**, agrega funciones que el instructor no cubre (modo oscuro, almacenamiento local, animaciones)
3. **Despliégalo**, sube tus proyectos a Netlify o Vercel y agrégalos a tu portafolio
4. **Escribe sobre eso**, un artículo explicando qué construiste y qué aprendiste impresiona a quienes contratan

## Checklist de portafolio para desarrolladores React {#portfolio-checklist-for-react-developers}

Un portafolio sólido de React debería incluir:

- [ ] **Una app CRUD** (crear, leer, actualizar, eliminar), demuestra que puedes construir lógica de negocio
- [ ] **Una app con API**, demuestra que puedes integrar datos externos
- [ ] **Un juego o herramienta interactiva**, demuestra creatividad y manejo de estado
- [ ] **Un proyecto con buen estilo**, demuestra que te importa el diseño y la experiencia de usuario

Los cursos de React de Scrimba, en conjunto, cubren las cuatro categorías.
