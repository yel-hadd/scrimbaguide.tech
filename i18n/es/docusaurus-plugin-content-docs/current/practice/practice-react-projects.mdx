# Proyectos de práctica con React

Cursos recomendados de Scrimba para practicar este tema. Formato interactivo incluido.

Los tutoriales enseñan conceptos. Los proyectos te enseñan cómo construir cosas realmente. La mejor manera de demostrar tus habilidades con React a los empleadores es con un portafolio de aplicaciones reales y funcionales. Los cursos de Scrimba incluyen proyectos capstone que construyes desde cero.

## Para quién es esto {#who-this-is-for}

Desarrolladores que quieren práctica práctica con este tema.


## Proyectos destacados de React en Scrimba {#featured-react-projects-on-scrimba}

### Tenzies (Learn React Course) {#tenzies-learn-react-course}
**Dificultad**: Principiante-Intermedio | **Lo que construyes**: Un juego de dados

Construye un juego completo donde los jugadores lanzan dados para hacer coincidir todos los valores. Cubre: `useState`, `useEffect`, renderizado condicional, manejadores de eventos y estilos CSS. Este proyecto te enseña cómo interactúan los componentes de React en una aplicación real.

[Comienza el curso Learn React](/docs/courses/react/learn-react) (Gratis)

### Assembly: Endgame (Learn React Course) {#assembly-endgame-learn-react-course}
**Dificultad**: Intermedio | **Lo que construyes**: Un juego de adivinanzas de palabras

Construye un juego estilo ahorcado con lenguajes de programación como tema. Cubre: composición de componentes, gestión de estado en múltiples componentes y renderizado de clases dinámicas. Más complejo que Tenzies, excelente para mejorar.

[Comienza el curso Learn React](/docs/courses/react/learn-react) (Gratis)

### Movie Search App (React Search Tutorial) {#movie-search-app-react-search-tutorial}
**Dificultad**: Intermedio | **Lo que construyes**: Una búsqueda de base de datos de películas

Construye una app que consulta la API de OMDB, muestra resultados en una cuadrícula receptiva y maneja estados de carga y error. Cubre: integración de API, `useEffect` para obtención de datos y debouncing de búsqueda.

[Comienza el curso Movie Search](/docs/courses/react/a-react-project-movie-search-app)

### Advanced React Projects {#advanced-react-projects}
**Dificultad**: Avanzado | **Lo que construyes**: Múltiples apps de calidad producción

El curso Advanced React (18.8 hrs) incluye proyectos que cubren: componentes compuestos, render props, hooks personalizados, optimización de rendimiento y patrones de Context API.

[Comienza el curso Advanced React](/docs/courses/react/advanced-react) (Pro)

## Cómo aprovechar al máximo el aprendizaje basado en proyectos {#how-to-get-the-most-from-project-based-learning}

1. **Construye primero, mira después**, intenta implementar cada función antes de ver la solución
2. **Amplía el proyecto**, agrega funciones que el instructor no cubre (modo oscuro, almacenamiento local, animaciones)
3. **Despliégalo**, coloca tus proyectos en Netlify o Vercel y agrégalos a tu portafolio
4. **Escribe sobre él**, una publicación de blog explicando qué construiste y qué aprendiste impresiona a los gerentes de contratación

## Lista de verificación de portafolio para desarrolladores de React {#portfolio-checklist-for-react-developers}

Un portafolio fuerte de React debe incluir:

- [ ] **Una app CRUD** (crear, leer, actualizar, eliminar), muestra que puedes construir lógica empresarial
- [ ] **Una app impulsada por API**, muestra que puedes integrar datos externos
- [ ] **Un juego o herramienta interactiva**, muestra creatividad y habilidades de gestión de estado
- [ ] **Un proyecto con estilos**, muestra que te importa el diseño y la experiencia del usuario

Los cursos de React de Scrimba en conjunto cubren las cuatro categorías.
