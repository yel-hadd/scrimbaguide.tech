# Crea una aplicación de clima en React

Construye una **interfaz real de clima** en Scrimba con **geolocalización, `fetch` estilo OpenWeather, estado para carga/errores y estilos dinámicos**, escribiendo código en el mismo reproductor que el instructor. Es el patrón de portafolio que reconocen los reclutadores.

Uno de los proyectos de portafolio React más solicitados es la clásica **aplicación de clima**. ¿Por qué? Porque demuestra que entiendes tres habilidades críticas:

1. **Obtener datos externos** (trabajar con APIs REST reales).
2. **Gestionar estado complejo** (almacenar coordenadas geográficas, temperaturas y estados de error).
3. **Renderizado dinámico de UI** (cambiar fondos según lluvia, sol o nieve).

Pero leer un tutorial no es suficiente para aprender estos conceptos. Necesitas escribir el código tú mismo.

## El problema con los tutoriales en video {#the-problem-with-video-tutorials}

Cuando ves un tutorial de YouTube sobre "Cómo construir una aplicación de clima React", caes en la **ilusión del tutorial**. Entiendes lo que escribe el instructor, pero cuando abres un editor VS Code vacío al día siguiente, tu mente se queda en blanco.

### La solución interactiva {#the-interactive-solution}

En Scrimba, no solo ves videos. El video *es* el editor de código. Cuando el instructor dice, "Okay, ahora escribamos la llamada `fetch()` a la API de OpenWeather", el video se pausa, y **escribes el código directamente en el reproductor**. 

Si te atascas, presionas reproducir, y el instructor escribe la solución EXACTA en las líneas de código exactas que acabas de ver.

## Conceptos clave que dominarás {#key-concepts-you-will-master}

### 1. El gancho `useEffect` para obtener datos {#1-the-useeffect-hook-for-data-fetching}
Aprenderás cómo desencadenar llamadas a la API apenas tu componente se monta sin causar bucles infinitos de re-renderizado.

### 2. El gancho `useState` para actualizar la UI {#2-the-usestate-hook-for-ui-updates}
Gestionarás múltiples piezas de estado:
- `city` (string)
- `weatherData` (object)
- `isLoading` (boolean)
- `error` (string)

### 3. Renderizado condicional {#3-conditional-rendering}
Si la API devuelve "clouds", renderizas el icono de nube. Si `isLoading` es true, muestras un spinner. Así es como se construyen las aplicaciones frontend profesionales.
