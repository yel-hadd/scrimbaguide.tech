# Practica CSS Grid

La pista de **CSS Grid** de Scrimba (más ejercicios de UI/CSS de soporte) te hace **colocar áreas, espacios y breakpoints en el reproductor del navegador**, de modo que `fr`, `minmax` y `grid-template-areas` se te queden porque los usaste, no porque hayas resaltado una entrada de blog.

## Para quién es esto {#who-this-is-for}

Desarrolladores que recurren a Flexbox para layouts bidimensionales y quieren crear secciones de marketing o dashboards de **nivel profesional**.


## ¿Por qué practicar CSS Grid en Scrimba? {#why-practice-css-grid-on-scrimba}

Leer documentación es pasivo. Para dominar **CSS Grid**, necesitas escribir código. El formato interactivo de Scrimba te permite:

1. **Pausar el video** en cualquier momento
2. **Editar el código** directamente en el reproductor
3. **Ejecutarlo** para ver tus cambios al instante

## Cómo practicar de manera efectiva {#how-to-practice-effectively}

1. **No solo mires**. Siempre que el instructor escriba código, pausa y reescribe el código tú mismo.
2. **Experimenta**. Cambia valores, borra líneas y mira qué sucede.
3. **Haz los desafíos**. Los cursos de Scrimba tienen desafíos integrados. No te los saltes.

## Usa esta guía cuando… {#use-this-guide-when}

Estás preparado para **dominar layouts bidimensionales**, Grid para la estructura, Flexbox para alineación detallada, en scrims guiados.
