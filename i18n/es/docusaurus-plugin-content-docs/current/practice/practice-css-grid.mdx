# Practica CSS Grid

El track de **CSS Grid** de Scrimba (más las prácticas de apoyo en UI/CSS) te hace **ubicar áreas, gaps y breakpoints directamente en el reproductor del navegador**, así que `fr`, `minmax` y `grid-template-areas` se quedan porque los usaste, no porque resaltaste un texto en un blog.

## Para quién es esto {#who-this-is-for}

Devs que por defecto recurren a trucos de Flexbox para layouts en 2D y quieren secciones de marketing o dashboards **con calidad de portafolio**.


## ¿Por qué practicar CSS Grid en Scrimba? {#why-practice-css-grid-on-scrimba}

Leer documentación es pasivo. Para dominar realmente **CSS Grid**, necesitas escribir código. El formato interactivo de Scrimba te permite:

1. **Pausar el video** en cualquier momento
2. **Editar el código** directamente en el reproductor
3. **Ejecutarlo** para ver tus cambios al instante

## Cómo practicar de forma efectiva {#how-to-practice-effectively}

1. **No te quedes solo mirando**. Cada vez que el instructor escriba código, pausa y escríbelo tú también.
2. **Rompe cosas**. Cambia valores, elimina líneas y observa qué pasa.
3. **Haz los desafíos**. Los cursos de Scrimba tienen desafíos integrados. No los saltes.
