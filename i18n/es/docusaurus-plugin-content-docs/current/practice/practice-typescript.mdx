# Practicar TypeScript

Scrimba ejecuta **TypeScript en el navegador**, pausa el video, amplía un tipo, observa los errores del compilador, corrígelos. Combina **[Learn TypeScript](/docs/courses/typescript/learn-typescript/)** con scrims gratis de **JavaScript** + **React** para que los tipos se encuentren con componentes reales, no con archivos `.ts` de prueba.

## Para quién es esto {#who-this-is-for}

Desarrolladores de JS que escribieron `any` para enviar una característica y ahora necesitan **confianza** antes de la próxima revisión de código.

TypeScript detecta errores antes de la producción; las lecciones interactivas detectan malentendidos antes de tu PR.


## ¿Por qué practicar TypeScript en Scrimba? {#why-practice-typescript-on-scrimba}

El formato interactivo de Scrimba es ideal para TypeScript porque:

1. **Pausa y edita**, detén el video y modifica las anotaciones de tipo para ver qué sucede
2. **Retroalimentación inmediata**, observa los errores de TypeScript en tiempo real mientras codificas
3. **Proyectos reales**, construye aplicaciones reales, no ejercicios aislados
4. **Sin instalación requerida**, TypeScript se ejecuta en el navegador, sin necesidad de herramientas locales

## Ejercicios de práctica de TypeScript {#typescript-practice-exercises}

### Ejercicio 1: Tipificar un objeto de usuario {#exercise-1-type-a-user-object}
```typescript
// Start with this JavaScript and add types:
const user = {
  name: "Alice",
  age: 30,
  email: "alice@example.com",
  isActive: true,
};
```
Practica definiendo interfaces, propiedades opcionales y modificadores de solo lectura.

### Ejercicio 2: Funciones genéricas {#exercise-2-generic-functions}
```typescript
// Make this function work with any type:
function getFirst(items) {
  return items[0];
}
```
Los genéricos son una de las características más poderosas de TypeScript. Practica usando `<T>` para crear funciones flexibles y seguras para los tipos.

### Ejercicio 3: Tipos de unión para respuestas de API {#exercise-3-union-types-for-api-responses}
```typescript
// Type this API response handler:
function handleResponse(response) {
  if (response.status === "success") {
    return response.data;
  } else {
    throw new Error(response.error);
  }
}
```
Las uniones discriminadas te enseñan cómo TypeScript estrecha tipos según condiciones, esencial para el trabajo real de API.

## Cómo practicar de manera efectiva {#how-to-practice-effectively}

1. **Comienza con JavaScript que conoces**, toma el código JS existente y agrega tipos de manera incremental
2. **Usa modo estricto**, `"strict": true` en tsconfig.json te obliga a manejar casos extremos
3. **Lee los errores**, los errores de TypeScript son verbosos pero informativos. Aprende a leerlos
4. **Construye algo real**, una aplicación de tareas, un cliente de API o una herramienta de CLI en TypeScript
