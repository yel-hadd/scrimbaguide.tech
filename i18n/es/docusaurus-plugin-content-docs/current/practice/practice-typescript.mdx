# Practica TypeScript

Scrimba ejecuta **TypeScript en el reproductor del navegador**: pausa un scrim, amplía un tipo, mira al compilador quejarse, corrígelo. Combina **[Learn TypeScript](/docs/courses/typescript/learn-typescript/)** con scrims gratis de **JavaScript** y **React** para que los tipos se encuentren con componentes reales, no con archivos `.ts` de juguete.

## Para quién es esto {#who-this-is-for}

Devs de JS que pusieron `any` para lanzar una funcionalidad y ahora necesitan **confianza** antes del próximo code review.

TypeScript detecta errores antes de producción; las lecciones interactivas detectan malentendidos antes de tu PR.


## ¿Por qué practicar TypeScript en Scrimba? {#why-practice-typescript-on-scrimba}

El formato interactivo de Scrimba es ideal para TypeScript porque:

1. **Pausa y edita**, detén el video y modifica anotaciones de tipo para ver qué pasa
2. **Retroalimentación instantánea**, ve los errores de TypeScript en tiempo real mientras programas
3. **Proyectos reales**, construye aplicaciones reales, no ejercicios aislados
4. **Sin configuración**, TypeScript corre en el navegador, sin toolchain local

## Ejercicios de práctica de TypeScript {#typescript-practice-exercises}

### Ejercicio 1: Tipar un objeto de usuario {#exercise-1-type-a-user-object}
```typescript
// Start with this JavaScript and add types:
const user = {
  name: "Alice",
  age: 30,
  email: "alice@example.com",
  isActive: true,
};
```
Practica definir interfaces, propiedades opcionales y modificadores readonly.

### Ejercicio 2: Funciones genéricas {#exercise-2-generic-functions}
```typescript
// Make this function work with any type:
function getFirst(items) {
  return items[0];
}
```
Los genéricos son una de las funciones más poderosas de TypeScript. Practica usar `<T>` para crear funciones flexibles y con seguridad de tipos.

### Ejercicio 3: Union types para respuestas de API {#exercise-3-union-types-for-api-responses}
```typescript
// Type this API response handler:
function handleResponse(response) {
  if (response.status === "success") {
    return response.data;
  } else {
    throw new Error(response.error);
  }
}
```
Los discriminated unions te enseñan cómo TypeScript estrecha tipos según condiciones, esencial para trabajo real con APIs.

## Cómo practicar de forma efectiva {#how-to-practice-effectively}

1. **Empieza con JavaScript que ya conoces**, toma código JS existente y agrega tipos de forma incremental
2. **Usa el modo estricto**, `"strict": true` en tsconfig.json te obliga a manejar casos límite
3. **Lee los errores**, los errores de TypeScript son extensos pero informativos. Aprende a leerlos
4. **Construye algo real**, una app de tareas, un cliente de API o una herramienta CLI en TypeScript
