# Practica Tailwind CSS

Scrimba enseña Tailwind haciendo que compongas clases de utilidad en el navegador, así `flex`, `grid-cols-3` y variantes `hover:` se quedan en tu memoria porque creaste un componente real con ellas, no porque hojeaste la documentación.

Tailwind CSS se ha convertido en el framework de estilos preferido para el desarrollo web moderno. En lugar de escribir CSS personalizado, compones clases de utilidad para construir cualquier diseño. La mejor forma de aprenderlo es construyendo interfaces reales.

## Para quién es esto {#who-this-is-for}

Desarrolladores que conocen algo de CSS y quieren construir interfaces de producción más rápido con clases de utilidad en lugar de escribir y mantener hojas de estilos separadas.


## Por qué practicar Tailwind en Scrimba {#why-practice-tailwind-on-scrimba}

1. **Retroalimentación visual**, observa tus clases de Tailwind renderizarse al instante mientras escribes
2. **Pausa y experimenta**, prueba diferentes clases de utilidad sin romper la lección
3. **Componentes reales**, construye tarjetas, barras de navegación y diseños, no ejemplos juguete
4. **Sin configuración necesaria**, Tailwind viene preconfigurado en el navegador

## Desafíos de práctica de Tailwind {#tailwind-practice-challenges}

### Desafío 1: Barra de navegación responsiva {#challenge-1-responsive-navbar}
Construye una barra de navegación que se colapse a un menú hamburguesa en móvil. Practica: `flex`, `hidden`, `md:flex`, `space-x-4`.

### Desafío 2: Grid de tarjetas {#challenge-2-card-grid}
Crea un grid responsivo de tarjetas que muestre 1 columna en móvil, 2 en tablet, 3 en escritorio. Practica: `grid`, `grid-cols-1`, `md:grid-cols-2`, `lg:grid-cols-3`, `gap-6`.

### Desafío 3: Alternador de modo oscuro {#challenge-3-dark-mode-toggle}
Estiliza un componente que cambia entre temas claros y oscuros. Practica: `dark:bg-gray-800`, `dark:text-white` y la variante `dark`.

### Desafío 4: Botón animado {#challenge-4-animated-button}
Crea un botón con efectos al pasar el cursor y transiciones. Practica: `hover:bg-blue-600`, `transition-colors`, `duration-200`, `transform`, `hover:scale-105`.

## Cómo practicar efectivamente {#how-to-practice-effectively}

1. **Reconstruye diseños existentes**, toma un diseño que te guste y reconstruyelo con Tailwind
2. **Usa la documentación como hoja de trucos**, mantén abierto [tailwindcss.com/docs](https://tailwindcss.com/docs) mientras practicas
3. **Comienza con estrategia mobile-first**, Tailwind es mobile-first por defecto. Estiliza primero la vista móvil, luego añade puntos de quiebre `md:` y `lg:`
4. **Extrae componentes**, una vez que te encuentres repitiendo combinaciones de clases, extráelos en componentes reutilizables
