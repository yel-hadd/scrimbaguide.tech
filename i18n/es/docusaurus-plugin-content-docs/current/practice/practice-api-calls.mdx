# Práctica de llamadas a APIs

Los cursos de **React** y **JavaScript** de Scrimba ponen **`fetch`, async/await, estados de carga y manejo de errores** dentro de mini-apps reales; pausas el video, rompes la solicitud, la corriges en el mismo panel. Eso es lo que miden en entrevistas, no "vi a alguien usar Postman".

## Para quién es esto {#who-this-is-for}

Desarrolladores junior que pueden renderizar JSX estático pero se quedan atrapados cuando un payload JSON, `try/catch` y spinners necesitan coexistir. Si has construido una interfaz estática pero nunca obtuviste datos en vivo en ella, este es el vacío a cerrar antes de entrevistas.

## Por qué practicar llamadas a API en Scrimba {#why-practice-api-calls-on-scrimba}

Leer la documentación de `fetch` es pasivo. Para controlar la **integración de API**, tienes que practicar. El formato interactivo de Scrimba te permite:

1. **Pausar el video** en cualquier momento
2. **Editar el código** directamente en el reproductor
3. **Ejecutarlo** para ver tus cambios al instante

## Principales cursos para practicar llamadas a API {#top-courses-to-practice-api-calls}


### [Free Interactive React Tutorial: Learn modern React in this extensive course lead by Bob Ziroll](/docs/courses/react/learn-react/) {#free-interactive-react-tutorial-learn-modern-react-in-this-extensive-course-lead-by-bob-ziroll}
**Nivel**: Intermedio | **Duración**: 15.1 h

El módulo de Side Effects te guía a través de `useEffect` y `fetch` de principio a fin, luego los proyectos capstone te tienen renderizando datos en vivo con estados de carga y error configurados.


### [React Search Tutorial: Learn to build a movie search app with this interative course](/docs/courses/react/a-react-project-movie-search-app/) {#react-search-tutorial-learn-to-build-a-movie-search-app-with-this-interative-course}
**Nivel**: Intermedio | **Duración**: 57 min

Un proyecto enfocado que consulta la API de OMDB, maneja entrada de búsqueda con debounce y muestra resultados en una cuadrícula responsive, exactamente el bucle fetch-render-handle-errors que los entrevistadores prueban.


### [Free JavaScript Tutorial: Learn the basics in this 9-hour interactive course lead by Per Borgen](/docs/courses/javascript/learn-javascript/) {#free-javascript-tutorial-learn-the-basics-in-this-9-hour-interactive-course-lead-by-per-borgen}
**Nivel**: Principiante | **Duración**: 9.4 h

Si tus fundamentos de async son débiles, retrocede un nivel primero. Los proyectos vanilla-JS aquí usan `fetch` y promises sin framework, así entiendes qué abstrae React.


## Cómo practicar efectivamente {#how-to-practice-effectively}

1. **No solo mires**. Cuando el instructor escribe código, pausa y escríbelo.
2. **Rompe cosas**. Cambia valores, elimina líneas y ve qué pasa.
3. **Haz los desafíos**. Los cursos de Scrimba tienen desafíos integrados. No los saltes.

## Usa esta guía cuando… {#use-this-guide-when}

Estás cansado de **APIs de to-do** y quieres **apps de portafolio confiables** que usan APIs reales como código en producción.
