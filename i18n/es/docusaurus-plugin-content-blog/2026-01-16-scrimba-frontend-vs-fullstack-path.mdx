# Scrimba Frontend vs Fullstack Path: ¿cuál elegir?

<DisclosureNotice />

Fullstack = Frontend + ~27h (backend, TypeScript, IA, Next.js). Elige Frontend para una ruta más rápida hacia el desarrollo web; Fullstack para roles full-stack.

## Para quién es esta guía {#who-this-is-for}

Para quienes deben elegir entre Frontend (81.6h) y Fullstack (108.4h): quienes están evaluando tiempo versus alcance, o apuntan a roles frontend versus full-stack.

"¿Debería empezar con el Frontend Path o ir directo a Fullstack?" Es la pregunta número uno en el Discord de Scrimba. La respuesta no es simplemente "más es mejor". Depende de tus objetivos profesionales, tu tiempo disponible y tu nivel de experiencia.

## La diferencia central {#the-core-difference}

El **[Fullstack Path](/docs/paths/fullstack-developer-path/)** es un superconjunto del **[Frontend Path](/docs/paths/frontend-developer-path/)**.

Contiene *todo* lo del Frontend Path, más alrededor de 27 horas de contenido adicional que cubre opciones de backend (Node, Express, SQL, Supabase), TypeScript, AI Engineering y Next.js.

## Matriz de decisión: ¿cuál es la opción correcta para ti? {#decision-matrix-which-is-right-for-you}

### Elige el [Frontend Path](/docs/paths/frontend-developer-path/) si: {#choose-the-frontend-path-if}

1.  **Eres principiante total y te sientes abrumado.** El Frontend Path está más enfocado. Dominar HTML, CSS, JavaScript y React ya es un desafío enorme. Sumarle la complejidad del backend puede llevarte al agotamiento.
2.  **Quieres conseguir trabajo lo antes posible.** Puedes conseguir empleo como "React Developer" o "Frontend Developer" solo con esta ruta. Toma ~27 horas menos (aproximadamente un mes de estudio) completarla.
3.  **Estás cambiando de carrera hacia un rol frontend específico.** Si sabes que te encanta el diseño/UI y prefieres evitar la lógica de bases de datos, quédate en Frontend.

### Elige el [Fullstack Path](/docs/paths/fullstack-developer-path/) si: {#choose-the-fullstack-path-if}

1.  **Quieres máxima flexibilidad en el mercado laboral.** Muchas ofertas de "Frontend" ahora incluyen Node.js o TypeScript como deseables. Conocerlos te convierte en un candidato más fuerte.
2.  **Quieres construir tu propio SaaS.** Si quieres crear un producto completo (como un clon de Twitter/X o una plataforma de alquileres), *necesitas* un backend.
3.  **Te interesa la IA.** El Fullstack Path incluye los nuevos módulos de AI Engineering (LLMs, agentes, RAG).
4.  **Tienes experiencia previa con código.** Si ya conoces HTML/CSS básico, avanzarás rápido al inicio y disfrutarás la profundidad de los módulos posteriores.

## Elegir Frontend Path vs Fullstack Path {#choose-frontend-path-vs-fullstack-path}

**Elige Frontend Path si:** quieres estar listo para trabajar más rápido (81.6h) y enfocarte en desarrollo web. Puedes actualizarte a Fullstack más adelante; el progreso se conserva.

**Elige Fullstack Path si:** quieres backend, TypeScript, IA y Next.js desde el inicio. Mejor para roles full-stack o enfocados en backend.
