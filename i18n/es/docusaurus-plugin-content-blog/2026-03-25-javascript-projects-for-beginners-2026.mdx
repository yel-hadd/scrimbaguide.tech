## Cómo clasificamos "valor de aprendizaje" {#how-we-ranked-learning-value}

Una clasificación más alta significa más **transferencia** a tareas laborales: persistencia, UI asíncrona, instintos de seguridad, disciplina de despliegue. Las etiquetas "principiante" e "intermedio" describen **complejidad**, no calidad; un build intermedio con alcance estrecho sigue siendo válido.

## Grupo A, JavaScript puro (sin framework) {#group-a-pure-javascript-no-framework}

Estos son ideales si aún tienes dudas sobre **eventos**, **actualizaciones de DOM** y **`async/await`**.

- **Calculadora**: te obliga a manejar entrada incorrecta y restablecer estado sin que React enmascare el flujo de datos.
- **Generador de citas aleatorias**: superficie mínima, perfecta para repetición de fetch-y-renderizado.
- **Prueba de velocidad de escritura**: excelente para alfabetización de temporizadores y casos especiales de enfoque.
- **Generador de contraseñas**: una introducción práctica a Web Crypto o `getRandomValues`.
- **Generador de paleta de colores**: enseña intuición HSL/RGB y pensamiento de contraste para UIs reales.
- **Máquina de batería**: hace que los errores de tiempo sean obvios, y es divertido si te gustan los bucles de retroalimentación táctiles.

Ancla tu lectura con [Learn JavaScript](/docs/courses/javascript/learn-javascript/) y mantén una pestaña abierta a [cómo escapar del tutorial hell](/blog/how-to-escape-tutorial-hell-2026/) cuando quieras echar un vistazo a soluciones.

## Grupo B, Proyectos React (después de que JS haga clic) {#group-b-react-projects-after-js-clicks}

Pasa aquí cuando puedas estructurar **createRoot**, **useState** y **useEffect** deliberadamente, no por memoria muscular de un video solo.

- **Lista de tareas (versión React)**: sigue siendo la mejor herramienta de enseñanza de elevación de estado.
- **Aplicación de tarjetas didácticas**: excelente para límites de componentes (tarjeta, mazo, resumen de sesión).
- **Aplicación de cuestionario**: practica flujos controlados y estado derivado.
- **Mini feed social**: enseña renderizado de listas, claves y estados vacíos que se sienten sociales.
- **Visor de Markdown**: empareja React con hábitos de HTML sanitizado.

Enlaces profundos: [Learn React](/docs/courses/react/learn-react/), [React Router](/docs/courses/react/react-router/), y la [guía de aplicación de búsqueda de películas](/docs/courses/react/a-react-project-movie-search-app/) con instrucciones.

## Grupo C, Proyectos de API e integración {#group-c-api-and-integration-projects}

Estos builds aún necesitan claridad de **vanilla fetch** incluso si la UI es React; depuración de redes es una habilidad de carrera.

- **Aplicación de clima**: la tríada clásica de carga / éxito / fallo.
- **Visor de perfil de GitHub**: paginación y deriva de esquema (los campos de API cambian).
- **Búsqueda de imágenes**: los límites de velocidad y la carga perezosa estiran tus habilidades de diseño.
- **Buscador de recetas**: atributos anidados entrenan renderizado defensivo (patrones `?.`).
- **Acortador de URLs**: incluso una versión de persistencia simulada enseña diseño de ID, y una pequeña función serverless es un bonus.
