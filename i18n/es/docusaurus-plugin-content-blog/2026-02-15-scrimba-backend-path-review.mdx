# Reseña de la ruta Backend de Scrimba (2026)

<DisclosureNotice />

**Sí, para desarrolladores JavaScript que quieren agregar habilidades del lado del servidor**, una ruta enfocada de ~39 horas en Node, Express y SQL. No es para principiantes absolutos ni para backends no-JavaScript.

La Backend Developer Path de Scrimba es la más nueva de las cuatro rutas de carrera, y con 36.2 horas, se mantiene estrictamente enfocada en JavaScript del lado del servidor. Cubre Node.js, Express, SQL y JavaScript del lado del servidor, todo lo que necesitas para construir APIs y servicios backend.

{/* truncate */}

## Qué incluye The Backend Developer Path {#whats-inside-the-backend-path}

The Backend Developer Path es un currículo estructurado que cubre:

- **Fundamentos de Node.js**, módulos, sistema de archivos, event loop, npm
- **Express.js**, enrutamiento, middleware, diseño de API REST, manejo de errores
- **SQL y bases de datos**, consultas, joins, diseño de esquema, PostgreSQL
- **Autenticación**, sesiones, JWTs, conceptos básicos de OAuth
- **Deployment**, desplegar tu backend en vivo

Con 36.2 horas de contenido, espera 80-120 horas de tiempo de aprendizaje real incluyendo ejercicios y proyectos.

## Para quién es esta ruta {#who-is-this-path-for}

Esta ruta está diseñada para desarrolladores que ya conocen los fundamentos de JavaScript y quieren pasar al lado del servidor. Si has completado la Frontend Developer Path o tienes experiencia equivalente, estás listo.

**Requisitos previos:**
- Conocimiento sólido de JavaScript (funciones, async/await, objetos, arrays)
- Comprensión básica de HTTP y APIs
- Familiaridad con la línea de comandos

Si eres un principiante absoluto, comienza con la [Frontend Developer Path](/docs/paths/frontend-developer-path/) primero.

## La diferencia interactiva {#the-interactive-difference}

Como todos los cursos de Scrimba, la ruta Backend usa el formato interactivo scrim. Esto importa especialmente para desarrollo backend donde:

- Puedes **modificar manejadores de rutas Express** y ver cambiar la respuesta
- Puedes **editar consultas SQL** en línea y ejecutarlas contra una base de datos
- Puedes **romper cadenas de middleware** y observar el manejo de errores

Comparado con ver un tutorial de Node.js en YouTube, estás escribiendo código de servidor, no solo viendo a alguien más escribirlo.

## Fortalezas {#strengths}

- **Enfocada y eficiente**, con 36.2 horas, no pierde tiempo en contenido relleno
- **Formato interactivo**, escribes código backend desde la primera lección
- **Stack moderno**, Node.js, Express y SQL están muy en demanda
- **Parte del ecosistema**, se combina naturalmente con las Frontend Developer Path y Fullstack Developer Path de Scrimba

## Limitaciones {#limitations}

- **Sin Python ni Go**, si quieres un backend no-JavaScript, busca en otro lado
- **Cobertura limitada de DevOps**, Docker, Kubernetes e CI/CD no se cubren en profundidad
- **Más corta que las alternativas**, 36.2 horas significa menos profundidad que un currículo de 100 horas
- **Requiere conocimiento de JavaScript**, esto no es un curso para principiantes desde cero

## Nuestro veredicto {#our-verdict}

**La Backend Developer Path es excelente para desarrolladores JavaScript que quieren ser fullstack.** Es enfocada, interactiva y enseña las habilidades backend más demandadas (Node.js, Express, SQL). Si necesitas Python o DevOps, tendrás que complementar con otros recursos.

**Calificación: 4.3/5**, restando puntos por diversidad limitada de lenguajes y duración más corta en comparación con la Frontend Developer Path.
