# Cómo aprender ingeniería de IA en Scrimba

<DisclosureNotice />

Sigue the AI Engineer Path (11.4h, Pro) o elige cursos individuales. Cubre agents, RAG, MCP, SDK de Vercel AI. 12 cursos de IA.

## Quién debería tomar este curso {#who-this-is-for}

Desarrolladores web que agregan habilidades de IA: quienes quieren aprender sobre agents, RAG o MCP; o cualquiera eligiendo entre la ruta y los cursos à la carte.

AI Engineering es la especialización que crece más rápido en el desarrollo web. No se trata de entrenar modelos foundation o hacer matemática pesada; se trata de **crear aplicaciones** que usan LLMs. Scrimba tiene uno de los currículos de ingeniería de IA más completos disponibles, **12 cursos** cubriendo todo desde la API de OpenAI hasta temas de vanguardia como Model Context Protocol (MCP) y RAG.

## Dos enfoques para aprender IA {#two-approaches-to-learning-ai}

Puedes seguir la **Ruta de Carrera** curada o tomar **cursos individuales** à la carte.

### Opción A: The AI Engineer Path (Estructurado, Pro) {#option-a-the-ai-engineer-path-structured-pro}

The [AI Engineer Path](/docs/paths/ai-engineer-path/) es un currículo estructurado de 11.4 horas diseñado para llevarte de un desarrollador web estándar a un AI Engineer.

**Secuencia de currículo:**

1.  **Intro to AI Engineering** (2.4 hrs): Conceptos básicos de LLMs, prompts y el SDK de OpenAI.
2.  **Deployment** (52 min): Cómo enviar apps de IA a producción.
3.  **Embeddings & Vector dbs** (95 min): Los fundamentos de "memoria" para IA.
4.  **AI Agents** (117 min): Construyendo agents autónomos que pueden usar herramientas e iterar.
5.  **Context Engineering** (58 min): Optimizando lo que alimentas al modelo.
6.  **Vercel AI SDK** (113 min): Usando el SDK estándar de la industria para React AI apps.
7.  **Model Context Protocol** (37 min): El nuevo estándar para conectar IA a datos.

## Lo que necesitas saber antes de empezar {#what-you-need-to-know-before-starting}

Definitivamente **no** necesitas saber Python. Ese es el punto hermoso de la ruta de Scrimba: es 100% JavaScript y TypeScript.

**Requisitos previos:**
- **JavaScript**: Nivel intermedio (Promises, async/await, objects).
- **React**: Los conceptos básicos son útiles para las partes de UI (Vercel AI SDK), pero la lógica del lado del servidor en Node.js es el núcleo.
- **Conocimiento de API**: Entender cómo hacer fetch requests y manejar JSON.

## ¿Por qué Scrimba para IA? {#why-scrimba-for-ai}

La mayoría de tutoriales de IA son solo ver videos de código boilerplate de Python. Scrimba es diferente:

1.  **Es todo JavaScript**: Si eres un web dev, no necesitas aprender un nuevo lenguaje.
2.  **Basado en el navegador**: No necesitas preocuparte por entornos de Python, pip o conda. Simplemente funciona.
3.  **Proyectos reales**: Construyes agents de soporte, bots de preguntas de documentos y motores de búsqueda semántica, no solo "Hello World".
