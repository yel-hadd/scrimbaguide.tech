# Ruta de Aprendizaje de React en Scrimba: Guía Semana a Semana

<DisclosureNotice />

Orden recomendado: Learn React (gratis) → Advanced React → Router → preparación de entrevistas. 8 semanas a 1-2 hrs/día. React es uno de los temas más sólidos de Scrimba con ~10 cursos.

## Para quién es esta guía {#who-this-is-for}

Estudiantes que planifican su viaje de React en Scrimba: quienes se sienten abrumados por las opciones de cursos, o cualquiera que quiera un camino estructurado semana a semana.

React es uno de los temas más sólidos de Scrimba, con **~10 cursos** y más de 50 horas de contenido. Se considera ampliamente una de las mejores plataformas interactivas para aprender React porque corriges código directamente en el reproductor de video. Sin embargo, con tantos cursos, puede resultar confuso saber en qué orden tomarlos. Esta guía traza el camino óptimo para ir desde "Hola Mundo" hasta "Contratado".

{/* truncate */}

## Orden Recomendado para Aprender React {#the-recommended-react-learning-order}

Hemos estructurado esto en un plan de 8 semanas, asumiendo que estudias ~1-2 horas al día.

### Semanas 1-2: Learn React (Gratis) {#weeks-1-2-learn-react-free}

**Duración:** 15.1 horas | **Instructor:** Bob Ziroll | **Costo:** $0

Empieza aquí. Este es el curso gratis insignia de Scrimba y es ampliamente considerado uno de los mejores recursos gratuitos de React en la web. Bob Ziroll te guía a través de conceptos modernos de React sin relleno innecesario.

**Qué aprenderás:**
- Páginas estáticas vs componentes React
- Props, State y Conditional Rendering
- `useEffect` y side effects
- Formularios e inputs en React
- Fetching de datos desde APIs

**Qué construirás:**
- **TenZs Game**: Un juego de dados.
- **Quizzical**: Una aplicación de trivia que obtiene datos de una API.
- **Meme Generator**: Un creador de memes interactivo.

### Semanas 3-4: Advanced React (Pro) {#weeks-3-4-advanced-react-pro}

**Duración:** 18.8 horas | **Instructor:** Bob Ziroll | **Costo:** Pro

Después de los conceptos básicos, este curso masivo cierra la brecha entre un principiante y un profesional. Se enfoca en escribir código limpio, reutilizable y eficiente.

**Temas Clave:**
- **Reutilización**: Children props, Higher Order Components (HOCs), y Render Props.
- **Context API**: Manejo de estado global sin prop drilling.
- **Custom Hooks**: Extracción de lógica en tus propios hooks.
- **Router (Intro)**: Conceptos básicos de routing.
- **Performance**: `React.memo`, `useMemo`, y `useCallback`.

<AffiliateLink href="https://scrimba.com/advanced-react-c02h?via=u42d4986" variant="button">Ver Advanced React</AffiliateLink>

---

### Semanas 5-6: React Router 6 (Pro) {#weeks-5-6-react-router-6-pro}

**Duración:** 9.7 horas | **Instructor:** Bob Ziroll | **Costo:** Pro

Las Single Page Applications (SPAs) necesitan routing. Este curso cubre la librería estándar de la industria `react-router-dom` en profundidad.

**Lo que dominarás:**
- Dynamic routes (`/products/:id`)
- Nested routes / Layout components
- Protected routes (requiere login)
- Loaders and Actions (nuevo en Router 6.4+)
- Manejo de 404s y errores

**Proyecto Capstone:** **#VanLife**, Una plataforma de alquiler completamente funcional para vans, con filtering, host dashboard, y authentication flows.

---

### Semana 7: React Challenges & Practice (Pro) {#week-7-react-challenges--practice-pro}

**Duración:** 9.8 horas | **Instructor:** Bob Ziroll

No puedes aprender solo viendo. Este curso te lanza **40 desafíos de coding**. Varían desde tareas simples de "arregla este bug" hasta problemas de lógica complejos.

**Ejemplos:**
- Arregla el array de dependencias roto en `useEffect`
- Implementa un toggle de modo oscuro
- Optimiza una lista que se renderiza lentamente

---

### Semana 8: Especialización y Preparación de Entrevistas {#week-8-specialization--interview-prep}

Elige tu sprint final según tus objetivos inmediatos:

#### Opción A: La Pista "Job Hunter" {#option-a-the-job-hunter-track}
Toma el curso de **React Interview Questions**. Desglosa preguntas técnicas de entrevista comunes como "¿Qué es el Virtual DOM?" y "Explica el ciclo de vida de React".

#### Opción B: La Pista "Bleeding Edge" {#option-b-the-bleeding-edge-track}
Toma **React 19 Tutorial** (Gratis). Aprende sobre Server Components, Actions, y el hook `use`. Ideal si te postulas a startups que usan Next.js.

#### Opción C: La Pista "Architect" {#option-c-the-architect-track}
Toma **Build Reusable React Components**. Aprende sobre compound components y patrones de diseño avanzados.
