# 10 Proyectos que Harás en Scrimba en 2026

<DisclosureNotice />

Las rutas de carrera incluyen APIs, aplicaciones React, bases de datos y proyectos capstone fullstack; la lista a continuación muestra proyectos representativos para que sepas qué construirás.

El mayor problema con la mayoría de tutoriales es que solo ves a alguien más programar. Asientes, pero cuando abres un editor de texto en blanco, te paralizas.

Scrimba resuelve esto obligándote a construir. Aquí hay 10 proyectos reales que construirás en las Rutas de Carrera que puedes poner en tu portafolio inmediatamente.

## Para Quién Es Esto {#who-this-is-for}

Estás eligiendo una ruta y quieres ejemplos concretos de lo que construirás antes de inscribirte.


## Los Tres Capstones Principales {#the-big-three-capstones}

Estos son los proyectos insignia que toman varias horas en completarse.

### 1. VanLife (React Router Capstone) {#1-vanlife-react-router-capstone}
*   **Curso:** [Advanced React](/docs/courses/react/advanced-react/)
*   **Qué es:** Una plataforma de alquileres tipo Airbnb para furgonetas de campista.
*   **Stack de tecnología:** React Router (patrones v6 que se mantienen en la versión v7), Loaders, Actions, Nested Routes, Firebase.
*   **Por qué impresiona:** Maneja escenarios complejos de ruteo del mundo real como rutas protegidas (se requiere login), parámetros de búsqueda y errores de obtención de datos.

### 2. Quizzical (Trivia App) {#2-quizzical-trivia-app}
*   **Curso:** [Learn React](/docs/courses/react/)
*   **Qué es:** Un cuestionario de preguntas de trivia dinámico que obtiene preguntas de la API Open Trivia Database.
*   **Stack de tecnología:** React, `useEffect`, obtención de API, renderizado condicional.
*   **Por qué impresiona:** Maneja el "estado del juego" perfectamente, verificando respuestas, sumando puntuaciones y reiniciando el juego, que es la lógica central de la mayoría de aplicaciones empresariales (State -> Action -> New State).

### 3. Tenzies (Dice Game) {#3-tenzies-dice-game}
*   **Curso:** [Learn React](/docs/courses/react/)
*   **Qué es:** Un juego rápido de lanzamiento de dados en el que congelas dados para que coincidan números.
*   **Stack de tecnología:** React State, Side Effects.
*   **Por qué impresiona:** Es adictivo e interactivo. Demuestra que entiendes cómo manejar muchas piezas de estado que cambian simultáneamente.

## Los Proyectos de IA (Nuevos para 2026) {#the-ai-projects-new-for-2026}

### 4. AI Support Agent {#4-ai-support-agent}
*   **Curso:** [Build a Support Agent](/docs/courses/ai/a-support-agent-with-vercel-ai-sdk/)
*   **Qué es:** Un chatbot de soporte al cliente que puede responder preguntas basado en una base de conocimiento específica.
*   **Tech:** Vercel AI SDK, OpenAI API, RAG (Generación Aumentada por Recuperación).

### 5. Translator App {#5-translator-app}
*   **Curso:** [Intro to AI Engineering](/docs/courses/ai/ai-engineering/)
*   **Qué es:** Una aplicación de traducción de texto que detecta idioma y contexto (por ejemplo, "traducir 'bank' en el contexto de río vs dinero").
*   **Tech:** las API de LLM más recientes, Prompt Engineering.

## Los Clásicos de "JavaScript Puro" {#the-pure-javascript-classics}

### 6. Movie Search App {#6-movie-search-app}
*   **Curso:** [Working with APIs](/docs/courses/javascript/)
*   **Qué es:** Un panel para encontrar películas, ver pósters y leer tramas.
*   **Tech:** Async/Await, Fetch API, manipulación del DOM.

### 7. Color Scheme Generator {#7-color-scheme-generator}
*   **Curso:** [Working with APIs](/docs/courses/javascript/)
*   **Qué es:** Una herramienta para diseñadores que genera paletas de colores coincidentes a partir de un color base.
*   **Tech:** REST APIs, integración de Clipboard API.

### 8. Mobile Restaurant Ordering App {#8-mobile-restaurant-ordering-app}
*   **Curso:** [Essential JavaScript](/docs/courses/javascript/)
*   **Qué es:** Un menú estilo "UberEats" donde agregas artículos a un carrito y calculas totales.
*   **Tech:** vanilla JS (¡sin framework!), Event Listeners, Data Attributes.

## Proyectos de Diseño y Maquetación {#design--layout-projects}

### 9. Learning Journal {#9-learning-journal}
*   **Curso:** [Responsive Design](/docs/courses/css/)
*   **Qué es:** Un diseño de blog de múltiples páginas.
*   **Tech:** CSS Grid, Flexbox, Media Queries (flujo Mobile-First).

### 10. Digital Business Card {#10-digital-business-card}
*   **Curso:** [Learn React](/docs/courses/react/)
*   **Qué es:** ¡Tu primer componente React!
*   **Tech:** Componentes React estáticos, Styling.
